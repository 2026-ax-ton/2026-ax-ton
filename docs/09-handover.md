## 4. 데이터 10칸과 그 계약

**화면 코드는 `localStorage` 를 직접 부르지 않습니다.** 반드시 `Store` 를 거칩니다.
**직접 부르는 코드가 `store.js` 밖에 없는지를 자동 검사가 매번 확인합니다.**

```
[화면 11개]  →  [ Store ]  →  지금: 브라우저 저장소
                    ↑
              서버가 생기면 이 안쪽만 서버 호출로 바꿉니다.
              화면 11개는 한 줄도 안 고쳐도 됩니다.
```

| # | 키 | 무엇 | 쓰는 쪽 | 읽는 쪽 |
|---|---|---|---|---|
| 1 | `accounts` | 계정 | 회원가입 | 로그인 · 게시판(역할 판정) |
| 2 | `session` | 지금 로그인한 사람 | 로그인 | 모든 화면(가드) |
| 3 | `setup` | 사업장·언어·공정·설비·노동자 | 기능1 | 거의 전부 |
| 4 | `library` | 안전 문구 + **언어별** 검수 상태 | 기능9 | 기능2 · 기능3 · 홈 |
| 5 | `courses` | 교육과 문항 | 기능2 | 기능3 · 기능4 · 5 · 6 |
| 6 | `progress` | 누가 무엇을 듣고 몇 점인지 | 기능3 · 기능4 | 기능5 · 기능6 · 마이 |
| 7 | `reports` | 위험요소 신고 (**익명**) | 기능8 | 기능6 |
| 8 | `posts` | 게시글·댓글 | 기능7 | 기능7 |
| 9 | `prefs` | **이 기기**의 보기 설정 (글자 크기) | 노동자 아무 화면 | 노동자 전부 |
| 10 | `orders` | 담당자의 **재교육 지시** | 기능6 | 노동자 홈 · 기능6 |

### 4.1 모양이 미묘한 세 곳

**① `library[].translations[code].status` — 언어별 검수**

```js
{ id: 'ph-3', ko: '환기팬이 돌지 않으면 …', status: 'reviewed',
  translations: {
    km: { text: '…', back: '…', status: 'reviewed' },
    id: { text: '…', back: '…', status: 'stopped' }   // 이 언어만 중지
  },
  flags: [ { note: '…', lang: 'id', at: '…', resolvedAt: null } ] }
```

읽을 때는 **반드시 `Store.phraseOk(p, lang)`**. `p.status` 를 직접 보면
**크메르어 노동자가 인도네시아어 오역 때문에 안전 지시를 잃습니다.**
문구 전체와 언어별 판정이 다르면 **엄한 쪽**(중지 > 대기 > 완료)을 따릅니다.

**② `courses[].quiz[].i18n` — 문항 다국어**

```js
{ id: 'q2', type: 'choice', prompt: '…', options: ['…','…','…'], answer: 1,
  i18n: { km: { prompt: '…', options: ['…','…','…'], results: [...] } } }
```

읽을 때는 **반드시 `Store.qtext(q, lang, field)`**.
**`answer` 는 `options` 의 인덱스**라, 번역 배열 길이가 다르면 정답이
다른 선택지를 가리키고 **틀린 작업을 맞다고 가르칩니다.**
그 검사는 `qtext` **한 곳에만** 있습니다.

**③ `progress[].quiz.asked` — 답이 어느 문항의 것인가 (C6 에서 추가)**

```js
quiz: { score: 67, passed: false, answers: [0,1,1], asked: ['q1','q2','q3'],
        at: '…', attempt: 2, firstPassed: true }
```

`answers` 의 자리는 **"그때 실제로 낸 문항"** 의 순서지 `course.quiz` 의 자리가
아닙니다. 문항을 하나 내리면(`retired`) 그 뒤에 푼 사람의 답이 **한 칸씩 밀립니다.**
읽을 때는 **반드시 `Store.askedQuestion(course, quizRow, i)`**.
`asked` 가 없는 옛 기록은 지금까지처럼 자리로 찾습니다.

### 4.2 데이터 모양을 바꿔야 한다면

1. `store.js` 의 그 키 주석부터 고칩니다 (거기가 계약서입니다)
2. **그 키를 읽는 화면을 전부** 엽니다 (위 표)
3. **읽는 통로를 함수 하나로 모읍니다** (`phraseOk` · `qtext` · `askedQuestion` ·
   `orderOpen` 이 전부 그렇게 생겼습니다). 화면마다 흩어 놓으면 언젠가 한 곳이 빠집니다
4. 검사를 돌리고, **일부러 망가뜨려** 그 검사가 잡는지 봅니다

### 8.2-2 트랙 색 (2026-08-30)

**담당자·운영자는 보라, 노동자는 빨강.** 같은 폰을 돌려 쓰기 때문에,
화면을 읽기 전에 머리띠 색만으로 누구 화면인지 알 수 있어야 한다.

**색은 두 곳에만 있다.** 화면 CSS 에 색을 직접 쓰지 않는다.

| 어디 | 무엇 |
|---|---|
| `src/assets/style.css` 의 `:root` | **보라** — 담당자 · 운영자 · 로그인 · 회원가입 (기본값) |
| `src/worker/worker.css` 맨 위의 `:root` | **빨강** — 노동자 화면에서 위 토큰을 덮어쓴다 |

| 토큰 | 어디에 쓰나 |
|---|---|
| `--brand` | 버튼 바탕 · 흰 바탕 위 글자. **양쪽 다 4.5:1 을 넘는 중간 짙기** |
| `--brand-strong` | 눌린 상태 · 머리띠 그러데이션 끝 |
| `--brand-deep` | `--brand-soft` 바탕 **위의 글자** |
| `--brand-soft` / `--brand-line` | 옅은 바탕 / 그 테두리 |
| `--brand-vivid` / `--brand-vivid-2` | **장식 전용** (막대 · 그러데이션). 글자를 얹지 않는다 |
| `--brand-focus` | 초점 테두리 |
| `--admin-accent` | **worker.css 가 덮어쓰지 않는다.** 노동자 화면 위에 뜨는 담당자용 안내(`.admin-here`) 전용 |

| 함정 | 규칙 |
|---|---|
| **시안의 밝은 색을 그대로 `--brand` 로 쓰기** | `--brand` 는 바탕으로도 글자로도 쓰인다. 밝은 색은 글자 대비가 모자람 → **`--brand-vivid` 로 따로 두고 장식에만** |
| **노동자 빨강이 위험 빨강과 겹치기** | 안전 화면에서 주 색과 위험 색이 같아 보이면 위험 표시가 묻힌다. `--stop` 은 짙은 진홍(`#8f1420`), 브랜드는 밝은 산호(`#c0392c`) |
| 노동자 화면의 담당자용 안내가 빨강이 됨 | 뜻이 반대다. `--admin-accent` 를 쓴다 |
| 회원가입 화면에서 `var(--brand)` 로 노동자 빨강을 기대하기 | **`signup.html` 에는 `worker.css` 가 실리지 않는다.** 그 화면의 노동자 칩만 값으로 직접 썼다 (`app.css` `#pick-role`) |
| 색을 바꾸고 배포 | **`src/sw.js` 의 `VERSION` 을 올려야 한다.** 안 올리면 옛 색이 그대로 남는다 |

### 8.2-4 화면이 가로로 밀리는 것 (2026-08-30 에 세 군데)

폰과 PC 를 폭 12가지로 훑어서 **화면 13개 × 12폭** 을 다 재 봤다.
세 군데가 밀리고 있었다. **전부 색을 바꾸기 전부터 있던 것**이고,
원인은 하나로 모인다 — **줄바꿈을 거부하는 것이 격자 칸 안에 들어갔다.**

격자·플렉스 칸은 기본이 `min-width: auto` 다. 안에 든 것이 줄바꿈을 거부하면
칸이 제 몫보다 넓어지고, 그대로 화면 전체가 옆으로 밀린다.

| 어디 | 무엇이 버텼나 | 어떻게 고쳤나 |
|---|---|---|
| 노동자 홈, 폰 폭 361~490px | `.bigmenu-cell` 안의 배지(`nowrap`) | 칸에 `min-width: 0` · 배지는 줄바꿈 · **두 칸으로 나누는 기준을 360 → 460px** |
| 운영자 문구, **1024~1400px** | 넓은 화면에서 `.tablewrap` 의 가로 스크롤을 꺼 뒀음 | 그 규칙을 뺐다. 표는 제 안에서 스크롤한다 (인쇄는 따로 펼침) |
| 운영자 문구, 폰 폭 320~390px | `.btn-sm` 의 긴 이름표가 한 줄로 버팀 | `.btn-sm` 의 `nowrap` 을 **표 안에서만** 남겼다 |

| 함정 | 규칙 |
|---|---|
| **격자 칸에 `nowrap` 인 것을 넣기** | 칸이 넓어지는 것으로 끝나지 않는다. **화면이 통째로 밀린다.** 칸에 `min-width: 0` 을 주고 안의 것이 접히게 둔다 |
| 넓은 화면이라고 표의 가로 스크롤을 끄기 | 넓어도 표가 더 넓을 수 있다. 노트북(1280·1366)이 그 구간이었다 |
| 폭을 **가로 밀림만으로** 판단하기 | 밀리지 않아도 비율이 망가질 수 있다 (아래 8.2-5) |

**재는 법** — 브라우저에서 아이프레임에 화면을 띄우고
`documentElement.scrollWidth - clientWidth` 를 본다. 0 이 아니면 밀리는 것이다.
`jsdom` 은 배치를 계산하지 않아 검사로는 못 잡는다.
그래서 `tests/test-docs.js` 는 **다시 그렇게 될 수 있는 모양**(위 표의 규칙들)을 대신 지킨다.

### 8.2-5 같은 이름을 두 화면이 나눠 쓰면 (2026-08-30)

**`.anon-note` 를 두 화면이 같이 쓰고 있었다.**

- 신고 화면(기능8) — 큰 익명 고지. 가운데 정렬로 세로로 쌓는 것
- 소통 화면(기능7) — 한 줄 안내. 아이콘 + 글을 가로로 놓는 것

`worker.css` 에서 **뒤에 있는 소통 화면 규칙이 앞의 것을 덮었다.**
그래서 *"이름을 남기지 않습니다"* — 이 화면에서 **가장 중요한 문장**이
네 칸짜리 가로줄로 찌그러져, 폰에서는 한 글자씩 접혀 나왔다.
가로로 밀리지는 않아서 **넘침만 재면 안 잡힌다.**

같은 종류로 **`.ico` 규칙이 배지 안까지 흘러든 것**도 있었다.
`.course-open .ico` 는 52px 짜리 색 상자인데, 그 칸에 들어간 배지의 체크 표시까지
52px 이 되어 **글자보다 큰 그림**이 됐다 (`.bigmenu-link .ico` 는 34px).

| 함정 | 규칙 |
|---|---|
| **다른 것에 같은 class 이름 쓰기** | 언젠가 한쪽이 다른 쪽을 덮는다. 이름을 가른다 (`.anon-note` / `.anon-line`) |
| 칸 안의 그림에 **자손 선택자**(`.칸 .ico`) 쓰기 | 그 칸에 들어온 배지·칩의 그림까지 잡는다. **바로 아래 자식(`>`)** 으로 쓴다 |
| 그래도 새 칸이 생기면 또 흔들림 | `style.css` 의 `.badge > .ico` 가 배지 안을 한 번 끊어 준다 — **배지는 어디에 들어가도 제 크기** |

### 8.2-3 개발용 메모는 배포 주소에서 감춘다 (2026-08-30)

화면 여덟 개 맨 아래의 **"여기부터 채우시면 됩니다"** 칸은 개발자에게 하는 말이다.
시연 중에 그것이 뜨면 보는 사람은 **"아직 안 만든 화면"** 으로 읽는다.
그렇다고 지우면 **무엇이 남았는지를 잃는다** (`tests/test-docs.js` 가 그 칸을 지금도 본다).

**그래서 지우지 않고 자리에 따라 감춘다.**

| 어디서 열었나 | `<html data-env>` | 메모 칸 |
|---|---|---|
| `file://` (더블클릭) | `dev` | **보인다** |
| `localhost` · `127.0.0.1` | `dev` | **보인다** |
| 브랜치 미리보기 (`…-git-develop-….vercel.app`) | `dev` | **보인다** |
| 검사 하네스 (`test.local`) | `dev` | 보인다 |
| **배포 주소 `2026-ax-ton.vercel.app`** | `live` | **안 보인다** |

- 판정은 `src/assets/store.js` 의 `whereAmI()` — `<head>` 에서 `<html data-env>` 를 붙인다
- 감추는 규칙은 `src/assets/app.css` 의 `.todo`
- 코드에서 쓰려면 `Store.env` (`'dev'` \| `'live'`) 와 `Store.isDev`
- 개발 자리에서는 칸 제목 앞에 **"개발 화면에서만 보입니다 ·"** 가 붙는다

| 함정 | 규칙 |
|---|---|
| **보이는 쪽을 기본값으로 두기** | 스크립트가 멈추면 **하필 시연에서** 메모가 튀어나온다. **`display: none` 이 기본값**이고, `data-env="dev"` 일 때만 다시 켠다. 실패해도 시연이 안전한 쪽으로 기울여 뒀다 |
| 메모를 **지워서** 해결하기 | 남은 일의 목록을 잃는다. 감추는 것과 없애는 것은 다르다 |
| `hidden` 속성으로 감추기 | 개발 자리에서도 안 보이게 된다. **감추는 것은 CSS 의 일**이다 |
| **배포 주소를 갈아 끼우고 `store.js` 를 안 고치기** | 새 주소가 `dev` 로 잡혀 시연에서 메모가 다시 보인다. `tests/test-demo.js` 가 잡는다 |
| 새 화면에 메모 칸을 넣고 `class="todo"` 를 빼기 | 안 묶이면 감춰지지 않는다 |

> **로그인 화면의 "목업" 배지는 이것과 다르다.** 그것은 개발용 메모가 아니라
> *"비밀번호가 이 브라우저에 그대로 저장됩니다"* 를 밝히는 **제품의 고지**다
> (`assets/auth.js` 맨 위 주석). 감추지 않는다.

### 8.2-1 음성 되돌림

| 함정 | 규칙 |
|---|---|
| **뜻이 안 닿는 소리를 내기** | 소리는 나는데 아무것도 전달되지 않으면 사람은 **"들었다" 고 넘어간다.** 그 언어 음성이 없으면 **안 내고, 왜 안 내는지 적는다** (`UI.voiceSilent` · `voiceNote`) |

| **기본을 `ko` 로 두기** | 기본이 되돌림이면 이 기능이 있는 이유가 사라짐. 기본은 **`silent`** |

| **aria-label 에 원인을 하나로 뭉뚱그리기** | 원인이 둘(브라우저 / 내 언어 음성). 화면 낭독기 쓰는 사람에게는 그것이 이유의 전부. `voiceNote()` 와 **한 통로** |
| **`ui.js` 의 되돌림 표와 사전이 갈림** | 관리자 화면은 `i18n.js` 를 안 읽어서 `VOICE_NOTE_KO` 를 씀. **`test-voicefallback.js` 가 양방향으로 대조** |

### 8.3-1 저장소를 조직으로 옮기면 (2026-09-28)

### 8.4 환경

| 함정 | 규칙 |
|---|---|
| ES 모듈 | `file://` 에서 CORS. `var X = (function(){...})()` |
| 절대경로 `/assets/...` | `file://` 에서 깨짐. **상대경로** |

| jsdom 은 화면을 안 그림 | CSS 는 **글로 읽어** 확인 |

| **`String.replace` 의 치환문에 `$$`** | JS 에서 `$$` 는 **리터럴 `$` 하나**를 뜻함. `UI.$$` 가 `UI.$` 로 조용히 바뀌어 화면 하나가 죽었음. 치환문에 `$` 가 있으면 **함수 형태**로: `s.replace(a, () => b)` |
| **셸 힙독이 백슬래시를 먹음** | `\b` `\s` 가 든 정규식을 힙독으로 넘기면 한 겹 사라져 다른 뜻이 됨. 그런 내용은 **Write 로 직접** 쓰기 |

| **`VERSION` 을 안 올리고 배포** | 고쳤는데 안 고쳐진 것으로 보임. Service Worker 의 가장 흔한 사고 |
| **★ `VERSION` 을 올렸는데도 옛 화면** | **새로고침만으로는 안 바뀐다.** `skipWaiting()` 을 일부러 안 부르므로, 새 판은 **그 사이트의 탭을 전부 닫았다 다시 열 때** 들어온다. 2026-08-30 에 배포 확인하다 겪음 — `caches.keys()` 에 `safety-v6` 과 `safety-v7` 이 같이 있으면 아직 옛 판이 화면을 쥐고 있는 것이다. **시연 전에는 탭을 한 번 다 닫으세요** |
| **"오프라인 가능" 을 고정 문구로 박음** | `file://` 이나 아직 안 담긴 상태에서도 그렇게 말함 → **화면이 거짓말**. `UI.offlineReady()` 로 실제 `controller` 를 보고 그림 |
| **`file://` 에서 등록을 시도** | 부르는 것만으로 예외가 나는 브라우저가 있음. **`https:` 검사 + `try/catch` 둘 다** |

## 10. 새 채팅창에서 시작하는 법

**Claude Code 를 열고 이렇게만 쓰면 됩니다.**

```
docs 폴더 읽고 바로 진행해줘
```

그러면 `CLAUDE.md` 규칙에 따라 이렇게 동작합니다.

1. `git branch --show-current` — `feature/byeonsoyun` 인지 확인
2. [`07-next-tasks.md`](07-next-tasks.md) 맨 위 **"★ 지난 세션이 끝난 자리"** 를 읽음
3. 지금 상태를 한 문단으로 말하고 **다음 한 걸음**을 제안
4. 끝나면 검사·문서·개발일지를 갱신하고 커밋·push 까지

**지금은 `- [ ]` 가 없으므로**, 새 세션은 아래 셋 중 하나를 제안할 것입니다.

- **폰으로 확인하기** ([`10-checklist.md`](10-checklist.md))
- **E층 — 오프라인 우선 동작**

> **더 자세한 배경이 필요하면** `docs/devlog/byeonsoyun.md` 맨 위 항목을 봅니다.
> 특히 **"막혔던 것 / 어떻게 풀었는지"** 에 이 코드가 왜 이렇게 생겼는지가 있습니다.
