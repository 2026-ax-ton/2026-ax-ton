## 1. 범위 — 두 개의 사이드 (표 1)

| 구분 | **작업자앱 (LMS 서비스앱)** | **관리자앱 (어드민)** |
|---|---|---|
| 사용자 | 이주노동자 | 사업장 안전 담당자(`admin`), 번역 검수 운영자(`operator`) |
| 기기·환경 | 개인 스마트폰. 공장 안, 인터넷이 약함, 장갑, 소음 | 사무실 PC. 인터넷 있음 |
| 목적 | 내 언어 음성으로 듣고, 글 없이 그림으로 이해를 확인받는다 | 교육을 만들고, 번역을 검수하고, 결과를 보고, 증빙을 낸다 |
| 화면 색 | 코랄 | 보라 |
| 외부 요청 | **0건** (확정, C06 D-002) — AI를 부르지 않는다 | AI 호출 허용 (해커톤, `/api/*` 경유 — D-005 후보) |
| 지금 코드 | `src/worker/` 6개 화면 | `src/admin/` 5개 화면 |
| 두 앱이 만나는 곳 | **데이터뿐이다.** 관리자앱이 `Store`에 쓴 검수 문구·교육을 작업자앱이 읽는다. 작업자앱이 쓴 진도·신고를 관리자앱이 읽는다 | |

**공통 (두 앱 모두)**: 계정·로그인·역할 분기(`index.html`, `signup.html`), 6개 언어·접근성·오프라인.

```
 [관리자앱]                          [ Store (데이터 10칸) ]                     [작업자앱]
 AD-01 사업장 등록  ─── setup ───►                              ◄─── setup ─── WK-01~06
 AD-02 문구 검수    ─── library ─►                              ──► library ─► WK-01 홈, WK-02 수강
 AD-03 AI 에이전트  ─── library(waiting만) ─►
 AD-04 교육 만들기  ─── courses ─►                              ──► courses ─► WK-02 수강, WK-03 검증
 AD-05 대시보드     ◄── progress · reports ──                  ◄── progress ── WK-02, WK-03
                    ─── orders ──►                              ──► orders ──► WK-01 홈
 AD-06 증빙         ◄── progress (읽기만)                       ◄── reports ── WK-04 신고
                                                                ◄─► posts ───► WK-05 소통
```

## 3. 상세 기능 정의 (사이드별)

### 3.1 작업자앱 (LMS 서비스앱)

| 기능 | 상세 기능 | 상태 |
|---|---|---|
| **WK-01 홈** | ① 오늘의 안전 문구 (검수 완료만, 음성, 좌우 넘기기) ② 수강→검증→완료 3단계 진행 표시 ③ 큰 메뉴 4개 + 남은 교육 수 배지 ④ 담당자 재교육 지시 표시 ⑤ 오역 신고 접수 | ①~④ ✅ · ⑤ ⬜ (서버) |
| **WK-02 교육 수강** | ① 내 공정 교육 목록 ② QR로 들어오면 그 교육 바로 열기 ③ 문구 한 장씩 내 언어 음성·픽토그램 ④ 내 언어 기준 검수 판정(`phraseOk`), 0개면 진행 막기 ⑤ 번역 없으면 한국어 + "번역 준비 중" ⑥ 음성 없으면 이유를 내 언어로 표시 ⑦ 다 들으면 `learnedAt` 기록 → 검증으로 | 전부 ✅ |
| **WK-03 이해도 검증** | ① 문항 3유형 — hotspot(위험 지점 짚기)·choice(올바른 작업 고르기)·match(작업↔보호구 잇기) ② 문항 음성 ③ 내 언어 문항(`qtext`) ④ 한 문항 한 번만 ⑤ 답한 직후 사고 결과 설명 ⑥ 전 문항 정답이어야 통과 ⑦ 미통과 화면에 "교육의 실패" ⑧ 다시 풀기는 처음부터, 최초 통과 여부 보존 | 전부 ✅ |
| **WK-04 위험요소 신고** | ① 설비 그림 선택 ② 위험유형 픽토그램 선택 ③ 메모(선택)·음성 받아쓰기 ④ 익명 접수 번호 ⑤ 사진 첨부 ⑥ 조치 결과 회신 | ①~④ ✅ · ⑤⑥ ⬜ (서버) |
| **WK-05 현장 소통** | ① 글·댓글 ② 이름 감추기(작성자 저장 안 함) ③ 내 글 수정·삭제 ④ 담당자 답글 "공식 답변" 표시 ⑤ 댓글 수정·삭제 ⑥ 글 번역 | ①~④ ✅ · ⑤⑥ ⬜ |
| **WK-06 마이페이지** | ① 수강·검증 이력 (미이수·미통과 숨기지 않음) ② 개인 증빙 보기 ③ 문항별 복기 (그림 먼저) ④ 내 언어 바꾸기 ⑤ 글자 크기 ⑥ 음성 대체 설정 | 전부 ✅ |

### 3.2 관리자앱 (어드민)

| 기능 | 상세 기능 | 상태 |
|---|---|---|
| **AD-01 사업장 등록** | ① 사업장 이름·규모 ② 사용 언어 등록 (등록 안 한 언어는 어디에도 안 나옴) ③ 공정 → 설비 (공정 없으면 설비 잠금) ④ 노동자 (사업장 내 식별번호, 외국인등록번호 없음) ⑤ 데이터 내보내기·불러오기(JSON) | 전부 ✅ |
| **AD-02 문구 라이브러리·검수** | ① 문구 목록·분류 ② 언어별 판정 승인·대기·중지 ③ 번역·역번역 대조 (낱말 차이, 부정 뒤집힘 표시) ④ 새 문구는 항상 대기 ⑤ 오역 신고 즉시 그 언어 중지 ⑥ 승인에는 번역 1개 이상 필요 ⑦ 음성 검수 | ①~⑥ ✅ · ⑦ ⬜ |
| **AD-03 AI 번역·검수 에이전트** | ① 한국어 문구 → 5개 언어 번역 초안 ② 역번역 ③ 규칙 대조(`negationFlipped` 등) ④ 뒤집힘이면 재시도 (상한) ⑤ 못 풀면 "사람에게 올림" ⑥ 결과는 항상 `waiting` ⑦ AI 실패 시 손 입력 칸 유지 ⑧ 호출 횟수·시간 상한 ⑨ 진행 단계 표시 ⑩ 경계 테스트 (가짜 응답) | 전부 🔶 |
| **AD-04 교육 만들기·발급** | ① 설비 → 언어 → 문구 → 문항 → 승인 마법사 ② 검수 완료 문구만 선택지 ③ 번역 없는 문구 승인 전 경고 ④ 문항 3유형 작성 + 번역·역번역 ⑤ 이수 기한 ⑥ 설비 앞 QR ⑦ 발급 후 문항 내리기·새로 붙이기 (순서·정답 변경 금지) | 전부 ✅ |
| **AD-05 대시보드·재교육 지시** | ① 언어×위험유형 정답률 (가장 크게) ② 취약 항목 ③ 이수율·최초 통과율 (작게) ④ 기한 D-day ⑤ 신고 처리 상태 ⑥ 기간 걸러 보기 ⑦ 재교육 지시 ⑧ 필수 문장 3개 (평가 아님·교육의 실패·내보내기 없음) ⑨ 기한 알림 | ①~⑧ ✅ · ⑨ ⬜ |
| **AD-06 교육 증빙** | ① 교육 1건 증빙 ② 분기·연도 묶음 ③ 대상자 전원 포함 (거르기·정렬 없음) ④ 범위 밖 교육 건수 표기 ⑤ 제공 언어 표기 ⑥ 인쇄(`window.print`) ⑦ 저장하지 않고 진도 기록을 그대로 읽음 ⑧ 위조 검증 해시 | ①~⑦ ✅ · ⑧ ⬜ |

## 4. 범위 밖 (이번 해커톤에서 만들지 않는다)

| 항목 | 이유 | 언제 |
|---|---|---|
| 기기 간 데이터 공유, 진짜 로그인, DB | 서버·DB 필요. 해커톤은 AI 호출만 서버리스로 (A01 질문 1) | 판매 단계 (S01 §9) |
| 사진·음성 첨부, 기한 알림, 증빙 해시 | 서버 필요 | 판매 단계 |
| 문항 출제 에이전트(B), 현장 신호 에이전트(C) | 하나를 깊게 (D-007 제안) | 로드맵 |
| 인사평가용 내보내기, 개인 순위, 신고자 조회 | **만들지 않는다** (P-3·P-5) | 없음 |
