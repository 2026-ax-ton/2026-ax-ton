## 1. 문제와 목표

- **문제**: 글을 못 읽고, 장갑을 끼고, 시끄럽고, 인터넷이 약한 곳에서 쓴다.
- **목표**: 6개 언어로 화면과 음성이 나오고, 손가락으로 누르기 쉽고, 끊겨도 열린다.

## 2. 사용자와 상황

- 크메르어·인도네시아어·베트남어·네팔어·태국어·한국어 사용 노동자. 저사양 안드로이드 (아이디어톤 PRD: Android 9 이상 — 가정).

## 3. 사용자 스토리

- US-23 노동자는 내 언어로 화면을 쓰기 위하여 언어를 바꾸고 글자 크기를 조절한다.
- US-24 노동자는 인터넷이 약한 현장에서도 교육을 이어가기 위하여 오프라인에서 화면을 연다.

## 4. 기능 요구사항

| ID | 요구 | 상태 | 근거 |
|---|---|---|---|
| FR-CM-02-01 | 화면 안내 글자를 6개 언어로 보여 준다 | ✅ | `i18n.js` |
| FR-CM-02-02 | 음성 합성으로 읽어 준다. 그 언어 음성이 없으면 소리를 내지 않고 이유를 그 사람 언어로 적는다. 소리가 안 나면 🔊→🔇 | ✅ | P-9 |
| FR-CM-02-03 | 모든 배지는 아이콘 + 글자 + 색 3중 (색만으로 구분하지 않음) | ✅ | `icons.js` |
| FR-CM-02-04 | 터치 대상 최소 60px | ✅ | `--tap-min` |

## 5. 화면 흐름

- 해당 없음 (모든 작업자앱 화면에 걸친 조건).
