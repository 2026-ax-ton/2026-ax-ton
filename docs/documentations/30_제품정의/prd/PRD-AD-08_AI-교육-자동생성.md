## 1. 문제와 목표

- **문제**
  - AD-07 까지 가도 담당자가 할 일이 많다 — 무엇이 위험한지 **스스로 알고 있어야** 사진을 찍고 문항을 만든다. 겸직 담당자는 설비 설명서를 읽을 시간이 없고, **놓친 위험은 교육에도 빠진다.**
  - 지금 교육 자료는 문구 + 도해 3종이다. 우리 공장 설비의 실제 모습과 동작을 보여 주는 **영상이 없다.** 글을 못 읽는 노동자에게 가장 잘 전달되는 형식이 빠져 있다.
- **목표**: 담당자는 **기계 정보(종류·제조사·모델명)와 사진**만 넣는다. AI가 공개 자료로 주의사항을 목록으로 만들고, 사진 위에 위험 부위를 찍고, 영상과 퀴즈 초안을 만든다. 담당자는 AI가 「확인 필요」로 표시한 것만 보고 **[승인·발급] 한 번**을 누른다.
- **넘지 않는 것**: AI는 끝까지 **제안**만 한다. 노동자에게 가는 것은 사람이 승인한 것뿐이다 (D-027 ①, FR-AD-03-06).

| 성공 지표 | 정의 | 목표값 | 측정 |
|---|---|---|---|
| 담당자 손 | 기계 정보 입력부터 발급까지 담당자가 누른 횟수(입력 칸 제외) | `미정` — 「확인 필요」가 0건이면 **1회** (제안) | 시연 전 기계 2종으로 잰다 |
| 놓친 위험 | 사람(안전 담당·KOSHA 자료)이 꼽은 위험 중 AI 목록에 없는 것 | 측정 후 정한다 | 기계 2종 × 사람 목록 대조 |
| 근거 없는 항목 | 출처 URL 이 없는데 노동자 교육에 들어간 항목 수 | **0건** (제안) | 경계 테스트 |
| 경계 위반 | 승인 전 `courses` 저장 · AI가 쓴 문장이 안전 문구로 노동자에게 감 | **0건** (AD-03·AD-07 과 같은 기준) | 경계 테스트 |
| 좌표 품질 | AI 박스와 사람이 그린 정답 박스의 IoU 평균 | 측정 후 정한다 | 주피터 노트북 (§6.3) |

## 2. 사용자와 상황

- 40인 공장 생산팀장, 안전 업무 겸직 담당자 (아이디어톤 PRD 페르소나 C — **가정, VOC로 확인 안 됨**).
- 새 설비가 들어오거나 교육을 새로 만들 때, **사무실 PC에서 기계 정보를 넣고 설비 앞에서 폰으로 사진을 찍는다** (AD-07 §11 Q3 결정과 같다).
- 노동자는 이 기능을 직접 쓰지 않는다. 노동자가 받는 것은 **승인된 교육(영상·퀴즈)** 뿐이고, 보내는 것은 답과 결과뿐이다 — 지금 동기화(`Store.sync`, D-032) 그대로다.

## 3. 사용자 스토리

> D04 백로그 등록 전이라 `US-` 번호가 없다.

- 담당자는 설비 설명서를 다 읽지 않아도 되도록, 기계 정보를 넣으면 **출처가 붙은 주의사항 목록**을 받는다.
- 담당자는 위험한 곳을 놓치지 않도록, AI가 **어떤 사진이 더 필요한지** 알려 주는 것을 받는다.
- 담당자는 틀린 내용이 노동자에게 가지 않도록, AI가 **확실하지 않다고 표시한 것만** 골라서 본다.
- 담당자는 영상을 직접 만들 줄 몰라도, 확정한 위험 부위로 만든 **안전교육 영상과 퀴즈 초안**을 받는다.
- 담당자는 AI가 안 될 때도 교육을 만들 수 있도록, 지금의 손 흐름(AD-04)으로 그대로 진행한다.

## 7. 비기능 · 넘지 않는 선

**AI 를 어떻게 「학습」시키나** — 파인튜닝이 아니다. 아래 넷을 서버 코드 한 곳(`api/_research.mjs` 등 상수)에 고정한다. 지금 `api/_hazards.mjs` 와 같은 방식이다.

1. **고정 시스템 지시문** — 역할, 출처 우선순위, 추측 금지, 안전 지시 문장 쓰기 금지
2. **출력 형식 강제** — JSON 스키마. 모양이 틀리면 버린다
3. **근거 강제** — 검색 근거 메타데이터에 있는 URL 만 출처로 인정한다
4. **서버 거르기** — 6종 · 상한 · 좌표 범위 · 출처 없음 · 충돌을 코드로 거른다 (모델을 믿지 않는다)

**출처 등급** — 1 제조사 설명서 > 2 KOSHA GUIDE · 법령 > 3 일반 웹 > 4 YouTube. 등급이 낮은 출처만 있는 항목은 「확인 필요」로 둔다.

**그 밖에**
- **AI 는 제안만 한다.** 확정·승인은 사람이 한다. 사람 손은 「확인 필요」 검토 + 마지막 1클릭으로 줄인다 (D-027 ① · 🆕 D-035)
- **문구는 검수된 라이브러리에서만** (P-1). AI 영상 안에 글자를 넣지 않는다
- **노동자 화면: 제3자 주소 0건 · 우리 서버만** (C05 T-1″ · D-032). 영상도 우리 주소로 내보낸다
- **사진에 사람이 찍히면 버린다.** 실제 노동자가 찍힌 사진으로 시연하지 않는다
- **처리방침**: 기계 정보·사진을 Google 로 보낸다는 것과 영상·사진 보존을 A05 에 더해야 한다
- 관리자 화면 공통 규칙(아이콘 + 글자 + 색, `innerHTML` 금지)
- 키는 서버 환경변수에만. 제출본은 해커톤 임시 키만 (D-034)

| 시연 | 어떻게 |
|---|---|
| 영상 시연 (녹화) | 배포 서버 그대로. 같은 기계 교육 A(지금 생성 시작, 진행 표시) → 교육 B(미리 생성·승인) → 노동자 폰에서 B 수강·퀴즈. 서버는 하나, 교육만 두 건 |
