## 1. 문제와 목표

- **문제**: 세 종류 사용자가 서로 다른 앱을 써야 한다. 서버가 없어 진짜 인증이 불가능하다.
- **목표**: 로그인 한 번으로 역할에 맞는 앱 첫 화면으로 간다. 진짜가 아닌 인증은 진짜인 척하지 않는다.

## 2. 사용자와 상황

- 노동자는 QR로 처음 들어올 때 로그인을 만난다. 그때 어느 설비를 찍었는지 잃으면 안 된다.

## 3. 사용자 스토리

- (공용) 사용자는 내 앱으로 가기 위하여 가입·로그인한다. 노동자는 등록된 언어·공정만 고른다.

## 5. 화면 흐름

```
 [로그인] ─► 역할 판정 ─┬─ worker   ─► 작업자앱 홈 (또는 ?next= 교육)
                       ├─ admin    ─► 관리자앱 대시보드
                       └─ operator ─► 관리자앱 문구 라이브러리
 [회원가입] ─► 역할 · (노동자) 언어 · 공정 ─► 로그인 상태로 첫 화면
```
