## 1. 문제와 목표

- **문제**: 지금 안전교육의 완료 기준은 출석부 서명이다. 서명은 참석의 증거이지 이해의 증거가 아니다.
- **목표**: 교육 완료 기준을 "이해했는가"로 옮긴다. 통과하지 못하면 교육 완료로 기록되지 않는다.

| 성공 지표 | 목표값 | 측정 |
|---|---|---|
| 문항 최초 통과율 | 70~85% (100%면 문항이 너무 쉬운 것) | 화면이 계산한다. **실측 없음** (예시 데이터 50%) — 🔷 아이디어톤 PRD 가정 |
| 재교육 후 통과율 | 95% 이상 | 실측 없음 |
| 글자를 읽지 않고 끝까지 완주 | 사용성 시험 통과 | **미수행** (HC-2, TK-1-03·04) |

## 2. 사용자와 상황

- 입국 3개월, 크메르어 사용, 프레스 공정 노동자 (아이디어톤 PRD 페르소나 A — **가정, VOC로 확인 안 됨**).
- 공장 안, 장갑, 소음. 개인 스마트폰. 모른다고 말하면 불이익이 있을까 걱정해 묻지 않는다.

## 3. 사용자 스토리

- US-14 노동자는 글을 읽지 않고 이해를 보이기 위하여 그림 문제를 손가락으로 푼다.
- US-15 노동자는 틀린 이유를 배우기 위하여 답한 직후 어떤 사고가 되는지를 본다.
- US-16 노동자는 미통과 시에도 낙인 없이 다시 배우기 위하여 "교육의 실패" 안내와 문항별 복기를 본다.

## 5. 화면 흐름

```
 수강 완료(WK-02) ─► [문항 n/총] 그림 + 음성 자동 재생
     │ 손가락으로 답 (hotspot 터치 / 선택지 3개 / 짝 잇기)
     ▼
 [즉시 결과] ✓ 또는 ✕ + "이대로 하면 생기는 사고" 그림·음성 ─► 다음 문항
     ▼ (마지막 문항 뒤)
 [통과] 완료 표시 ─► 홈
 [미통과] "교육의 실패" 안내 + 다시 배우기(WK-02) / 문항별 복기(WK-06)
```

## 7. 비기능·넘지 않는 선

- P-6 미통과는 교육의 실패. P-5 점수를 인사평가용으로 내보내지 않는다.
- `answer`는 `options`의 인덱스다. 번역 배열 길이가 다르면 정답이 다른 선택지를 가리킨다 — 검사는 `qtext` 한 곳에만 둔다.
- 터치 60px, 아이콘+글자+색, 오프라인에서도 열린다(CM-02). 외부 요청 0건.
