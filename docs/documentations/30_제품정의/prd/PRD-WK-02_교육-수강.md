## 1. 문제와 목표

- **문제**: 한국어 교육은 내용이 전달되지 않는다. 번역이 틀리면 오역이 그대로 사고가 된다.
- **목표**: 검수된 안전 문구만, 내 언어 음성과 픽토그램으로 한 장씩 듣는다. 못 받은 것은 화면에 남긴다.

## 2. 사용자와 상황

- 설비 앞 QR을 찍거나 홈에서 들어온다. 크메르어 음성이 없는 폰도 많다.

## 3. 사용자 스토리

- US-12 노동자는 내 언어로 이해하기 위하여 안전 문구를 음성과 함께 한 장씩 본다.
- US-13 노동자는 음성이 안 날 때도 상황을 알기 위하여 이유를 내 언어 화면으로 확인한다.

## 4. 기능 요구사항

| ID | 요구 | 상태 | 근거 |
|---|---|---|---|
| FR-WK-02-01 | 내 공정 설비의 교육 목록을 보여 준다 | ✅ | `learn.js` |
| FR-WK-02-02 | QR(`?course=`)로 들어오면 그 교육을 바로 연다. 로그인 전이면 로그인 뒤 이어서 연다 | ✅ | CM-01 |
| FR-WK-02-03 | 문구를 **내 언어 기준**으로 검수 판정한다 (`Store.phraseOk`). 다른 언어의 오역으로 내 지시가 사라지지 않는다 | ✅ | P-1 |
| FR-WK-02-04 | 걸러 낸 문구가 0개면 진행을 막는다 | ✅ | `learn.js` |
| FR-WK-02-05 | 내 언어 번역이 없으면 숨기지 않고 한국어 원문 + "번역 준비 중"을 띄운다 | ✅ | 同 |
| FR-WK-02-06 | 내 언어 음성이 없으면 소리를 내지 않고 이유를 내 언어로 적는다 (한국어로 대신 읽지 않음) | ✅ | P-9 |
| FR-WK-02-07 | 다 들으면 `progress.learnedAt`을 남기고 이해도 검증(WK-03)으로 보낸다 | ✅ | 同 |
| FR-WK-02-08 | 검수된 녹음 음성을 쓴다 | ⬜ | 음성도 검수 상태가 필요 (09-handover §6.1) |
| FR-WK-02-09 | 진행 점(n/총)과 [이전]·[다음] 버튼을 둔다. 첫 장에서 [이전]은 비활성 | ✅ | `learn.js` `step-dots`·`btn-prev` (2회차 시안에서 발견) |
| FR-WK-02-10 | 번역 없음과 음성 없음이 겹치면 "번역 준비 중"을 먼저, 음성 안내를 그 아래에 둔다 | ✅ (2026-11-01) | H8, `learn.js` renderStep |

## 5. 화면 흐름

```
 [교육 목록] 또는 QR 직행 ─► [문구 1/n] 픽토그램 + 내 언어 글 + 🔊 자동 재생 (음성 없으면 🔇 + 이유)
 ─► ▶ 다음 … ─► [다 들음] ─► 이해도 검증(WK-03)
```
