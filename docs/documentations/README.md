## 제출 절차 (마감 직전 1회)

1. 빈 칸이 0개인지 확인한다 (`미정`이 남았으면 담당자·기한을 확인)
2. 양식 hwp를 열고 **가이드라인 페이지를 삭제**한다
3. md 내용을 표에 옮긴다 — **목차는 수정하지 않는다.** 해당 없는 절은 "해당 없음"으로 적는다
4. 공통 형식: 맑은고딕 · 제목1 20pt · 제목2 14pt · 제목3 12pt · 제목4 11pt · 본문 10pt · 줄간격 150%(D05·D06은 130%) · 페이지 번호 필수
5. 문서번호 `20__-TeamName-Doc-0__` 부여
