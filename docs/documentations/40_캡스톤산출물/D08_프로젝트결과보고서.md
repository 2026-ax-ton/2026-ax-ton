## 시스템 설명

SAFE-LANG은 한국어를 잘 모르는 외국인 노동자가 안전교육을 **이해했는지 확인**하는 웹 서비스이다.
노동자는 설비 QR로 접속해 자기 언어(6개)의 음성으로 교육을 듣고, 글자 없이 그림을 눌러 이해도 문항에 답한다. 통과해야 교육이 끝난 것으로 기록된다.
담당자는 검수가 끝난 안전 문구만 교육에 쓰고, 이수·미이수 전원이 담긴 증빙을 만든다. 통과하지 못한 결과는 노동자의 잘못이 아니라 교육의 실패로 다룬다.
해커톤 버전은 **AI 번역·검수 에이전트**와 **실제 DB·로그인**을 더했다. 노동자 폰에서 푼 결과가 서버를 거쳐 담당자 PC에 나타난다. 에이전트가 번역 → 역번역 → 대조 → 재시도 → 사람에게 올림을 수행하고, 사람이 승인한 번역만 노동자에게 나간다.

## 시스템 운영 환경

- 사용자 기기: 스마트폰·PC 브라우저 (안드로이드 확인, iOS `미확인`)
- 화면: 정적 웹앱 (빌드 없음) · 크롬 더블클릭(`file://`)으로도 실행
- 데이터: **Neon Postgres** (싱가포르) — `Store` 모듈의 서버 모드, 기기에는 캐시 · `file://`이면 브라우저 `localStorage`만 (로컬 모드)
- 서버: Vercel 서버리스 함수 (`/api/auth/*`·`/api/store`·`/api/reports`·`/api/translate`·`/api/backtranslate`)
- 외부 서비스: Google Gemini API (번역·역번역) · 브라우저 내장 음성 합성·받아쓰기
- 오프라인: Service Worker (노동자 화면은 외부 요청 0건)

## 개발 적용 기술

| 영역 | 기술 |
|---|---|
| 화면 | HTML · CSS · 순수 JavaScript (전역 IIFE, ES 모듈·프레임워크·빌드 없음, 의존성 0) |
| AI 에이전트 | 브라우저 지휘 루프(`agent.js`) · 도구 3개(번역·역번역·규칙 대조) · 재시도 상한 · 사람에게 올림 · 결과 `waiting` 고정 |
| AI 모델 | Google Gemini `generateContent` — 번역과 역번역을 **다른 모델**로, 역번역에는 원문을 주지 않음 |
| 서버·DB | Vercel Functions (Node) · **Neon Postgres** · 진짜 로그인(scrypt·토큰·잠금) · 사업장 분리 권한 검사 · 익명 신고 별도 저장 · 출처 검사·일일 상한 |

| 다국어·음성 | 6개 언어 화면 사전(126키), Web Speech API, 음성 없음 감지 |
| 데이터 | `localStorage` 10칸 · 언어별 검수 판정(`phraseOk`) · 판정 기록(`judged`) |
| 오프라인·QR | Service Worker · 자체 QR 인코더 |
| 품질 | Node + jsdom 자체 하네스 1,619건(+ 에이전트 경계·API 테스트) · GitHub Actions |
| 협업·배포 | GitHub (`main` ← `develop` ← `feat/agent-*`, PR) · Vercel 자동 배포 |

## 시스템 활용 효과

> 규칙: 항목마다 「무엇이 좋아졌는가 + 실측 수치 + 그 수치를 잰 근거」를 함께 적는다. **잰 적이 없는 수치는 쓰지 않는다.**
> ⚠️ 아래 ⬜ 칸은 **11/16 기능 동결 뒤 실측**해 채운다.

**1) 이해 확인 방식의 전환 — 서명에서 통과로**
- 출석부 서명 대신 그림 문항 통과가 교육 완료의 기준이 된다. 글을 읽지 않고 끝까지 쓸 수 있게 설계했다.
- 실측: ⬜ 인터뷰·MVP 테스트 결과 (목표 인터뷰 3명+, 테스트 3회+ — [S07](../10_사업화/S07_검증-계획.md))

**2) 검수 안 된 안전 문구의 차단 — 테스트로 지킨다**

| 구분 | 값 |
|---|---|
| 자동 테스트 | 1,619건 실행 · 실패 0 (2026-10-31, [D07 §6.1](D07_시험결과서.md)) |
| 기능 요구(PRD FR) 구현 | 136개 중 약 91개 (약 67%, 2026-10-31) → 해커톤 목표 약 88% |
| 에이전트 경계 | ⬜ 19건 (D07 §3.2 9)) — AI가 `reviewed`를 보내도 `waiting` 저장 등 |

**3) AI 번역·검수 에이전트 — 사람의 일을 "판정"으로 줄인다**
- 지금은 운영자가 번역문과 역번역을 손으로 입력한다. 에이전트는 이를 5개 언어에 대해 자동으로 하고, 뜻이 뒤집힌 곳만 사람에게 올린다.
- 실측: ⬜ 문구 10개 × 5개 언어의 처리 시간·재시도율·올림 비율 (TK-2-11, 11/8) · 비용은 문구 100개당 약 1.1~3.3달러 (계산값, S02 N-65)

**4) 🆕 실제 서버·DB — 여러 기기가 함께 쓴다**
- 노동자 폰에서 푼 결과가 담당자 PC 대시보드에 나타난다. 데이터가 브라우저 삭제로 사라지지 않는다.
- 실측: ⬜ 두 기기 반영 시간, 서버 실패 시 기록 유실 0건 (STC-E25-010·013, 11/13)
