# D05 · N차 스프린트 백로그 (개발 태스크 목록)

> 양식: `2025-개정-D05-N차_스프린트백로그(태스크목록).hwp`
> **문서 상태** 초안 v0.1 (프로토타입) · **최종 수정** 2026-10-10
> 스프린트 날짜·범위는 모두 **제안**이다. 해커톤 공지 후 확정한다. 후보 스토리는 🔶 로 표시했다.

## ⚠️ 2차 이후 스프린트의 규칙 (양식 지시)

- 차수마다 §1~§5 한 벌을 **새로 쓴다.** 이전 차수의 절은 지우지 않는다.
- 이전 차수의 태스크가 바뀌면 **「이전 차수 변경 태스크」 표**에 따로 적는다.
- 태스크 ID는 `TK-<차수>-<번호>` 로 매긴다 — 차수마다 1번부터 다시 매기면
  「원 TK_ID」가 어느 차수 것인지 알 수 없다.

## 스프린트 구분

| 차수 | 기간 | 주제 | 근거 |
|---|---|---|---|
| 1차 | 2026-10-12 ~ 2026-10-25 | **방향 확정과 현장 검증** — 문서 체계, 실사용 시험, 수익·수치 검증, 테스트 이식성, 서버 도입 판단 | 주제·평가표 공지 전에는 에이전트 코드를 쓰지 않는다 (C06 D-003). 사람이 해야 하는 검증이 비어 있다 |
| 2차 | 2026-10-26 ~ 2026-11-08 | **AI 기반 + 에이전트 1개 핵심** (후보: A 번역·검수) + 경계 검사 | 공지 후 G0 통과가 전제 (**후보**) |
| 3차 | 2026-11-09 ~ 2026-11-22 | **안정화·시연·발표 준비** (여유 시 B 또는 C 일부) | 오프라인 해커톤(11월 말) 직전 동결 (**후보**) |
