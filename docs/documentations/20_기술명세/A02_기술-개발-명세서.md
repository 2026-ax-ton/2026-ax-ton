- 두 안 모두 **API 계약(§5.3·5.4)은 같다.** 함수 본문을 먼저 만들고 위치만 나중에 옮긴다.
- 파일 형식: Web Handler + `.mjs` (Vercel 문서: 프레임워크 없는 프로젝트는 `"type": "module"` 또는 `.mjs`). `.mjs`면 `package.json`이 필요 없다.

### 5.2 공통 규칙

| 항목 | 값 |
|---|---|
| 메서드 | `POST` (+ 사전 요청 `OPTIONS`). 그 밖은 405 |
| 요청 헤더 | `Content-Type: application/json` · `X-Agent-Pass: <운영자 통과 문구>` (§5.6) |
| 출처 검사 | 요청의 `Origin`이 배포 주소(`ALLOWED_ORIGIN`) **또는 이 배포 자신의 주소(`https://${VERCEL_URL}`, Vercel이 넣어 준다)** 와 같으면 통과. 미리보기 주소는 배포마다 바뀌어서 손으로 적은 값 하나로는 맞출 수 없다 — 자기 자신을 허용하는 것은 「같은 출처」의 정의 그대로다 (2026-10-31 구현). **시연 기간에만** `ALLOW_FILE_ORIGIN=1`이면 `Origin: null`(제출 HTML을 `file://`로 연 경우)도 통과. 그 밖은 403 |
| CORS | 배포 주소에서 부르면 같은 출처라 CORS 헤더를 내지 않는다. `null` 출처를 통과시킬 때만 `Access-Control-Allow-Origin: null` · `Access-Control-Allow-Headers: Content-Type, X-Agent-Pass` · `Access-Control-Allow-Methods: POST, OPTIONS` · `Vary: Origin`을 붙인다 |
| 사전 요청 | `OPTIONS`는 출처 검사를 통과하면 204 + 위 CORS 헤더, 아니면 403. 모델을 부르지 않고 일일 상한에 세지 않는다 |
| 본문 상한 | 4KB 초과 → 413 (Vercel 자체 상한은 4.5MB, N-60) |
| 시간 | 함수 `maxDuration` 30초 (`export const config = { maxDuration: 30 }`), 모델 호출 타임아웃 20초 (`AbortController`) |
| 응답 | `application/json; charset=utf-8`, `Cache-Control: no-store` |
| 오류 형식 | `{ "error": "<code>", "message": "<한국어 설명>" }` |
| 로그 | 한 줄 JSON: `{route, lang, attempt, ms, status, err}`. **문구 원문·키·IP를 남기지 않는다** |
| 금지 | 응답에 `status`(승인 상태) 필드를 넣지 않는다. 승인은 사람만 한다 (FR-AD-03-06) |

> **왜 `null` 출처인가** — 해커톤 현장 시연은 제출한 HTML 파일을 운영 PC 크롬에서 더블클릭해 연다([C08 §7](../00_개발컨벤션/C08_해커톤-규정과-대응.md)). 이때 브라우저는 `Origin: null`을 보낸다. 다른 로컬 파일도 같은 값을 보내므로 막는 힘이 약하다 → **제출~11/28 시연 기간에만 켜고 바로 끈다.** 남은 방어는 통과 문구(§5.6 2층)·일일 상한(3층)·공급사 예산(4층)이다. ❓ 제출 HTML이 외부 API를 부르는 것이 규정상 되는지 운영진 답변 대기 (C08 §8)

**오류 코드**

| HTTP | `error` | 언제 | 화면 동작 |
|---|---|---|---|
| 400 | `bad_request` | JSON 아님, 필드 누락, 언어 코드 허용 목록 밖, 길이 초과 | 손 입력 칸 |
| 401 | `pass_required` | `X-Agent-Pass` 없음·틀림 | "운영자 통과 문구를 입력하세요" |
| 403 | `origin` | 다른 출처 | 손 입력 칸 |
| 405 | `method` | POST 아님 | — |
| 413 | `too_large` | 본문 4KB 초과 | 손 입력 칸 |
| 429 | `limit` | 일일 상한 초과 | "오늘 AI 사용 한도를 넘었습니다" + 손 입력 칸 |
| 500 | `config` | 키·모델 환경변수 없음 (키 값은 출력하지 않음) | 손 입력 칸 |
| 502 | `model` | 모델 오류, 빈 출력, 출력 길이 초과 | 손 입력 칸 |
| 504 | `timeout` | 모델 20초 초과 | 손 입력 칸 |

### 5.3 `POST /api/translate`

**요청**
```json
{ "ko": "회전 중인 롤러에 손을 넣지 마세요.", "lang": "km", "attempt": 0, "hint": "" }
```
| 필드 | 타입 | 규칙 |
|---|---|---|
| `ko` | string | 1~300자, 앞뒤 공백 제거 |
| `lang` | string | `km` · `id` · `vi` · `ne` · `th` 중 하나 (`ko` 제외) |
| `attempt` | integer | 0~2. 0 = 첫 시도 |
| `hint` | string | 선택. 재시도일 때 앞 역번역(최대 600자). 예: 부정이 사라진 역번역 문장 |

**응답 200**
```json
{ "text": "<크메르어 번역문>", "model": "gemini-3.1-flash-lite", "attempt": 0 }
```

**모델 호출 (서버 → Gemini API `generateContent`)**
```http
POST https://generativelanguage.googleapis.com/v1beta/models/${AI_MODEL_TRANSLATE}:generateContent
x-goog-api-key: ${GEMINI_API_KEY}
content-type: application/json
```
```json
{
  "system_instruction": { "parts": [{ "text": "너는 산업안전 지시문 번역가다. 한국어 지시문을 <언어명>으로 번역한다. 규칙: 1) 금지·부정(하지 마세요, 금지, 안 됩니다)을 반드시 보존한다. 2) 기계·부위 이름은 현장 노동자가 쓰는 쉬운 말로 쓴다. 3) 설명·따옴표·로마자 표기 없이 번역문 한 문장만 출력한다." }] },
  "contents": [{ "role": "user", "parts": [{ "text": "<ko>" }] }],
  "generationConfig": { "maxOutputTokens": 600, "thinkingConfig": { "thinkingLevel": "low" } }
}
```
- 키는 URL 쿼리(`?key=`)가 아니라 **`x-goog-api-key` 헤더**로 보낸다. URL은 로그에 남기 쉽다.
- `temperature`를 보내지 않는다. Gemini 3.6 이후·4 모델은 `temperature`·`top_p`·`top_k`를 무시하고 경고를 내며, 이후 400 오류로 바뀐다고 공지돼 있다. 이전 Gemini 3 모델도 기본값 유지가 권장이다.
- `thinkingLevel: "low"` — 생각 토큰도 출력 요금이 붙고 지연이 늘어난다. 모델마다 지원 값이 다르므로 키 발급 후 실제 호출로 확인한다.
- `attempt > 0`이면 `system_instruction` 끝에 "앞 번역을 한국어로 되돌렸더니 '<hint>'가 되어 뜻이 바뀌었다. 부정과 금지를 다시 확인하라."를 붙인다.
- 응답에서 `candidates[0].content.parts[0].text`만 읽는다. 후보가 없거나(`promptFeedback.blockReason` 있음) 앞뒤 공백 제거 후 1~600자가 아니면 502.
- 같은 엔드포인트 대신 Google이 새 개발에 권하는 **Interactions API**(`POST …/v1beta2/interactions`)도 있다. `generateContent`는 "계속 완전 지원"이고 중단 일정 공지는 없다(2026-10-23 확인). 한 번 묻고 한 번 답하는 상태 없는 호출이라 `generateContent`를 쓴다 — **후보**, 멘토링 결정 9.
- 언어명은 서버의 고정 표(`km`→"크메르어" 등)에서 가져온다. 요청값을 프롬프트에 그대로 넣지 않는다.

### 5.4 `POST /api/backtranslate`

**요청** `{ "text": "<번역문>", "lang": "km" }` — `text` 1~600자
**응답 200** `{ "back": "<한국어 역번역>", "model": "<모델 ID>" }`

**모델 호출** — 형식은 §5.3과 같다. 차이:
- 모델: `${AI_MODEL_BACK}` — **번역과 다른 모델 또는 다른 프롬프트** (같은 오류를 같이 놓치지 않게, A01 질문 3). 후보: `gemini-3.8-flash` (다른 세대 모델) 또는 `gemini-3.1-flash-lite` + 다른 프롬프트 — `미정`(멘토링 결정 5).
- `system_instruction`: "다음 <언어명> 문장을 한국어로 직역한다. 원문을 추측해 고치지 말고 쓰인 그대로 옮긴다. 부정은 부정으로, 긍정은 긍정으로 옮긴다. 한국어 문장 하나만 출력한다."
- 역번역 쪽에는 **원래 한국어 문장을 주지 않는다.** 주면 모델이 원문에 맞춰 "고쳐서" 대조가 무의미해진다.

### 5.5 환경변수

| 이름 | 예 | 범위 | 설명 |
|---|---|---|---|
| `GEMINI_API_KEY` | (비밀, Google AI Studio에서 발급) | Production · Preview 각각 다른 키 | 코드·응답·로그에 절대 없음 (STC-E19-001) |
| `AI_MODEL_TRANSLATE` | `gemini-3.1-flash-lite` | 전체 | 번역 모델 코드 |
| `AI_MODEL_BACK` | `gemini-3.8-flash` | 전체 | 역번역 모델 코드 (`미정`) |
| `AI_TIMEOUT_MS` | `20000` | 전체 | 모델 호출 타임아웃 |
| `AI_DAILY_LIMIT` | `600` | Production 600 · Preview 100 | 하루 호출 상한 (§5.6) |
| `AGENT_PASS` | (비밀) | 전체 | 운영자 통과 문구 (§5.6) |
| `ALLOWED_ORIGIN` | `https://<프로젝트>.vercel.app` | 환경별 | 같은 출처 검사. **Production만 넣으면 된다** — 미리보기는 `VERCEL_URL`로 저절로 맞는다 |
| `VERCEL_URL` | (Vercel이 자동으로 넣는다) | 전체 | 이 배포 자신의 호스트. 손으로 넣지 않는다 |
| `ALLOW_FILE_ORIGIN` | `0` | Production은 시연 기간만 `1` | `file://` 시연의 `Origin: null` 허용 (§5.2) |

- 값 예시는 가정이다. 600회/일 = 문구 20개 × 30회.
- 로컬 확인: `vercel dev` + `.env.local`(저장소에 올리지 않음 — `.gitignore`가 `.env.*`를 막는다).
- **무료 등급 주의**: Gemini 무료 등급에 보낸 내용은 Google 제품 개선에 쓰인다(유료 등급은 쓰이지 않음, N-64). 보내는 것은 안전 문구뿐이라 개인정보는 없지만, **Production은 결제를 연결한 유료 등급 키**를 쓴다. 무료 등급 호출 한도는 키 발급 후 콘솔에서 확인한다.

### 5.6 남용 방지 — `미정` (멘토링 결정 3·4)

지금 로그인은 목업이라 **서버가 운영자를 알아볼 방법이 없다.** 아무나 `/api`를 불러 크레딧을 쓸 수 있다.

| 층 | 방법 | 막는 것 | 한계 |
|---|---|---|---|
| 1 | 같은 출처 검사 (`Origin`) | 다른 사이트에서 부르기 | 직접 만든 요청은 헤더를 속일 수 있다 |
| 2 | `X-Agent-Pass` — 운영자가 처음 한 번 입력, `sessionStorage`에 보관. **★ ASCII만 쓴다** — HTTP 헤더 값은 바이트 문자열이라 한글 문구를 넣으면 브라우저가 요청 자체를 만들지 못한다 (2026-10-31 구현 중 확인) | 문구를 모르는 사람 | 문구가 새면 끝. 정기 교체 |
| 3 | 일일 상한 `AI_DAILY_LIMIT` | 대량 호출 | 함수는 상태가 없다 → 인스턴스 메모리 계산은 근사치. 정확히 하려면 KV 저장소 필요(후보) |
| 4 | Google 콘솔의 결제 예산 알림·할당량 | 최악의 비용 | 설정 방법은 키 발급 후 확인 |

- 제안: H 단계는 1+2+3(근사)+4. S 단계에서 서버 세션 인증으로 2를 대체한다.

## 6. AI 에이전트 (브라우저 `agent.js`) 🔶

### 6.1 상태 기계 (언어마다 따로)
```
idle ─[AI 번역 받기]→ translating → backtranslating → comparing ─┬─ ok ─────────────→ done (waiting 저장)
                                                                 └─ flipped → retry(n<2) → translating
                                                                            └─ n=2 ───→ escalated (waiting + 사람에게 올림)
어느 단계든 오류·시간 초과 → failed → 손 입력 칸 표시 (FR-AD-03-07)
```

### 6.2 알고리즘
```js
// assets/agent.js — IIFE, 전역 Agent. ES 모듈 아님.
async function runLang(phrase, lang, onStep) {
  let hint = '', last = null;
  for (let attempt = 0; attempt <= 2; attempt++) {
    onStep(lang, 'translating', attempt);
    const t = await call('/api/translate', { ko: phrase.ko, lang, attempt, hint }, 25000);
    onStep(lang, 'backtranslating', attempt);
    const b = await call('/api/backtranslate', { text: t.text, lang }, 25000);
    onStep(lang, 'comparing', attempt);
    const c = compare(phrase.ko, b.back);           // Review.negationFlipped + newWordCount
    last = { text: t.text, back: b.back, tries: attempt + 1, flipped: c.flipped, escalated: false, model: t.model };
    if (!c.flipped) return last;
    hint = b.back;
  }
  return { ...last, escalated: true };               // 상한 도달 → 사람에게 올림
}
// run(): 언어끼리는 Promise.allSettled로 병렬, 언어 안에서는 순차.
//         이미 reviewed인 언어는 건너뛴다 (FR-AD-03-15).
```
- 실제 코드는 프로젝트 규칙대로 IIFE·`var` 스타일로 쓴다. 위는 흐름만 보인다.
- `call()`은 `fetch` + `AbortController`(25초). 응답 JSON 모양(`text`·`back`이 문자열)을 검사하고 아니면 throw.
- `navigator.onLine === false`면 [AI 번역 받기]를 비활성 + 이유 표시 (조용히 숨기지 않음).
- `file://`로 열었으면 상대 경로 `/api` 대신 **`API_BASE`(배포 주소, `agent.js` 맨 위 상수)** 로 부른다 — 현장 시연용 (§5.2, C06 D-019). 노동자 화면은 여전히 외부 요청 0건이다.

### 6.3 저장 (데이터 계약 변경)
```js
library[i].translations[code] = {
  text, back,
  status: 'waiting',                        // ★ 응답과 무관하게 코드 상수
  agent: { tries, flipped, escalated, model, at },   // 🔶 신규
  judged: { by: userId, at }                // 🔶 신규 — 사람이 판정할 때만 (AD-02 FR-09)
}
```
- `store.js` 계약 주석부터 고치고, `normalize`가 새 필드를 지우지 않게 한다.
- 화면 표시는 전부 `textContent` (FR-AD-03-11). AI 출력은 신뢰하지 않는 문자열이다.

### 6.4 비용 상한
- 문구 1개 최대 호출 = 언어 5 × 2단계 × 3회 = 30회. 1회 입력 약 500·출력 약 150토큰 가정.
- 문구 100개당 약 **1.1~3.3달러** (재시도 없음 ~ 최대, 번역 flash-lite + 역번역 3.8-flash, 2027년 가격, 생각 토큰 제외 — N-65, 🔶 계산값).
- 역번역을 flash-lite로 하면 약 0.35~1.05달러로 줄어든다(🔶).

| `POST /api/auth/login` · `/signup` · `/logout` | 세션 쿠키 발급·삭제 |
| `GET /api/store/:key` · `PUT /api/store/:key` | `Store.load/save` 대체 (사업장 단위) |
| `POST /api/reports` · `GET /api/reports/:ticket` | 사진 신고, 접수 번호로 회신 확인 |
| `POST /api/proof/seal` | 증빙 생성 시점 해시·타임스탬프 |
| 예약 작업 | 기한·미이수 알림 |

### 9.3 인증
- 쿠키 `sid`: `HttpOnly; Secure; SameSite=Lax; Max-Age=1209600`(14일). 세션 테이블에 저장.
- 비밀번호: `node:crypto` `scrypt` + 사업장별이 아닌 계정별 salt. 외부 라이브러리 없이 된다.
- 노동자 로그인 단순화(사업장 QR + 식별번호)는 이 단계에서 다룬다 (PRD-CM-01 §11).

### 9.4 동기화 — 가장 큰 설계 결정 (`미정`, 멘토링 결정 6)
- 지금 화면은 `Store.x.load()`를 **동기**로 부른다. 서버 호출은 비동기다.
- 제안: `localStorage`를 그대로 캐시로 두고, 화면이 열릴 때 서버에서 당겨 오고(pull), 저장할 때 대기열에 넣어 밀어 보낸다(push). 화면 코드는 바뀌지 않는다.
- 충돌 규칙 후보: 저장소 단위 "나중 저장 우선"(단순, 위험) vs 기록 단위 병합(`progress`·`reports`는 추가만 하므로 병합이 쉽다).
- 옮기기: 기존 사업장은 `Store.exportAll()` JSON을 한 번 올려 서버로 옮긴다.

### 9.5 DB 스키마 (초안)
```sql

create table accounts (id uuid primary key, workplace_id uuid references workplaces, user_id text unique,
  role text check (role in ('worker','admin','operator')), lang text, pw_hash text not null);  -- 외국인등록번호 열 없음
```

### 14.2 테이블 (DDL 초안)

```sql
create table workplaces (
  id uuid primary key default gen_random_uuid(),
  name text not null, size_band text,
  join_code text unique not null,            -- 노동자 가입 코드 (담당자가 재발급 가능)
  created_at timestamptz default now());

create table accounts (
  id uuid primary key default gen_random_uuid(),
  workplace_id uuid references workplaces,   -- 운영자는 null (사업장을 가로지름)
  user_id text unique not null,              -- 노동자 = 사업장 내 식별번호, 담당자·운영자 = 이메일
  role text not null check (role in ('worker','admin','operator')),
  name text, title text, lang text, process_id text,
  pw_hash text not null, pw_salt text not null,   -- scrypt (node:crypto)
  failed_count int default 0, locked_until timestamptz,
  created_at timestamptz default now());      -- 외국인등록번호·여권번호 열 없음

create table sessions (
  token_hash text primary key,               -- 토큰 원문은 저장하지 않는다 (sha256)
  account_id uuid references accounts on delete cascade,
  expires_at timestamptz not null, created_at timestamptz default now());

create table docs (                           -- 사업장별 저장 키 (Store 키와 1:1)
  workplace_id uuid references workplaces,
  key text check (key in ('setup','courses','progress','posts','orders')),
  data jsonb not null, version int not null default 1,
  updated_at timestamptz default now(),
  primary key (workplace_id, key));

create table library (                        -- 문구 라이브러리: 전 사업장 공용, 운영자 관리
  id text primary key, data jsonb not null,
  version int not null default 1, updated_at timestamptz default now());

create table reports (                        -- 익명 신고: 계정 열이 없다 (구조로 익명을 지킨다)
  id uuid primary key default gen_random_uuid(),
  workplace_id uuid references workplaces,
  data jsonb not null, created_at timestamptz default now());

create table audit (                          -- 중요한 행동 기록 (판정·계정·내보내기). 신고는 기록하지 않는다
  id bigserial primary key, workplace_id uuid, account_id uuid,
  action text, target text, at timestamptz default now());
```

- 테이블 변경은 `db/migrations/NNN_설명.sql` 파일로만 한다. 운영 DB에 손으로 고치지 않는다.
- `prefs`(글자 크기)는 기기 설정이라 서버에 올리지 않는다. `session`은 서버 `sessions`로 대체한다. `accounts`는 서버 테이블이고 화면에 비밀번호를 내려보내지 않는다.

### 14.3 API (표 14-2) — 모두 `api/` 아래, 응답 JSON, 오류 `{error, message}`

| 메서드 · 경로 | 누가 | 하는 일 |
|---|---|---|
| `POST /api/auth/signup-workplace` | 담당자 | 사업장 + 담당자 계정 생성, 가입 코드 발급 |
| `POST /api/auth/signup` | 노동자 | `{joinCode, userId(식별번호), pw, lang, name?}` → 그 사업장 노동자 계정 (담당자 명단의 식별번호와 연결, FR-AD-01-07) |
| `POST /api/auth/login` | 전원 | `{userId, pw}` → `{token, user}`. 5번 틀리면 10분 잠금 |
| `POST /api/auth/logout` | 전원 | 토큰 폐기 |
| `GET /api/store?keys=…` | 로그인 | 자기 사업장 `docs` + 공용 `library` + (담당자만) `reports` → `{key: {data, version}}` |
| `PUT /api/store/:key` | 역할별 (표 14-3) | `{data, baseVersion}` → 서버가 합치기 규칙(§14.4)으로 합쳐 저장 → `{data, version}` |

| `PATCH /api/reports/:id` | 담당자 | 처리 상태 변경 |
| `POST /api/translate` · `/api/backtranslate` | 운영자 | AI (§5). 서버 모드에서는 `X-Agent-Pass` 대신 운영자 토큰으로 확인 |

- 모든 질의는 매개변수 방식(`sql\`... ${v}\``)만 쓴다. 문자열 이어 붙이기 금지.

### 14.4 권한과 합치기 규칙 (표 14-3)

| 키 | 읽기 | 쓰기 | 합치기 (서버) |
|---|---|---|---|
| `setup` | 사업장 전원 | 담당자 | `version` 비교 — 오래된 판이면 409 → 화면이 당겨와 다시 시도 |
| `library` (공용) | 전원 | 운영자 | 문구 `id` 기준. 언어별 `translations[code]`는 나중 판정 우선, `judged` 기록 |
| `courses` | 사업장 전원 | 담당자 | 교육 `id` 기준 |
| `progress` | 담당자 전체 · 노동자는 **자기 것만** | 노동자(자기 `workerId`만) | `workerId + courseId` 기준. 남의 행이 섞이면 서버가 버린다 |
| `posts` | 사업장 전원 | 전원 (자기 글) | 글 `id` 기준, 댓글은 `id` 합집합 |
| `orders` | 사업장 전원 | 담당자 | 지시 `id` 기준 |
| `reports` | 담당자 | 노동자(`POST`만) | 추가만. 수정은 담당자 `PATCH` |

- **화면의 역할 가드(`Auth.require`)는 그대로 두고, 서버가 같은 검사를 다시 한다.** 주소를 직접 쳐도 남의 사업장 데이터는 안 나온다.

### 14.5 `Store` 서버 모드 (화면 코드는 그대로)

1. **모드 판정**: `location.protocol === 'https:'` 이고 토큰이 있으면 서버 모드, 아니면 로컬 모드 (`file://` 시연·오프라인 시험은 로컬 모드).
2. **읽기**: `Store.x.load()`는 지금처럼 **동기로 캐시(`localStorage`)를 읽는다.**
3. **당겨오기**: 페이지가 열리면 `GET /api/store`를 백그라운드로 부른다. 캐시와 다르면 캐시를 바꾸고 **한 번만** 다시 그린다 (반복 방지 표시). 대시보드는 20초마다 당겨온다.
4. **보내기**: `save()`·`update()`는 캐시에 쓰고 **보낼 대기열**(`safety.outbox.v1`)에 넣는다. 온라인이면 바로, 오프라인이면 다시 연결될 때 보낸다. 409면 당겨와 다시 합친다.
5. **실패**: 서버가 응답하지 않으면 캐시로 계속 쓰고 화면 위에 "서버와 연결이 끊겨 이 기기에 저장 중" 배지를 띄운다. **조용히 잃지 않는다.**

### 14.6 보안·개인정보 (H 단계에서 하는 것)

| 항목 | 방법 |
|---|---|
| 비밀번호 | `crypto.scrypt` + 계정별 salt. 응답·로그에 나가지 않는다 |
| 토큰 | 32바이트 난수, DB에는 sha256만, 만료 12시간, 로그아웃 시 삭제 |
| 시도 제한 | 계정별 5회 실패 → 10분 잠금 |
| 사업장 분리 | 모든 질의에 토큰의 `workplace_id` 조건. 요청 본문의 사업장 값은 믿지 않는다 |
| 익명 신고 | 별도 테이블·별도 경로, 계정 열 없음, 우리 로그·감사에 계정 없음. ⚠️ Vercel 플랫폼 접근 로그(IP)는 우리가 끌 수 없다 → 처리방침에 적는다 |
| 키·비밀 | `DATABASE_URL`·`GEMINI_API_KEY` 등은 환경변수만, Production/Preview 분리 |
| 노동자 화면 | 제3자 요청 0건 (테스트), 같은 출처 `/api`만 |
| 개인정보 | 최소 수집, 처리방침·동의 초안 [A05](A05_개인정보-처리방침-초안.md) (법률 검토 전) |
