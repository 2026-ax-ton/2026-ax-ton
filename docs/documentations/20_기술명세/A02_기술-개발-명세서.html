PART 01

지금 시스템

빌드 없는 정적 웹앱이다. 화면 11개가 전역 모듈을 거쳐 브라우저 저장소 10칸을 읽고 쓴다. 프레임워크·외부 라이브러리는 0개이고, 해커톤에서는 관리자앱에 AI 에이전트와 /api 함수 2개만 더한다.

PART 02

해커톤에서 붙이는 것 — 호출 순서

브라우저가 순서를 지휘하고, 서버 함수는 Gemini를 한 번씩만 부른다. 키는 서버에만 있고, 역번역에는 원문을 주지 않으며, 결과는 언제나 대기(waiting)로 들어온다. 사람이 승인해야 노동자에게 간다.

멘토에게 확인할 것 · 루프를 브라우저에서 돌리는 A안이 맞나, 서버 B안이 맞나? (결정 2)

PART 03

API 계약

함수는 2개, 메서드는 POST 하나, 응답에 승인 상태는 없다. 오류는 9가지이고 어떤 오류든 화면은 손 입력으로 돌아간다. 전체 규칙은 부록 5장.

POST /api/translate

요청
{ "ko": "회전 중인 롤러에 손을 넣지 마세요.",
  "lang": "km", "attempt": 0, "hint": "" }
응답 200
{ "text": "…", "model": "gemini-3.1-flash-lite", "attempt": 0 }
서버 → Gemini
POST …/v1beta/models/$AI_MODEL_TRANSLATE:generateContent
x-goog-api-key: $GEMINI_API_KEY
{ "system_instruction": { "parts": [{ "text": "산업안전 번역 규칙…" }] },
  "contents": [{ "role": "user", "parts": [{ "text": "<ko>" }] }],
  "generationConfig": { "maxOutputTokens": 600,
    "thinkingConfig": { "thinkingLevel": "low" } } }

POST /api/backtranslate

요청
{ "text": "<번역문>", "lang": "km" }
응답 200
{ "back": "<한국어 역번역>", "model": "gemini-3.8-flash" }
규칙
  • 번역과 다른 모델(후보 gemini-3.8-flash)
  • 원래 한국어 문장을 보내지 않는다 — 보내면 모델이 원문에 맞춰 고쳐 대조가 무의미해진다
  • temperature를 보내지 않는다 (Gemini 3.6+ 무시·향후 400)
  • 응답 candidates[0].content.parts[0].text만 읽는다

현장 시연 규정 (10/23 공지) · 시연은 제출한 HTML을 운영 PC 크롬에서 더블클릭(file://)으로만 연다. 이때 요청 출처는 null이다 → 시연 기간에만 ALLOW_FILE_ORIGIN=1로 통과 + CORS 헤더 + OPTIONS 204, 화면은 배포 주소 API_BASE로 부른다. AI 부분은 영상으로 백업 (부록 5.2) (결정 10)

2. 기술 스택

영역 지금 ✅ H 🔶 S ⬜ 고른 이유
브라우저 언어 JavaScript (전역 IIFE, 'use strict'), ES 모듈 금지 같음 같음 file://로 열 때 ES 모듈은 CORS로 막힌다. "인터넷 없이 그냥 열린다"를 지킨다
UI 프레임워크 없음. DOM 직접 조작 (UI.el, textContent) 같음 같음 의존성 0, 저사양 안드로이드에서 빠르게 열림, 빌드 단계 없음
스타일 순수 CSS (app.css·style.css·worker.css·admin.css) 같음 같음 기기 글꼴 사용 (크메르·태국·데바나가리 깨지면 Noto 배포 — PRD-CM-02)
저장 localStorage (Store) 같음 서버 DB + localStorage 캐시
오프라인 Service Worker (sw.js) 같음 같음 + 동기화 대기열 공장 안 약한 인터넷
음성 Web Speech API speechSynthesis (읽어 주기) · 받아쓰기(신고) 같음 녹음 음성 검수(로드맵) 외부 TTS를 쓰면 노동자 화면 외부 요청이 생긴다
QR 자체 구현 qr.js (바이트 모드, 오류 정정 M) 같음 같음 외부 QR 서비스 미사용
서버 런타임 없음 Vercel Functions, Node.js (Web Handler, .mjs) 같음 의존성 없이 내장 fetch로 API 호출
AI 모델 없음 Gemini API — 번역 gemini-3.1-flash-lite, 역번역 후보 gemini-3.8-flash (다른 모델) 같음 가격(100만 토큰당 USD): flash-lite 입력 0.25 / 출력 1.50, 3.8-flash 입력 0.75 / 출력 3.75 → 2027-01-01부터 1.50 / 7.50 (N-64)
DB 없음 없음 PostgreSQL (관리형 — 공급사 미정) Store 10칸이 그대로 테이블이 된다
파일 저장 없음 없음 객체 저장소 (공급사 미정) 신고 사진
인증 목업 (localStorage에 계정·비밀번호 평문) 같음 서버 세션 쿠키 + 비밀번호 해시 (node:crypto scrypt) 목업은 시연용이다. 판매 전 반드시 교체
테스트 Node 22 + jsdom(저장소 밖 설치) + 자체 하네스 + 가짜 fetch 경계 테스트 + API 통합 테스트 src/에 의존성을 넣지 않는다
배포 Vercel Hobby (정적) Vercel (함수 포함). 판매 전 Pro Vercel Pro Hobby는 비상업 용도만 (N-61)
저장소 규칙 main ← develop ← feat/agent-*, PR 사용 (D-004) 같음 같음

의존성 원칙 — src/(브라우저)는 의존성 0을 유지한다(결정). 서버 함수도 H 단계에서는 의존성 0(내장 fetch)이다. S 단계에서 DB 드라이버가 필요해지면 서버 쪽에만 package.json을 둔다(§9.5).

요청 헤더 Content-Type: application/json · X-Agent-Pass: <운영자 통과 문구> (§5.6)
출처 검사 요청의 Origin이 배포 주소(ALLOWED_ORIGIN)와 같으면 통과. 시연 기간에만 ALLOW_FILE_ORIGIN=1이면 Origin: null(제출 HTML을 file://로 연 경우)도 통과. 그 밖은 403

사전 요청 OPTIONS는 출처 검사를 통과하면 204 + 위 CORS 헤더, 아니면 403. 모델을 부르지 않고 일일 상한에 세지 않는다

응답 application/json; charset=utf-8, Cache-Control: no-store
오류 형식 { "error": "<code>", "message": "<한국어 설명>" }
로그 한 줄 JSON: {route, lang, attempt, ms, status, err}. 문구 원문·키·IP를 남기지 않는다
금지 응답에 status(승인 상태) 필드를 넣지 않는다. 승인은 사람만 한다 (FR-AD-03-06)

왜 null 출처인가 — 해커톤 현장 시연은 제출한 HTML 파일을 운영 PC 크롬에서 더블클릭해 연다(C08 §7). 이때 브라우저는 Origin: null을 보낸다. 다른 로컬 파일도 같은 값을 보내므로 막는 힘이 약하다 → 제출~11/28 시연 기간에만 켜고 바로 끈다. 남은 방어는 통과 문구(§5.6 2층)·일일 상한(3층)·공급사 예산(4층)이다. ❓ 제출 HTML이 외부 API를 부르는 것이 규정상 되는지 운영진 답변 대기 (C08 §8)

요청

응답 200

{ "text": "<크메르어 번역문>", "model": "gemini-3.1-flash-lite", "attempt": 0 }

{
  "system_instruction": { "parts": [{ "text": "너는 산업안전 지시문 번역가다. 한국어 지시문을 <언어명>으로 번역한다. 규칙: 1) 금지·부정(하지 마세요, 금지, 안 됩니다)을 반드시 보존한다. 2) 기계·부위 이름은 현장 노동자가 쓰는 쉬운 말로 쓴다. 3) 설명·따옴표·로마자 표기 없이 번역문 한 문장만 출력한다." }] },

}
  • 키는 URL 쿼리(?key=)가 아니라 x-goog-api-key 헤더로 보낸다. URL은 로그에 남기 쉽다.
  • temperature를 보내지 않는다. Gemini 3.6 이후·4 모델은 temperature·top_p·top_k를 무시하고 경고를 내며, 이후 400 오류로 바뀐다고 공지돼 있다. 이전 Gemini 3 모델도 기본값 유지가 권장이다.
  • thinkingLevel: "low" — 생각 토큰도 출력 요금이 붙고 지연이 늘어난다. 모델마다 지원 값이 다르므로 키 발급 후 실제 호출로 확인한다.
  • attempt > 0이면 system_instruction 끝에 "앞 번역을 한국어로 되돌렸더니 ''가 되어 뜻이 바뀌었다. 부정과 금지를 다시 확인하라."를 붙인다.

  • 언어명은 서버의 고정 표(km→"크메르어" 등)에서 가져온다. 요청값을 프롬프트에 그대로 넣지 않는다.

6. AI 에이전트 (브라우저 agent.js) 🔶

6.1 상태 기계 (언어마다 따로)

idle ─[AI 번역 받기]→ translating → backtranslating → comparing ─┬─ ok ─────────────→ done (waiting 저장)
                                                                 └─ flipped → retry(n<2) → translating
                                                                            └─ n=2 ───→ escalated (waiting + 사람에게 올림)
어느 단계든 오류·시간 초과 → failed → 손 입력 칸 표시 (FR-AD-03-07)

6.2 알고리즘

// assets/agent.js — IIFE, 전역 Agent. ES 모듈 아님.
async function runLang(phrase, lang, onStep) {
  let hint = '', last = null;
  for (let attempt = 0; attempt <= 2; attempt++) {
    onStep(lang, 'translating', attempt);
    const t = await call('/api/translate', { ko: phrase.ko, lang, attempt, hint }, 25000);
    onStep(lang, 'backtranslating', attempt);
    const b = await call('/api/backtranslate', { text: t.text, lang }, 25000);
    onStep(lang, 'comparing', attempt);
    const c = compare(phrase.ko, b.back);           // Review.negationFlipped + newWordCount
    last = { text: t.text, back: b.back, tries: attempt + 1, flipped: c.flipped, escalated: false, model: t.model };
    if (!c.flipped) return last;
    hint = b.back;
  }
  return { ...last, escalated: true };               // 상한 도달 → 사람에게 올림
}
// run(): 언어끼리는 Promise.allSettled로 병렬, 언어 안에서는 순차.
//         이미 reviewed인 언어는 건너뛴다 (FR-AD-03-15).
  • 실제 코드는 프로젝트 규칙대로 IIFE·var 스타일로 쓴다. 위는 흐름만 보인다.
  • call()은 fetch + AbortController(25초). 응답 JSON 모양(text·back이 문자열)을 검사하고 아니면 throw.
  • navigator.onLine === false면 [AI 번역 받기]를 비활성 + 이유 표시 (조용히 숨기지 않음).
  • file://로 열었으면 상대 경로 /api 대신 API_BASE(배포 주소, agent.js 맨 위 상수) 로 부른다 — 현장 시연용 (§5.2, C06 D-019). 노동자 화면은 여전히 외부 요청 0건이다.

library[i].translations[code] = {

  status: 'waiting',                        // ★ 응답과 무관하게 코드 상수

}

  • 화면 표시는 전부 textContent (FR-AD-03-11). AI 출력은 신뢰하지 않는 문자열이다.

9. 판매 단계 설계 ⬜ (후보)

9.1 구조

브라우저 (화면 그대로) ─ Store(캐시 + 동기화 대기열) ─HTTPS─ Vercel 함수 /api/* ─ PostgreSQL
                                                                         └─ 객체 저장소 (사진)

9.2 API (요약 — SPEC-BE §3.2)

경로 용도
POST /api/auth/login · /signup · /logout 세션 쿠키 발급·삭제
GET /api/store/:key · PUT /api/store/:key Store.load/save 대체 (사업장 단위)
POST /api/reports · GET /api/reports/:ticket 사진 신고, 접수 번호로 회신 확인
POST /api/proof/seal 증빙 생성 시점 해시·타임스탬프
예약 작업 기한·미이수 알림

9.3 인증

  • 쿠키 sid: HttpOnly; Secure; SameSite=Lax; Max-Age=1209600(14일). 세션 테이블에 저장.
  • 비밀번호: node:crypto scrypt + 사업장별이 아닌 계정별 salt. 외부 라이브러리 없이 된다.
  • 노동자 로그인 단순화(사업장 QR + 식별번호)는 이 단계에서 다룬다 (PRD-CM-01 §11).

9.4 동기화 — 가장 큰 설계 결정 (미정, 멘토링 결정 6)

  • 지금 화면은 Store.x.load()를 동기로 부른다. 서버 호출은 비동기다.
  • 제안: localStorage를 그대로 캐시로 두고, 화면이 열릴 때 서버에서 당겨 오고(pull), 저장할 때 대기열에 넣어 밀어 보낸다(push). 화면 코드는 바뀌지 않는다.
  • 충돌 규칙 후보: 저장소 단위 "나중 저장 우선"(단순, 위험) vs 기록 단위 병합(progress·reports는 추가만 하므로 병합이 쉽다).
  • 옮기기: 기존 사업장은 Store.exportAll() JSON을 한 번 올려 서버로 옮긴다.

9.5 DB 스키마 (초안)

create table workplaces (id uuid primary key, name text not null, size_band text, langs text[]);
create table accounts (id uuid primary key, workplace_id uuid references workplaces, user_id text unique,
  role text check (role in ('worker','admin','operator')), lang text, pw_hash text not null);  -- 외국인등록번호 열 없음
create table phrases (id uuid primary key, ko text not null, category text, status text);
create table phrase_translations (phrase_id uuid references phrases, lang text, text text, back text,
  status text check (status in ('reviewed','waiting','stopped')), agent jsonb, judged_by uuid, judged_at timestamptz,
  primary key (phrase_id, lang));
create table progress (id bigserial primary key, workplace_id uuid, worker_id uuid, course_id uuid,
  learned_at timestamptz, quiz jsonb, created_at timestamptz default now());   -- 수정 없이 추가만
create table reports (id bigserial primary key, ticket text unique, workplace_id uuid, equipment_id text,
  hazard text, memo text, photo_key text, status text, created_at timestamptz default now()); -- 신고자 열 없음
  • 공급사(관리형 PostgreSQL·객체 저장소)는 미정. 기준: 한국 리전 여부, Vercel 연동, 무료 구간, 백업.
