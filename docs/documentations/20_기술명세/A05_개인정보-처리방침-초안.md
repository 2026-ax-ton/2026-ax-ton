## 2. 보관과 파기

- 보관 장소: Neon Postgres (AWS 싱가포르 리전), 사용자 기기 브라우저 저장소(캐시).
- 보관 기간: `미정` — 사업장의 교육 기록 보존 의무 기간을 확인한 뒤 정한다 (byeonsoyun, P 단계). 사업장 탈퇴 시 해당 사업장 데이터를 지운다.
- 파기: DB에서 삭제하고 백업 주기가 지나면 백업에서도 사라지게 한다.

### 3.1 🆕 사진을 보낼 때 (2026-11-04 신설)

담당자가 설비 사진으로 교육 문항 초안을 만드는 기능([PRD-AD-07](../30_제품정의/prd/PRD-AD-07_사진-위험요소-인식.md))에서만 사진을 보낸다. 노동자는 이 기능을 쓰지 않는다.

| 항목 | 내용 | 근거 |
|---|---|---|
| **보내는 것** | 담당자가 그 자리에서 찍은 **설비 사진의 줄인 사본** 1장 + 우리가 쓴 지시문. 그것뿐이다 | FR-AD-07-03·14 |
| **보내지 않는 것** | 노동자 정보·진도·문항 응답·**노동자가 올린 위험요소 신고 사진**. 신고는 익명 자료라 공급사로 내보내지 않는다 | FR-AD-07-14·18, 표 1 「신고자 정보를 저장하지 않는다」 |
| **누가 찍나** | **담당자 본인**이 찍거나 고른 사진만 보낸다. 노동자가 보낸 사진은 입력으로 쓰지 않는다 | FR-AD-07-18 |
| **우리 쪽 보관** | **저장하지 않는다.** 분석 결과(위험 지점 좌표·위험유형)만 담당자 화면에 남고, 사진 사본은 서버에도 기기에도 남기지 않는다 | FR-AD-07-03·17 · PRD-AD-07 §11 Q1 (B안) |
| **받는 곳 보관** | **`미정`** — Google 의 보존 정책을 확인해 적는다. 우리가 정할 수 없는 부분이라 **모르는 채로 「없다」고 쓰지 않는다** | A04 4-7 (법률 검토 전) |
| **사람이 찍혔을 때** | 찍기 전에 "사람 얼굴·이름표가 나오지 않게 설비만 찍어 주세요"를 글자와 그림으로 안내한다. AI 가 사람·이름표를 알아보면 **그 결과를 버리고 다시 찍게 한다** | FR-AD-07-02·20 |
| ⚠️ **남는 한계** | 사람 감지는 사진이 **우리 서버와 공급사로 간 뒤**에 일어난다. 기기 안에서 먼저 거르려면 브라우저 인식 모델이 필요해 「`src/` 의존성 0」(C05 T-5′)과 부딪힌다. 그래서 **촬영 전 안내가 1차 방어**이고, 감지는 2차다 | PRD-AD-07 §11 Q5 |
| **시연** | **실제 노동자가 찍힌 사진으로 시연하지 않는다.** 해커톤 시연은 설비만 찍은 예시 사진으로 한다 | 이 문서 머리말 |

## 4. 이용자의 권리

- 자기 정보의 열람·정정·삭제를 요청할 수 있다. 노동자는 담당자 또는 운영 창구(`미정`)로 요청한다.
- 동의하지 않으면 서버 모드를 쓰지 않는다 — 단, 사업장 교육 증빙이 어려워질 수 있음을 알린다.

## 5. 안전성 확보 조치 (해커톤 단계 구현)

- 비밀번호 해시(scrypt), 토큰 만료, 로그인 시도 제한, 사업장별 접근 통제, 비밀 키 환경변수 관리, 전송 구간 HTTPS, 신고 익명 구조, 중요한 행동 기록. 상세 [A02 §14.6](A02_기술-개발-명세서.md).

## 6. 노동자 동의 화면 (가입 화면에 넣을 문안 — 한국어 원문)

> - 외국인등록번호나 여권번호는 받지 않아요.
> - 위험 신고는 누가 했는지 저장하지 않아요.
> - 내 기록은 이 회사의 안전교육 관리에만 써요. 평가나 순위에 쓰지 않아요.
> - 정보는 싱가포르에 있는 서버에 저장돼요.
> [ 동의해요 ] [ 동의하지 않아요 ]
