# A05 · 개인정보 처리방침·수집 동의 — 초안

> **문서 상태** 초안 v0.1 · **최종 수정** 2026-10-31 · **소유자** byeonsoyun
> ⚠️ **법률 검토 전 초안이다.** 해커톤 시연은 예시 데이터로만 한다. 실제 노동자 데이터를 받기 전(시범 운영 P 단계)에 창업지원센터·법률 상담으로 확인한다 ([A04 4-7](A04_운영준비-체크리스트.md)). 법 조항 번호와 보존 기간은 확인 전이라 `미정`으로 둔다.

## 1. 모으는 정보와 목적 (표 1)

| 대상 | 모으는 항목 | 목적 | 모으지 않는 것 |
|---|---|---|---|
| 노동자 | 사업장 내 식별번호, 사용 언어, 이름(선택), 소속 공정, 교육 이수·문항 응답 기록 | 교육 제공, 이해도 확인, 사업장 증빙 | 외국인등록번호·여권번호·국적·연락처 |
| 담당자 | 이메일(아이디), 이름, 직함, 사업장 정보 | 교육 관리, 증빙 발급 | |
| 운영자 | 이메일, 이름 | 번역 검수 | |
| 위험 신고 | 설비·위험유형·메모(·음성은 글로 바꿔 저장) | 현장 위험 개선 | **신고자 정보를 저장하지 않는다** |
| 서비스 기록 | 로그인 시각, 중요한 행동 기록(판정·내보내기) | 보안·책임 기록 | 신고 행동 |

## 2. 보관과 파기

- 보관 장소: Neon Postgres (AWS 싱가포르 리전), 사용자 기기 브라우저 저장소(캐시).
- 보관 기간: `미정` — 사업장의 교육 기록 보존 의무 기간을 확인한 뒤 정한다 (byeonsoyun, P 단계). 사업장 탈퇴 시 해당 사업장 데이터를 지운다.
- 파기: DB에서 삭제하고 백업 주기가 지나면 백업에서도 사라지게 한다.

## 3. 처리 위탁·국외 이전 (표 2)

| 받는 곳 | 하는 일 | 위치 | 보내는 정보 |
|---|---|---|---|
| Vercel Inc. | 화면·서버 함수 호스팅 | 함수 리전 싱가포르(`sin1`), 회사는 미국 | 요청 데이터 전반 (접속 IP는 플랫폼 기록에 남을 수 있음) |

## 4. 이용자의 권리

- 자기 정보의 열람·정정·삭제를 요청할 수 있다. 노동자는 담당자 또는 운영 창구(`미정`)로 요청한다.
- 동의하지 않으면 서버 모드를 쓰지 않는다 — 단, 사업장 교육 증빙이 어려워질 수 있음을 알린다.

## 5. 안전성 확보 조치 (해커톤 단계 구현)

- 비밀번호 해시(scrypt), 토큰 만료, 로그인 시도 제한, 사업장별 접근 통제, 비밀 키 환경변수 관리, 전송 구간 HTTPS, 신고 익명 구조, 중요한 행동 기록. 상세 [A02 §14.6](A02_기술-개발-명세서.md).

## 6. 노동자 동의 화면 (가입 화면에 넣을 문안 — 한국어 원문)

> **[내 정보는 이렇게 쓰여요]**
> - 회사가 준 번호, 사용하는 말, 교육을 들은 기록만 저장해요.
> - 외국인등록번호나 여권번호는 받지 않아요.
> - 위험 신고는 누가 했는지 저장하지 않아요.
> - 내 기록은 이 회사의 안전교육 관리에만 써요. 평가나 순위에 쓰지 않아요.
> - 정보는 싱가포르에 있는 서버에 저장돼요.
> [ 동의해요 ] [ 동의하지 않아요 ]

- 6개 언어 번역과 음성 안내를 붙인다. 번역은 **원어민 검수를 거친 것만** 쓴다 (우리 제품 원칙과 같다).
- 문해력을 전제하지 않으므로 그림과 음성으로도 설명한다.
