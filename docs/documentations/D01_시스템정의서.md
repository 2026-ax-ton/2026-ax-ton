## 작품 설명

이 시스템은 한국어를 잘 모르는 외국인 노동자가 안전교육을 이해했는지 확인하는 웹 서비스이다.
담당자는 검수된 다국어 안전 문구를 골라 교육을 만들고, 설비 앞 QR로 노동자에게 배포한다.
노동자는 자기 언어의 음성으로 교육을 듣고, 글을 읽지 않고 손가락으로 푸는 그림 문제로 이해를 보인다.
통과하지 못하면 교육 완료로 기록되지 않으며, 결과는 언어별 취약 항목과 제출용 증빙 문서로 정리된다.
해커톤 버전에서는 번역·검수·출제·분석 업무에 AI 에이전트를 붙이되, 안전 지시로 쓰이는 최종 승인은 사람이 한다. (AI 에이전트 범위 — **후보**)

## 사용자 유형

- **주요 사용자** : 노동자 — 한국어가 서툰 외국인 제조업 노동자. 6개 언어(크메르어·인도네시아어·베트남어·네팔어·태국어·한국어)를 지원한다.
- **보조 사용자** : 담당자 — 50인 미만 사업장의 안전 업무 겸직자(생산팀장 등). 교육을 만들고 결과와 증빙을 다룬다.
- **관리자** : 운영자 — 번역이 맞는지 판정(승인·대기·중지)하는 검수 담당자. 여러 사업장의 문구를 가로질러 본다.
- **비용 부담 후보 (멘토링 의견)** : 실제 사용자(노동자)는 비용을 낼 수 없으므로, 돈을 쓸 수 있는 주체는 사업주·기관·정부/지자체이다. 수익 모델은 `미정` ([C06 D-010](00_개발컨벤션/C06_결정기록.md)).

## 운영 개념

1. 담당자가 사업장·설비를 등록하고, 운영자가 번역을 검수한 안전 문구로 교육과 문제를 만들어 QR과 함께 발급한다.
2. 노동자가 설비 앞 QR로 접속해 내 언어 음성으로 교육을 듣고, 그림 문제를 풀어 이해도를 검증받는다. 노동자는 위험 요소를 익명으로 신고할 수 있다.
3. 담당자가 대시보드에서 언어별 취약 항목을 확인해 재교육을 지시하고 교육을 고친다. 결과는 증빙 문서로 인쇄한다.
4. (해커톤 · **후보**) AI 에이전트가 번역·문제 초안·현장 신호 분석을 먼저 처리하고, 사람이 판정한다. AI가 실패하면 기존 수동 방법이 그대로 남는다.

## 작품의 주요 기능

1. **문해력 비전제 이해도 검증** — 손가락으로 하는 그림 문제 3유형(위험 지점 짚기·올바른 작업 고르기·보호구 짝 맞추기). 통과해야 교육 완료로 기록된다.
2. **검수 게이트가 있는 다국어 안전교육 생성** — 언어별 검수 판정(승인·대기·중지), 역번역 대조, 오역 신고 즉시 중지. 검수된 문구만 안전 지시가 된다.
3. **이해 결과를 담은 증빙·개선 루프** — 미이수자를 숨길 수 없는 증빙 인쇄, 언어×위험유형 정답률 대시보드, 재교육 지시.
4. **(해커톤 · 후보) AI 에이전트** — 번역·검수(A), 문항 출제(B), 현장 신호 분석(C) 중 선택. 결과는 항상 `waiting` 상태로 제출되고 사람이 판정한다.

## 기타 개발 시 고려사항

1. **현장 환경** — 인터넷이 약하고 장갑을 끼고 글을 못 읽는 사용자를 전제한다. 노동자 화면은 외부 요청 0건, 오프라인 동작, 60px 터치 영역, 음성 병행을 지킨다.
2. **사람·데이터 보호** — 익명 신고(신고자 식별값 저장 0), 미통과 숨김 금지, 인사·평가용 내보내기 금지, 외국인등록번호·여권번호 미수집, "면책" 표현 금지.
3. **확장 순서** — 서버가 없는 현재 구조(브라우저 저장소 `Store` 한 통로)에서 시작해, 해커톤에서 AI 호출용 서버리스 함수를 처음 도입한다(**후보**, 소유자 승인 필요). 기기 간 공유·진짜 로그인·사진/음성 첨부는 서버 필요 항목으로 남아 있다.
4. **수치의 신뢰성** — 발표·문서의 통계는 출처 확인 후 쓴다. 출처 없는 수치는 `미정` 처리한다.
