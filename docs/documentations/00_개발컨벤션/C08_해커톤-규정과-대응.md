## 8. 운영진 채널톡 문의문 (초안)

> 안녕하세요, 한국기술교육대학교 청일점 팀입니다. 현장 시연 파일 관련해 두 가지 여쭙습니다.
>
> 1. 저희 서비스는 HTML 파일 여러 개와 JS·CSS 파일로 이루어진 웹앱입니다. 크롬에서 `index.html`을 더블클릭하면 서버 없이 바로 실행되지만, 파일이 한 개가 아니라 **폴더 구조**입니다. 이 경우 **폴더를 zip으로 압축해 제출**하고 현장에서 압축을 풀어 `index.html`을 실행해도 되는지, 아니면 반드시 HTML 파일 한 개로 만들어야 하는지 궁금합니다.
> 2. 서비스의 AI 기능은 제출한 HTML 파일 안에서 **저희가 운영하는 서버 함수(API)를 호출**해 AI 번역 결과를 받아옵니다. 시연 자체는 제출한 HTML 파일로 진행하고 발표 중에 다른 URL을 열지는 않는데, 이렇게 제출 파일이 내부적으로 외부 API를 호출하는 것은 허용되는지 확인 부탁드립니다.
>
> 그리고 메일 제목의 [거점대학교]에는 학교 이름(한국기술교육대학교)을 적으면 되는지도 알려 주시면 감사하겠습니다.
