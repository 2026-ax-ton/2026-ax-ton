## 2. 수료 조건 — 하나라도 빠지면 수료 안 됨

- **멘토링 6회 + 해커톤 당일 전부 참여.** 멘토가 회차마다 **팀원 전원**의 참석을 화면 캡처로 확인한다
- **카메라를 켜고 얼굴이 보여야** 참석으로 인정된다
- 중도 포기하면 이미 들은 1단계 교육까지 수료증이 안 나온다
- 팀 구성은 바꿀 수 없다 (추가·분리 불가)
- 당일 불참 사유가 있으면 **사전에** 채널톡으로 문의

> **기획·디자인 팀(팀장 + 팀원 2)도 모든 멘토링에 카메라를 켜고 들어와야 한다.** 기술 멘토링도 마찬가지다.
