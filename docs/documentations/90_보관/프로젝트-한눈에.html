3누가 쓰나

사용자는 세 종류입니다.

노동자

6개 언어(크메르·인도네시아·베트남·네팔·태국·한국어)로 교육을 듣고, 그림 문제를 풀고, 위험을 신고하거나 질문합니다.

담당자

사업장 안전 담당자. 설비 등록 → 교육 만들기 → 대시보드 확인 → 증빙 출력.

운영자

번역 검수 담당. 안전 문구의 번역이 맞는지 승인·대기·중지를 판정합니다.

검수가 끝난(reviewed) 문구만 안전 지시로 쓰입니다. 번역이 틀리면 사고로 이어질 수 있기 때문입니다.
