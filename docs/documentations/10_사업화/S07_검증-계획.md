## 3. 동의와 익명 — 지킬 선

- 시작 전에 **목적·시간·녹음 여부를 말로 설명**하고 동의를 받는다. 거절해도 불이익이 없다고 말한다
- **이름·연락처·사업장명·외국인등록번호를 적지 않는다.** 기록은 `P1`, `M1` 같은 번호로만
- **얼굴을 찍지 않는다.** 화면·손만 찍는다 (발표 사진도 같음)
- 녹음은 동의할 때만, 정리 후 삭제
- 제품 원칙과 같다: 신고는 익명, 개인을 드러내는 기록을 남기지 않는다

## 4. 인터뷰 질문지

### 4.1 안전관리자·사업주 (약 30분, 10문항)

1. 외국인 노동자는 몇 명이고 어느 나라 분들인가요?
2. 지금 안전교육은 어떻게 하나요? (누가 · 언제 · 어떤 자료 · 몇 분)
3. 교육할 때 가장 어려운 점은 무엇인가요? (말이 안 통함 / 시간 / 자료 / 확인)
4. 교육 내용을 알아들었는지 지금은 어떻게 확인하나요?
5. 교육했다는 기록은 어떻게 남기나요? 점검 때 무엇을 보여 주나요?
6. (앱 시연 5분 뒤) 이 화면 중 바로 쓰고 싶은 것과 필요 없는 것은?
7. 이런 서비스에 돈을 낸다면 얼마까지, 누가 내야 한다고 보나요? (사업주 / 지자체 / 협회)
8. 번역 문구를 사람이 검수한다는 점이 중요하게 느껴지나요?
9. 안전 업무로 평가받는 지표(KPI)는 무엇인가요? (사고율 · 보험료 · 점검 결과 · 과태료 등)
10. 이런 도구를 사려면 누가 결재하나요? 지금 안전에 쓰는 돈은 1년에 얼마쯤인가요? (2차 창업 멘토링: 숫자 검증·최종 결정권자 — [S08 §4·§6](../../infos/05_멘토링/2026-10-24_사업2차/S08_창업멘토링2차-결과-2026-10-24.md))

### 4.2 노동자 (약 15분, 6문항 — 짧고 쉬운 말로, 가능하면 모국어 통역)

1. 한국에서 어떤 일을 하나요? 한국어는 얼마나 읽을 수 있나요?
2. 처음 일할 때 안전교육을 받았나요? 알아들었나요?
3. 일하다가 위험하다고 느낀 적이 있나요? 그때 누구에게 말했나요?
4. (MVP 테스트 §5 뒤) 앱에서 어려웠던 곳은 어디인가요?
5. 그림·소리 중 무엇이 더 도움이 됐나요?
6. 이 앱으로 위험을 신고할 수 있다면 쓰겠나요? 이름이 안 남는다는 것이 중요한가요?

## 5. MVP 테스트 시나리오

| 단계 | 참가자에게 하는 말 | 관찰할 것 |
|---|---|---|
| 0. 준비 | — | 시연 기기에 **예시 데이터 채우기**, 참가자 언어 설정 |
| 1. 로그인 | "이 화면에서 시작해 주세요" | 언어를 스스로 바꾸는가 |
| 2. 교육 수강 | "오늘 교육을 끝까지 들어 주세요" | **설명 없이** 끝내는가, 막힌 화면 |
| 3. 이해도 검증 | "문제를 풀어 주세요" | 첫 시도 통과 여부, 틀린 문항 |
| 4. 위험 신고 | "위험한 것을 봤다고 생각하고 알려 주세요" | 신고 버튼을 찾는 시간 |
| 5. 관리자 (관리자 참가자만) | "교육을 하나 만들어 발급하고 결과를 보세요" | 대시보드 숫자를 이해하는가 |

- **진행자는 도와주지 않는다.** 막히면 30초 기다린 뒤 "어디가 어려운가요?"만 묻는다
- 측정: ① 끝까지 마침 여부 ② 단계별 걸린 시간 ③ 막힌 곳 ④ 이해도 검증 첫 시도 통과 ⑤ 참가자 한마디

## 7. 개선 고리 — 발견을 점수로 바꾸는 법

1. **발견**: 2명 이상이 같은 곳에서 막히면 발견 1건으로 센다 (1명은 메모만)
2. **기록**: PRD §10에 "발견" 칸 작성 → 바꿀 요구사항을 FR로 적는다
3. **할 일**: `docs/07-next-tasks.md` H 절에 항목 추가 (`**어디**:` `**됐는지**:` 포함)
4. **개선**: byeonsoyun이 고치고 테스트
5. **재확인**: 다음 참가자에게 같은 단계를 시켜 **전후**를 비교한다 (시간·마침 여부)
6. **증거**: 고치기 전·후 화면 캡처를 남긴다 (얼굴 없이)

## 8. 발표에 넣는 방법

- 장표 1장: "인터뷰 **n명** · MVP 테스트 **n회** · 발견 **k건** · 반영 **m건**"
- 인용 1~2개: 안전관리자 한마디 + 노동자 한마디 (번호로만 표기)
- 전후 1쌍: 개선 전 화면 → 개선 후 화면 + 바뀐 숫자 (예: 수강 마침 시간)
- 문제 이해도(15)에도 같은 인용을 쓴다
- 팀워크(10): "검증은 기획·디자인 팀이 수행하고 개발이 반영했다"를 역할 표와 함께 보여 준다
