## 2026-11-06

**한 것**
- T17 을 「기계 정보 → AI 리서치 → 사진 좌표 → 영상·퀴즈 → 1클릭 승인」으로 넓히는 기능 정의서 [PRD-AD-08](../documentations/30_제품정의/prd/PRD-AD-08_AI-교육-자동생성.md) v0.1 과 결정 제안 C06 D-035 를 썼다. 코드는 팀 확정까지 멈춘다

**막혔던 것 / 어떻게 풀었는지**
- "Higgsfield 를 Gemini 에 MCP 로 붙여야 하나, 안 되면 GPT 로 바꿔야 하나" → 조사해 보니 MCP 는 에이전트가 도구를 부르는 방식이라 우리 서버엔 필요 없고, 검색 근거·YouTube 입력·박스 좌표·영상(Veo)이 전부 Gemini 키 하나로 된다
- "노동자 화면은 외부 요청 금지라 영상을 못 보낸다"로 오해했다 → 막힌 것은 **제3자 주소**뿐이고 우리 서버는 이미 주고받는다(D-032). 영상도 우리 주소로 내보내면 된다
- YOLO 를 쓰고 싶었지만 추론 서버가 제출본에서 금지라 제품 흐름에선 Gemini 박스를 쓰고, 노트북은 좌표 품질 측정·학습 데이터 준비로 돌렸다

**다음에 할 것**

## 2026-11-05

**한 것**
- T17 서버 함수 `POST /api/hazards` 를 만들었다 — 담당자가 찍은 설비 사진을 Gemini 에 넣어 위험 지점(퍼센트 좌표·위험유형·이유)을 **제안**받는다. 저장은 하지 않는다
- 실측 도구(`scripts/measure-hazards.mjs`)에 있던 지시문·거르는 규칙을 `api/_hazards.mjs` 로 옮겨 서버와 도구가 같은 함수를 쓰게 했다
- 검사 65건 추가 (`tests/test-api-hazards.mjs`) — 전체 28묶음 2,582건 통과

**막혔던 것 / 어떻게 풀었는지**
- 서버의 본문 상한이 4KB(번역용)라 사진이 안 들어간다 → 이 함수만 2MB 로 따로 두고, 사진 자체는 1.5MB 천장. 화면이 1024px 로 줄여 보내면 보통 150~300KB 다
- 위험유형 6종을 화면 파일(`store.js`)에서 읽으면 서버 배포 묶음에 그 파일이 있다고 믿을 수 없다 → 서버엔 코드 목록 사본을 두고, **화면과 어긋나면 검사가 깨지게** 묶었다
- 번역 함수는 운영자 통과 문구로 열리는데, 이건 담당자 화면이라 로그인 토큰(T11)으로 역할을 본다
