# 01. 데모 촬영 대본 — 3차(AI·DB) 컷 단위

> **아이디어톤(9월) 대본과 다른 점**
> 그때는 전부 `localStorage` 뿐이었습니다. 지금은 **실제 Gemini 번역**과
> **기기 두 대 사이 동기화**가 실물로 돕니다 — 이번 영상의 핵심은 이 둘입니다.
> 나머지(이해도 검증·증빙)는 9월 대본을 그대로 씁니다
> ([`../2026-09_아이디어톤/발표-인계/04-데모-촬영-대본.md`](../2026-09_아이디어톤/발표-인계/04-데모-촬영-대본.md)).

> **★ 이 문서가 못 하는 것** — 실제 화면 녹화·마이크 내레이션·편집은
> 사람이 합니다. 여기 있는 것은 **무엇을 어느 순서로, 어떤 계정으로,
> 몇 초짜리로 찍을지**까지입니다. Claude Code 는 코드는 고치지만
> 카메라를 들지 않습니다.

---

## 0. 촬영 전 준비

| 체크 | 무엇 | 왜 |
|---|---|---|
| ☐ | **배포 주소**(`https://2026-ax-ton.vercel.app`)에서 찍는다 | `file://` 은 AI·동기화를 켜려면 서버의 `ALLOW_FILE_ORIGIN=1` 이 필요하다(시연 기간에만 켠다, C06 D-019). 배포 주소는 그 설정이 필요 없다 |
| ☐ | **3차(T10~T15)가 `main` 에 올라가 있는지 확인** — 아직이면 사용자에게 "배포해 줘" 를 받아야 한다 | `main` 이 2차(AI) 판 그대로면 DB·로그인·동기화·익명 신고 화면이 안 보인다 |
| ☐ | 노동자 폰 1대 + 담당자 PC 1대(또는 PC + 다른 브라우저) 준비 | 컷 B(두 기기 동기화)에 **반드시** 둘이 필요하다 |
| ☐ | 폰·PC 모두 **먼저 한 번 열어 둔다** (예시 데이터 자동 채우기) | 촬영 중에 빈 화면이 뜨면 다시 찍어야 한다 |
| ☐ | 운영자(`oper@safety.kr`)로 **AI 번역을 한 번 미리 눌러 본다** | 공급사 응답이 2~3초 걸린다 — 처음 누르는 순간을 날것으로 찍으면 "느린 건가" 하는 정적이 생긴다. 리듬을 한 번 보고 찍는다 |
| ☐ | PC **소리 켜 두고 녹음 포함** | 이해도 검증 음성 컷이 이 제품의 핵심이다 |
| ☐ | 형식은 9월 대본과 같다 — **MP4, 1920×1080, 컷당 15~25초, 자막 한 줄씩** | |

## 1. 새 컷 — 이번 영상에서 꼭 넣을 것

### 컷 A — ★ AI 번역·검수 (25초) — 이번 영상에서 가장 중요

| | |
|---|---|
| **계정** | `oper@safety.kr` / `1234` → 문구 라이브러리 |
| **길** | 검수 안 된 문구 하나 고르기 → **[AI 번역 받기]** 누르기 → 5개 언어 진행 줄이 차는 것 기다리기 |
| **보여줄 것** | **실제 Gemini 응답**이 몇 초 안에 들어온다. 언어별로 "시도 n/3" 이 올라간다 |
| **자막** | `AI가 다섯 언어로 옮기고, 사람이 보고 승인합니다` |
| **놓치면 안 되는 것** | 번역이 들어와도 상태가 **`waiting`(대기)** 인 것 — 사람이 "승인"을 눌러야 `reviewed` 가 된다. **AI는 여기까지, 승인은 사람** 이라는 문구가 화면에 있다 |
| **선택** | 시간 있으면 "사람에게 올림"(역번역이 뜻을 뒤집었을 때) 화면도 5초 추가 |

### 컷 B — ★★ 두 기기 동기화 (25초) — 두 번째로 중요

| | |
|---|---|
| **기기** | 노동자 폰(`W-4821-07`) + 담당자 PC(`kim@daesung.co.kr`, 대시보드) **나란히** 화면에 |
| **길** | 폰에서 이해도 검증을 통과(또는 위험요소 신고 접수) → 아무것도 안 누르고 PC 대시보드를 20초 지켜본다 |
| **보여줄 것** | **PC 화면이 저절로** 바뀐다 — 통과 기록이 뜨거나 신고 큐에 올라온다. 담당자가 새로고침을 누르지 않는다 |
| **자막** | `노동자 폰과 담당자 PC가 20초 안에 같은 것을 봅니다` |
| **촬영 팁** | 화면 분할(폰 캡처 앱 또는 폰을 손에 들고 PC 화면과 같이 찍기)로 **동시에** 보여야 설득력이 생긴다. 타임스탬프가 영상에 남게 초시계 앱을 PC 한쪽에 띄워도 좋다 |
| **놓치면 안 되는 것** | 폰이 **비행기 모드가 아닌 것**(끊기면 안 올라간다). PC 쪽에 작게 뜨는 동기화 배지 |

### 컷 C — 공용 폰 자동 로그아웃 (15초)

| | |
|---|---|
| **길** | 노동자 계정으로 이해도 검증 **통과** → [홈으로] 누르기 |
| **보여줄 것** | 로그인 화면으로 돌아간다 — 다음 사람이 바로 자기 계정으로 들어갈 수 있다 |
| **자막** | `공장 폰은 여러 명이 돌려 씁니다 — 검증이 끝나면 자동으로 로그아웃됩니다` |

### 컷 D — 익명 신고 (15초)

| | |
|---|---|
| **길** | `W-4821-07` → 위험요소 신고 → 설비·위험유형 그림 두 번 선택 → 접수 |
| **보여줄 것** | 접수 번호만 뜨고, 이름·아이디를 **아무 데도 입력하지 않았다** |
| **자막** | `위험요소 신고는 익명입니다 — 누가 알렸는지 저장하지 않습니다` |

| 순서 | 컷 | 길이 | 비고 |

| 3 | (9월) 이해도 검증 ★ | 25초 | 그대로 — 음성 🔊 반드시 |

AI·검증·동기화가 이번 3차의 핵심이고, 나머지는 9월 영상이 이미 증거로 있다.

## 5. 라이브 시연이 안 될 때 (보험)

9월 대본 §4 와 같습니다 — **`src/index.html` 더블클릭이 최후 보험**입니다.
다만 이번 차수는 더블클릭(`file://`)만으로는 **AI·동기화·익명 신고가 켜지지 않습니다**
(서버의 `ALLOW_FILE_ORIGIN=1` 이 시연 기간에만 켜져 있어야 합니다, C06 D-019).
그 설정이 꺼져 있으면 로컬 모드(목업 로그인)로 자동 전환되고, **이해도 검증·증빙 등
서버 없이도 되는 기능은 그대로 됩니다** — "그래도 교육은 계속됩니다" 로 말을 돌릴 수 있습니다.
