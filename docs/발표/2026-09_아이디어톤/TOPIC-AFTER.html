개선 후 · 해커톤 AI Agent 버전

해커톤에서 바꾸는 것: 사람 손으로 하던 일을 AI 에이전트가 먼저 해 둔다

기본 흐름과 원칙은 그대로 두고, 가장 손이 많이 가는 곳에 AI 에이전트를 붙입니다. 마지막 결정은 언제나 사람이 합니다.

한눈에 비교에이전트란에이전트 후보 3개구조 변화안전장치평가표미정 사항
먼저 알아둘 것. 아래 에이전트는 모두 후보입니다. 해커톤 주제와 평가표가 공지되기 전까지 코드는 쓰지 않기로 했습니다. 확정된 것에는 확정, 아직 정해지지 않은 것에는 후보 표시를 붙였습니다.

1. 이전과 이후, 한눈에 비교

부분이전 (v1.0)이후 (해커톤)
번역과 역번역사람이 직접 입력AI가 번역하고 다시 한국어로 옮겨 비교까지 해 둠
번역 검수규칙으로 단어 비교 (AI 아님)AI가 의미가 어긋난 곳을 찾고, 고쳐 보고, 안 되면 사람에게 넘김
문제 출제사람이 하나씩 제작AI가 초안을 만들고 사람이 고름
대시보드숫자만 보여줌AI가 "왜 이런지" 가설과 재교육 안을 제안

노동자 화면외부 요청 0건그대로 0건 확정 방향

2. 에이전트가 뭔가요

질문에 한 번 답하는 AI(챗봇)와 다릅니다.

챗봇
한 번 묻고 한 번 답합니다. 그다음은 사람이 다 합니다.
에이전트
목표를 받으면 스스로 여러 단계를 밟습니다. 결과를 확인해서 틀렸으면 다시 시도하고, 그래도 안 되면 사람에게 넘깁니다.
우리 에이전트의 원칙은 하나입니다. AI는 "초안과 제안"까지만, 승인은 반드시 사람. 에이전트가 만든 결과는 항상 "대기" 상태로 들어가고, 사람이 눌러야 효력이 생깁니다. 이 원칙은 이전 버전의 "AI 여기까지 · 승인은 사람"을 그대로 잇습니다.

3. 붙일 곳: 에이전트 후보 3개 후보

셋을 모두 만들지, 하나만 깊게 만들지는 아직 정하지 않았습니다. 혼자 개발할 가능성을 감안하면 하나를 깊게 만드는 쪽이 현실적입니다.

AI가 하는 단계사람이 하는 단계

A. 번역·검수 에이전트 후보

쓰는 사람: 운영자 · 줄이는 일: 번역 입력과 검수에 드는 수작업
  • 한국어 안전 문장을 6개 언어로 번역
  • 번역문을 다시 한국어로 옮김 (역번역)
  • 원문과 역번역을 비교 (기존 검수 도구 활용)
  • 어긋나면 다시 번역 (정해진 횟수까지)
  • 그래도 안 되면 사람에게 넘김, 통과해도 사람이 최종 승인

우리 제품의 핵심 관문(번역 검수)에 바로 붙기 때문에 설명하기 쉽고 심사에서 눈에 띄기 좋은 후보입니다.

B. 문제 출제 에이전트 후보

쓰는 사람: 담당자 · 줄이는 일: 그림 문제 하나하나 만드는 시간
  • 검수된 교육 문장을 읽음
  • 그림 문제(위험 위치 누르기, 고르기, 짝 맞추기) 초안 작성
  • 위험 위치 좌표를 기존 좌표 도구로 지정
  • 문장 길이 등 기존 규칙에 맞는지 자동 확인
  • 담당자가 보고 고르거나 고쳐서 채택

C. 현장 신호 에이전트 후보

쓰는 사람: 담당자 · 줄이는 일: 숫자를 읽고 대책을 정하는 일
  • 대시보드의 진도와 익명 제보를 함께 분석
  • "이 항목이 약한 이유" 가설 제시
  • 비슷한 제보를 묶어 중복 정리
  • 재교육 지시서 초안 작성
  • 담당자가 판단하고 발행

특정 개인을 가리키는 결과는 만들지 않습니다. 개인 평가 금지 원칙을 지키기 위해서입니다.

4. 구조는 어떻게 달라지나 후보

지금은 서버가 없습니다. AI를 쓰려면 비밀 열쇠(API 키)를 안전하게 둘 곳이 필요해서, 작은 서버 기능 하나가 처음으로 들어옵니다.

노동자 화면

  • 그대로 둡니다
  • 외부 요청 0건 유지
  • 인터넷 없이도 동작
  • AI와 직접 연결하지 않음

담당자·운영자 화면

  • AI 호출을 허용
  • 호출은 Vercel의 작은 서버 기능(/api)을 거침
  • AI 키는 화면 코드가 아니라 서버 설정에만 보관
  • AI 실패 시 기존 수동 방법으로 되돌아감
서버 기능을 쓰려면 배포 설정(Root Directory)을 바꿔야 하고, 이는 소유자의 승인이 필요한 작업입니다. 그래서 실제 작업 전에 확인하기로 했습니다.

5. 안전장치: 바뀌지 않는 것

사람이 결정한다.
에이전트 결과는 항상 "대기" 상태입니다.
검수된 문장만 지시가 된다.
AI가 만든 문장도 검수를 통과해야만 교육에 나갑니다.
AI가 고장 나도 서비스는 돈다.
실패하면 이전 방식(수동 입력)으로 돌아갑니다.
익명과 개인 보호.
제보자를 식별하거나 개인을 평가하는 결과는 만들지 않습니다.
시험도 방식이 바뀝니다. AI는 매번 답이 다르므로 "내용이 맞는가"를 시험하지 않고, 가짜 AI 응답을 넣어서 경계선(대기 상태 유지, 실패 시 복귀 등)이 지켜지는지를 시험합니다.

6. 평가표에 어떻게 대응하나

아이디어톤 평가표 기준입니다. 해커톤 평가표가 공지되면 다시 맞춥니다.

20문제정의: 이해를 확인할 길이 없다는 문제는 그대로 유효
20AI 활용: 지금 가장 약한 곳. 에이전트가 정확히 여기를 채움
30해결방식: "사람이 승인하는 AI"가 차별점. 서버 기능으로 확장성도 설명 가능
30실행력·발표: 실제 동작하는 시연 하나를 깊게 보여주는 것이 중요
