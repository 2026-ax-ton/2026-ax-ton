지금까지 만든 것: 이주노동자 안전교육 이해도 검증 플랫폼

해커톤에서 무엇을 바꿀지 이야기하려면, 먼저 "지금 무엇이 있고 무엇이 없는지"를 같이 알아야 합니다. 이 문서는 비전공자 팀원을 위한 현재 상태 설명입니다.

문제동작 흐름사용자 3종화면 11개되는 것/안 되는 것AI 공백지키는 원칙

1. 풀려는 문제

안전교육은 매년 하는데, 외국인 노동자가 내용을 이해했는지는 아무도 확인하지 못합니다.

서명은 참석의 증거일 뿐, 이해의 증거가 아니다.
지금 현장은
교육 시간에 한국어로 설명하고, 출석부에 서명을 받으면 끝납니다. 말이 통하지 않아도 서명은 됩니다.
그래서 생기는 일
이해하지 못한 채 위험한 작업에 들어갑니다. 사고가 나면 "교육했다"는 서명만 남습니다.

2. 이 플랫폼이 일하는 순서

글을 못 읽어도 끝까지 할 수 있게, 소리와 그림 중심으로 만들었습니다.

  1. 사업장 등록담당자가 회사와 노동자, 사용 언어를 입력합니다.
  2. 번역 검수 (관문)운영자가 번역문과 역번역(다시 한국어로 옮긴 글)을 비교해 승인합니다. 승인된 문장만 교육에 쓰입니다.
  3. 교육 만들기승인된 문장으로 교육 자료와 문제를 구성합니다.
  4. 노동자 음성 수강노동자가 자기 언어로 소리를 들으며 교육을 받습니다.
  5. 그림으로 이해도 확인글 대신 그림 문제(위험한 곳 누르기, 고르기, 짝 맞추기)로 이해를 확인합니다.
  6. 대시보드로 약한 곳 파악담당자가 어떤 항목에서 많이 틀리는지 봅니다.
  7. 증빙 인쇄서명이 아니라 "이해했다는 기록"을 인쇄해 보관합니다.
별도 기능
노동자가 현장 위험을 익명으로 제보할 수 있고, 담당자와 이야기하는 대화 화면이 있습니다.

3. 쓰는 사람 3종류

노동자

코랄색 화면

교육을 듣고 문제를 풉니다. 제보도 합니다. 6개 언어를 지원합니다.

담당자

보라색 화면

사업장의 교육을 만들고 결과를 봅니다. 대시보드와 증빙을 다룹니다.

운영자

보라색 화면

번역 검수를 맡습니다. 승인 전에는 아무 문장도 교육에 나가지 않습니다.

5. 지금 되는 것, 안 되는 것

되는 것

  • 끝까지 이어지는 전체 흐름 (등록에서 증빙까지)
  • 인터넷 없이도 동작 (오프라인 지원)
  • 서버 없이 인터넷 주소로 배포 (Vercel 자동 배포)
  • 자동 점검 테스트 1,613개 통과 (v1.0 시점)
  • 노동자 화면에서 외부로 나가는 요청 0건

안 되는 것

  • 서버와 DB가 없어서 기기 간 데이터 공유가 안 됩니다
  • 로그인은 흉내(모의)만 냅니다
  • 사진과 음성 첨부 제보가 안 됩니다
  • 기한 알림이 없습니다
  • 휴대폰 카메라로 QR 읽기 시험과, 글 없이 끝까지 해보는 실사용 시험을 아직 못 했습니다
  • 문제 문장 자체의 검수는 아직 안 됐습니다

6. 가장 큰 빈칸: AI가 없다

이 프로젝트는 "AI 해커톤"에 나가지만, 현재 버전에는 AI가 실제로 일하는 곳이 없습니다. 번역과 검수가 전부 사람 손입니다.

번역문과 역번역사람이 직접 입력합니다.
검수 도구 (review.js)단어를 규칙으로 비교하고 "아니다"가 뒤집혔는지 확인하는 정도입니다. AI가 아닙니다.
문제 출제사람이 하나씩 만듭니다.
대시보드 해석숫자는 보여주지만 "왜 그런지"와 "무엇을 할지"는 사람이 읽어냅니다.

이 빈칸이 해커톤에서 채울 부분입니다. 다음 문서(개선 후)에서 설명합니다.
