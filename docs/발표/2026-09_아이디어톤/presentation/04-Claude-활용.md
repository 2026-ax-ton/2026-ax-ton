# 04. Claude 활용 — 어떻게, 왜 그렇게 썼나

> **평가지표** — AI(Claude) 활용 과정의 **구체성** (10) · AI 활용의 **문제해결 기여도** (10) = **20점**
> 지표 원문: *"Claude Code를 **어떻게, 왜 그렇게** 활용했는지 구체적으로 설명하는가"*

---

## 0. 먼저 — AI 가 두 군데 있습니다. 섞어 말하면 안 됩니다

```
1층  제품 안의 AI   — 사용자가 만나는 AI. 어디까지가 AI 인지 화면에 적혀 있다
2층  개발에 쓴 AI   — Claude Code. 이 코드베이스가 만들어진 방식
```

**평가지표가 묻는 것은 주로 2층**이지만, **1층에서 "AI 를 어디까지만 쓸지
정한 것" 자체가 설계**라는 이야기가 이 프로젝트의 색깔입니다.

## 1. 한 문장으로

> ## **"AI 에게 코드를 시킨 것이 아니라,**
> ## **AI 가 지켜야 할 규칙과 스스로를 의심하는 절차를 먼저 만들고**
> ## **그 안에서 일하게 했습니다."**

## 2. 2층 — 개발에 쓴 Claude Code (구체성 10점)

### ① `CLAUDE.md` — 규칙을 세션마다 자동으로 주입

저장소 루트의 `CLAUDE.md` 를 Claude Code 가 **매 세션 자동으로 읽습니다.**
아무것도 붙여넣지 않아도 적용됩니다. 여기에 **제품 원칙과 기술 제약**을 적었습니다.

| 갈래 | 내용 |
|---|---|
| **코드 규칙** | 외부 요청 0건 · `innerHTML` 금지 · ES 모듈 금지 · 터치 타깃 60px · 색상만으로 상태 구분 금지 |
| **제품 원칙** | 검수된 문구만 안전 지시로 · 신고는 익명 · 미이수를 숨기지 않음 · **"면책" 표현 금지** |
| **데이터 계약** | `localStorage` 를 직접 부르지 않고 `Store` 를 거친다 |
| **git 규칙** | `main` 직접 push 금지 · `--force` 금지 · **훅 건너뛰기 금지** |

> **왜 그렇게 했나** — **혼자 개발하면 원칙은 조용히 무너집니다.**
> *"이번만 예외로"* 가 쌓이면 어느 순간 다른 제품이 되어 있습니다.
> **사람이 매번 기억하는 대신, 도구가 매번 읽게** 했습니다.

### ② 문서를 세션 간 기억으로 — *"docs 보고 바로 진행해줘"*

Claude Code 는 세션이 끊기면 맥락을 잃습니다. 그래서 **저장소 안 문서**를
기억 장치로 썼습니다.

| 문서 | 역할 |
|---|---|
| `docs/07-next-tasks.md` 맨 위 **"★ 지난 세션이 끝난 자리"** | 지금 상태 + 다음 한 걸음. **이것만 보면 이어갈 수 있음** |
| `docs/devlog/byeonsoyun.md` | **막혔던 것 / 어떻게 풀었는지.** 왜 이 코드가 이렇게 생겼는지 |
| 각 파일 맨 위 주석 | 그 화면이 **코드로 지키는 제품 원칙** |
| 화면 안 "여기부터 채우시면 됩니다" 칸 | 그 화면에 남은 일 |

**실제로 작동한 사례** — 2026-08-27 세션이 작업 도중 **세션 한도로 끊겼습니다.**
다음 세션이 `07-next-tasks.md` 와 작업대에 남은 코드만 보고 그대로 이어갔습니다.

> **이 문서 폴더도 그 방식의 결과입니다.** 새 채팅창을 열고
> *"docs 보고 바로 진행해줘"* 라고만 치면 이어집니다.

### ③ 제품 원칙을 **문서가 아니라 검사로** 박기

**문서에만 적힌 규칙은 지켜지지 않습니다.** 그래서 자동 검사가 봅니다.

- 신고 데이터에 신고자를 식별할 값이 **없는지**
- **미이수자를 숨기는 경로**가 생기지 않았는지
- 증빙에 **"면책"** 이라는 표현이 없는지
- `localStorage` 를 직접 부르는 코드가 `store.js` **밖에 없는지**
- 이름을 감춘 글·댓글에서 **아이디가 새어 나가지 않는지**
- 재교육 지시가 **누적 횟수를 세거나 사람을 줄 세우지 않는지**
- **PC 화면에서 취약 항목이 이수율 타일보다 작아지지 않는지** (CSS 도 글로 읽어 확인)
- 문서와 화면의 "할 일" 칸이 **다른 말을 하지 않는지**

> **★ 마지막 둘이 이 프로젝트답습니다.**
> **레이아웃 한 줄**과 **문서 한 줄**로도 제품 원칙이 무너질 수 있어서
> 거기까지 검사를 붙였습니다.

### ④ ★★ "망가뜨려 보기" — AI 가 쓴 검사를 믿지 않는 절차

**이게 발표에서 가장 강한 대목입니다.**

> **검사를 쓰고 나면 항상 일부러 코드를 망가뜨려, 그 검사가 정말 잡는지 봅니다.
> 안 잡히면 그 검사는 아무것도 지키지 않는 것입니다.**

예를 들어 오늘(08-28) 오프라인 기능을 붙이고 나서 **네 방향으로** 망가뜨렸습니다 —
담을 목록에서 한 줄 빼기 · 쿼리 무시 옵션 빼기 · https 검사 빼기 ·
담기지도 않았는데 "오프라인 가능" 배지 그리기. **넷 다 잡혔습니다.**

> **왜 이 절차가 필요한가** —
> **AI 가 만든 것을 AI 가 검사하면 사이좋게 틀릴 수 있습니다.**
>
> 그래서 QR 검사에서는 **블록 표를 코드에서 가져오지 않고 검사 쪽에 따로 적었고**,
> **규격(ISO/IEC 18004)의 상수와 대조**했습니다 —
> **그 값들은 우리가 정할 수 있는 것이 아니기 때문**입니다.

### ⑤ 되돌리기 어려운 일은 사람에게 물어보기

`CLAUDE.md` 에 적어 뒀습니다 — **파일 삭제 · 브랜치 변경 · 데이터 모양 변경 ·
배포**는 먼저 물어봅니다. 실제로 배포(`main` push)와 문서 파일 삭제 전에
확인을 받았습니다.

### ⑥ 개발일지 — AI 가 쓰고 사람이 읽는 기록

한 덩어리가 끝날 때마다 **한 것 / 막혔던 것 / 남는 한계 / 다음에 할 것** 을
남겼습니다. **23편**입니다.

*"막혔던 것 / 어떻게 풀었는지"* 를 반드시 적게 한 이유는,
**며칠 뒤에는 기억나지 않고 그게 발표 재료**이기 때문입니다.
**이 발표 문서의 재료가 전부 거기서 나왔습니다.**

## 3. ★ AI 가 실제로 무엇을 잡아냈나 (기여도 10점)

> **"기여했다" 를 말로 하지 않고 잡아낸 것으로 보여 줍니다.**
> 전부 개발일지에 날짜와 함께 기록돼 있습니다.

| # | 무엇을 잡았나 | 왜 위험했나 |
|---|---|---|
| **1** | **답이 어느 문항의 것인지 어긋날 수 있던 잠재 버그** — `answers` 가 자리(index)로만 문항을 가리키고 있었음 | 문항 하나를 내리면 뒤에 푼 사람의 답이 한 칸씩 밀려, **대시보드가 "끼임 항목 정답률"이라 말하면서 다른 문항의 숫자를 보여 줌.** 그걸 보고 교육을 고침 |
| **2** | **QR 이 그림은 멀쩡한데 스캔이 안 되던 고장** — 형식정보 자리를 막으면서 타이밍 무늬 두 칸을 덮어씀 | **되읽기 검사로는 안 잡혔고 규격 대조 검사가 잡음.** "내 글씨를 내가 읽는" 검사의 한계 |
| **3** | **카카오톡 안에서 음성이 조용히 실패** | 카톡 브라우저가 있다고 대답하고 `speak()` 도 받아 놓고 **아무 소리도 안 냄.** 글을 못 읽는 사람에게는 **그 화면이 통째로 빈 화면**인데 그대로 통과함 |
| **4** | **"남의 재교육 지시는 안 보인다" 검사가 우연히 통과하고 있었음** | 예시 데이터가 다른 공정이라 **다른 필터에 먼저 걸렸음.** 거르기 코드를 지워도 통과했음 |
| **5** | **항상 통과하게 돼 있던 검사** — `items.every(...) \|\| items.length === 2` | 뒤 조건이 늘 참이라 **아무것도 안 지키고 있었음** |
| **6** | **오늘(08-28) 오프라인 작업 중 `UI.$$` 가 조용히 `UI.$` 로 바뀜** | 치환 과정에서 `$$` 가 리터럴 `$` 한 개로 줄어드는 JS 규칙에 걸림. **회원가입 화면이 죽었는데 새로 쓴 검사가 그 자리에서 잡음** |

> **★ 6번이 특히 좋은 이야기입니다.**
> *"오늘도 하나 났습니다. 그리고 **그날 새로 쓴 검사가 그걸 잡았습니다.**
> 이게 저희가 말하는 '스스로를 의심하는 절차' 입니다."*

### 그리고 잡은 것만큼 중요한 것 — **안 하기로 정한 것**

AI 는 시키면 만듭니다. **안 만드는 결정을 사람이 해야 했습니다.**

| 안 만든 것 | 왜 |
|---|---|
| 증빙의 걸러 보기 · 결과순 정렬 | **정렬만 바꿔도 미이수자를 밀어내는 통로**가 됨 |
| "재교육 n회" 누적 횟수 | 인사 평가 자료가 됨 |
| 목업에 있던 **"오프라인 가능" 배지** (오프라인이 안 되던 시절) | **화면이 거짓말을 하면 안 됨.** 오프라인이 실제로 되는 오늘에야 붙였고, 그것도 **정말 담겼을 때만** 뜨게 함 |
| 목업의 **"사진 보기" · "조치 결과 회신"** | 지금 안 되는 일. 시안에 있다고 옮기면 화면이 거짓말을 함 |

## 4. 1층 — 제품 안의 AI

### 어디까지가 AI 인지 화면에 그대로 적혀 있습니다

| 화면 | 고지 | 전문 |
|---|---|---|
| **기능9 라이브러리** | `AI 여기까지` | *"초안 번역 · 역번역 대조 · 음성 합성까지가 AI 입니다. **승인은 사람이 합니다.**"* |
| **기능2 교육 만들기** | `AI 여기까지` | *"**AI 는 안전 문구를 새로 쓰지 않습니다.** 사람이 검수를 마친 라이브러리에서 고르기만 합니다."* |
| **기능6 대시보드** | `AI 개입 없음` | *"이 화면의 숫자는 노동자가 실제로 답한 기록을 그대로 센 것입니다. **추정하거나 보정하지 않습니다.**"* |

### ★ 왜 AI 를 일부러 제한했나

**이 제품에서 AI 가 틀리면 사람이 다칩니다.**

> 번역에서 부정문이 뒤집히면 *"보호구를 착용하지 마시오"* 가 됩니다.
> **오역이 그대로 사고가 됩니다.**

| AI 가 하는 것 | 사람이 하는 것 |
|---|---|
| 초벌 번역 (초안) | **승인 / 중지 판정** |
| **역번역 대조 — 사람이 볼 곳을 좁혀 줌** | 뜻이 뒤집혔는지 최종 확인 |
| 음성 합성 | 음성이 알아들을 만한지 |

> **"AI 를 어디까지만 쓸지 정하는 것" 자체가 이 제품의 설계입니다.**

### `review.js` — 왜 "부정 뒤집힘만" 크게 경고하나

> 낱말이 다른 것만으로는 위험을 가릴 수 없습니다.
> *"환기팬이 돌지 않으면"* → *"팬이 꺼져 있으면"* 은 **말만 바꿔 쓴 것**이고,
> *"손을 넣지 마십시오"* → *"손을 넣어도 됩니다"* 는 **정반대 지시**입니다.
> 둘을 같은 세기로 표시하면 운영자가 표시를 무시하게 되고,
> 그러면 정작 **뜻이 뒤집힌 문구가 그냥 지나갑니다.**

**경고를 많이 하는 것이 안전한 게 아닙니다. 무시하게 만들면 없느니만 못합니다.**

### 지금 도는 것 / 안 도는 것 — 정직하게

| | 상태 |
|---|---|
| **역번역 대조 로직** (`assets/review.js`) | ✅ **돕니다.** 낱말 차이와 **부정 뒤집힘**을 다른 세기로 표시 |
| **음성 합성** | ✅ 돕니다 (브라우저 `speechSynthesis`) |
| **초벌 번역 자동 생성** | ❌ **아직 안 돕니다.** 외부 요청 0건 규칙 때문에 클라우드 번역 API 를 부를 수 없음 → **서버가 생기는 시점** |

> **★ 발표에서 이렇게 말합니다.**
> *"AI 번역 연동은 아직 안 붙였습니다. 대신 **AI 가 낸 것을 사람이 어떻게
> 검증할지**를 먼저 만들었습니다 — 역번역 대조와 판정 권한 분리입니다.
> 순서를 그렇게 잡은 이유는, **검증 없이 번역만 붙이면 오역이 그대로 사고**가
> 되기 때문입니다."*

## 5. 이 항목에서 나올 질문 셋

| 질문 | 답의 뼈대 |
|---|---|
| **"AI 가 다 만든 거 아닌가요?"** | 코드는 대부분 Claude Code 가 썼습니다. **다만 무엇을 만들지, 무엇을 만들지 않을지, 그리고 만든 것을 어떻게 의심할지는 사람이 정했습니다.** 위 §3 의 "안 만든 것" 표가 그 결과입니다 |
| **"AI 가 틀린 적 없나요?"** | 있습니다. **6건을 이름 붙여 적어 뒀습니다** (§3). 그래서 **검사를 쓴 뒤 일부러 망가뜨려 보는 절차**를 매번 넣었습니다 |
| **"제품에 AI 가 실제로 돌긴 하나요?"** | 역번역 대조와 음성 합성은 돕니다. **초벌 번역은 아직 안 붙였습니다** — 외부 요청 0건 규칙 때문이고, 더 중요하게는 **검증 쪽을 먼저 만들어야 했기** 때문입니다 |
