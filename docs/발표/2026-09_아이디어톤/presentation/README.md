## 이 발표의 태도 — 먼저 정하고 갑니다

이 프로젝트는 **"안 되는 것을 안 된다고 적는 것"** 을 제품 안에서까지 규칙으로
삼았습니다. 미이수자를 숨기지 않고, 음성이 안 나면 화면에 적고, 오프라인이
안 되던 시절에는 목업에 있던 "오프라인 가능" 배지를 **일부러 안 붙였습니다.**

**발표도 같은 태도로 합니다.**

| 이렇게 말합니다 | 이렇게 말하지 않습니다 |
|---|---|
| "확인한 범위에서는 안 보였습니다" | "그런 서비스는 없습니다" |
| "AI 번역 연동은 아직 안 붙였습니다. 검증 쪽을 먼저 만들었습니다" | "AI 가 번역합니다" |
| "폰으로 눌러 봤고, **글 못 읽는 사람 실증은 아직**입니다" | "글 못 읽는 사람도 다 됩니다" |
| "서버가 빠진 완제품입니다" | "완성했습니다" |

**심사위원은 과장을 잡아내는 사람들입니다.** 한계를 먼저 말하면 나머지 말의
신뢰도가 올라갑니다. 그리고 이 프로젝트는 **한계를 이미 전부 적어 놨습니다** —
그게 강점입니다.
