## 4. 검증 4겹 — 어떻게 확인했나

### 겹 1. 자동 검사 (기계)

`tests/` 는 **실제 배포되는 화면 스크립트를 그대로** 돌립니다. 흉내 낸 코드가 아닙니다.
jsdom 으로 진짜 DOM 을 만들고, `store.js` → `auth.js` → `i18n.js` → 화면 JS 를
**실제 페이지와 같은 순서로** 실행합니다.

### 겹 2. ★ 일부러 망가뜨려 보기 (이게 이 프로젝트의 방식입니다)

**통과 개수가 늘어난 것으로 만족하지 않습니다.** 검사를 믿지 않으려고 코드를 일부러 깨 봅니다.

가장 최근 예 — **음성 되돌림에서 10가지를 망가뜨렸고 10가지 전부 잡혔습니다.**

| 무엇을 망가뜨렸나 | 잡혔나 |
|---|---|
| 소리 안 냄인데 한국어로 읽어 버리게 | 잡음 |
| 기본값을 한국어로 되돌리게 | 잡음 |
| 이상한 값 검증을 빼기 | 잡음 |
| 버튼 그림이 안 바뀌게 | 잡음 |
| 화면이 다시 그려 달라고 안 알리게 | 잡음 |
| 되돌림 표와 사전을 어긋내기 (양방향) | 잡음 |
| 한국어도 되돌림 대상으로 만들기 | 잡음 |
| 번역 배지 가드 빼기 | 잡음 |
| 선택 칩 하나 빼기 | 잡음 |

> **말할 것** — *"검사가 안 잡으면 그 검사는 아무것도 지키지 않는 겁니다.
> 그래서 **잡히는지 확인하고 나서야** 그 검사를 믿습니다."*

### 겹 3. 손으로 확인 (사람)

- **안드로이드 폰 실기** — 버튼이 장갑 낀 손 크기로 눌리는지, 크메르어 글자가 안 깨지는지
- 여기서 **카카오톡 안에서 음성이 조용히 안 나는 것**을 찾았습니다 → 고쳤습니다
- **비행기 모드로 잘라 보기** — 인터넷 없이 화면이 열리는지
- 순서는 [`../10-checklist.md`](../../../10-checklist.md) 에 있습니다

### 겹 4. 배포된 주소를 실제로 열어 보기

**push 됐다고 배포된 것이 아닙니다.** 매번 실제 주소를 열어 확인합니다.

```
curl -s https://2026-ax-ton.vercel.app/assets/ui.js | grep notifyVoice
```

그리고 `/docs/` `/tests/` `/CLAUDE.md` 가 **404 인 것**도 확인합니다 —
문서와 검사 코드가 공개되면 안 되니까요.

## 5. ★★ 검사가 증명하는 것 / 증명하지 못하는 것

**이 절이 신뢰도의 핵심입니다.** 1,463건을 자랑하는 것보다 **한계를 아는 것**이 점수가 됩니다.

| 검사가 **증명하는 것** | 검사가 **증명하지 못하는 것** |
|---|---|
| 화면이 실제 데이터로 끝까지 돈다 | **사람이 그 화면을 이해하는지** |
| 신고에 식별값이 저장되지 않는다 | 현장에서 **실제로 신고를 하는지** |
| 미이수를 숨기는 경로가 코드에 없다 | 감독기관이 이 증빙을 **인정하는지** |
| 검수 안 된 문구가 화면에 안 나온다 | **번역이 실제로 맞는지** (역번역도 같은 사람이 넣음) |
| 소리가 났는지 안 났는지 판정한다 | **발음이 알아들을 만한지** |
| 외부 요청이 0건이다 | 서버가 생겼을 때도 그럴지 |
| QR 이 규격에 맞게 인코딩된다 | **폰 카메라가 실제로 읽는지** (아직 안 찍어 봤습니다) |

> ### 발표에서 쓸 한 수
> *"검사 1,463건이 증명하는 것은 **'코드가 우리가 정한 원칙을 어기지 않았다'** 까지입니다.
> **'사람이 이해했다' 는 코드로 증명할 수 없습니다.**
> 그건 실제 노동자에게 보여 줘야 알 수 있고, 저희는 아직 못 했습니다."*

**이렇게 말하는 것이 "1,463건 통과했습니다" 보다 강합니다.**

## 6. 외부 요청 0건 — 예외 2개까지 말하는 것이 정확합니다

**"외부 요청 0건" 은 이 프로젝트의 자랑입니다.** CDN · 웹폰트 · 외부 이미지 · npm 패키지가
하나도 없습니다. **픽토그램은 좌표만 든 선 아이콘**이고 (`assets/icons.js`),
**QR 도 직접 만들었습니다** (`assets/qr.js`). 아이콘 폰트조차 쓰지 않습니다.

그런데 **예외가 정확히 2개** 있고, 숨기지 않았습니다.

| 예외 | 무엇 | 어디에 적어 뒀나 |
|---|---|---|
| `sw.js` 의 `fetch(req)` | 같은 오리진 요청을 그대로 흘려보냄 | 코드 주석 + 검사가 "외부 주소 0건" 을 따로 지킴 |
| 신고 화면의 **받아쓰기** | 브라우저가 소리를 인식 서버로 보냄 | **화면에 적혀 있음** — *"이 기능만 인터넷이 필요합니다"* |

> **말할 것** — *"받아쓰기는 저희가 서버를 부르는 게 아니라 브라우저가 부르는 겁니다.
> 그래도 결과는 같으니 **화면에 적었습니다.** 예외를 셋으로 늘리지 않는다는 규칙도
> `CLAUDE.md` 에 넣었습니다."*
