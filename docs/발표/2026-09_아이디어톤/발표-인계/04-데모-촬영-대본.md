# 04. 데모 촬영 대본 — 컷 단위

> **왜 라이브 시연을 안 하나**
> 현장 인터넷 · 폰 음성 · 브라우저 데이터 · QR 조명 — **변수가 넷**입니다.
> 하나만 어긋나도 발표 150초가 무너집니다.
> **미리 찍어 두고, 라이브는 보험으로만 남겨 둡니다.**

---

## 0. 촬영 전 준비 — 이걸 안 하면 다시 찍습니다

| 체크 | 무엇 | 왜 |
|---|---|---|
| ☐ | **PC 크롬 새 창** (시크릿 아님) | 시크릿은 새로고침하면 데이터가 날아갑니다 |
| ☐ | 배포 주소 `https://2026-ax-ton.vercel.app` 로 열기 | `file://` 은 주소창이 지저분하고 오프라인 시연이 안 됩니다 |
| ☐ | 처음 열면 **예시 데이터가 저절로 채워짐** 확인 | 안 채워지면 저장소가 막힌 브라우저입니다 |
| ☐ | 브라우저 **확대 110~125%** | 영상에서 글자가 작으면 아무것도 안 보입니다 |
| ☐ | **북마크바 숨기기** (Ctrl+Shift+B), 탭 1개만 | 화면이 깔끔해야 내용이 보입니다 |
| ☐ | PC **소리 켜 두고 녹음 포함** | 음성이 이 제품의 절반입니다 |
| ☐ | 알림 끄기 (방해 금지 모드) | 촬영 중 팝업이 뜨면 다시 찍습니다 |
| ☐ | 폰은 **따로 찍기** (아래 컷 8·9) | PC 화면 녹화와 섞지 않습니다 |

### 형식

| 항목 | 권장 |
|---|---|
| 형식 | **MP4** (H.264). **GIF 금지** — 용량이 크고 화질이 무너지고 소리가 없습니다 |
| 해상도 | 1920×1080 |
| 컷 길이 | 컷당 **15~25초**. 넘으면 잘라서 두 컷으로 |
| 도구 | Windows `Win+G` (Xbox Game Bar) 또는 OBS |
| 자막 | **컷마다 한 줄**씩 넣기 — 소리 없이 봐도 뜻이 남게 |
| 마우스 | **천천히.** 클릭 전에 0.5초 멈추기 |

## 1. 컷 목록 — 9컷, 합계 약 150초

발표 대본의 시연 절(150초)에 그대로 맞췄습니다.
**시간이 없으면 컷 3·4·7 만** 쓰세요 (§3 참고).

### 컷 1 — 검수되지 않은 번역은 나가지 않는다 (20초)

| | |
|---|---|
| **계정** | `oper@safety.kr` / `1234` |
| **길** | 로그인 → 문구 라이브러리 → `ph-3` 찾기 |
| **보여줄 것** | `ph-3` 이 **인도네시아어만 중지**된 상태. 역번역이 *"프레스가 꺼지면 손을 넣어도 됩니다"* 로 **뜻이 뒤집힌 것** |
| **자막** | `번역이 정반대로 뒤집혔습니다 — 인도네시아어만 중지했습니다` |
| **놓치면 안 되는 것** | 크메르어는 **계속 "검수 완료"** 인 것을 같은 화면에서 보여 주기 |

### 컷 2 — 그래서 노동자 화면이 갈린다 (20초)

| | |
|---|---|
| **계정** | `W-4821-07` (크메르어) → 교육 |
| **보여줄 것** | 컷 1 에서 본 그 문구가 **크메르어 노동자에게는 그대로 나온다** |
| **자막** | `한 언어의 오역이 다른 언어 노동자의 안전 지시를 빼앗지 않습니다` |
| **선택** | 시간 있으면 `W-4821-11`(인도네시아어) 로 바꿔 **그 문구가 빠진 것**까지 |

### 컷 3 — ★ 이해도 검증 (25초) — **가장 중요한 컷**

| | |
|---|---|
| **계정** | `W-4821-07` → 이해도 검증 |
| **보여줄 것** | **hotspot** — 설비 그림에서 위험 지점을 **손가락으로 짚는** 문항 |
| **자막** | `글자를 한 자도 읽지 않고 답합니다` |
| **★ 반드시** | **🔊 를 눌러 크메르어 음성이 나오는 것을 소리로 들려주기.** 이게 없으면 이 컷은 절반입니다 |
| **놓치면 안 되는 것** | 문항이 **글이 아니라 그림**인 것이 화면에 크게 보여야 합니다 |

### 컷 4 — ★ 일부러 틀려 보기 (20초) — **두 번째로 중요**

| | |
|---|---|
| **보여줄 것** | 틀린 답을 고르면 **"그 선택이 어떤 사고가 되는지"** 를 바로 말해 준다 |
| **자막** | `맞고 틀림만 알려 주면 다음에 또 같은 선택을 합니다` |
| **놓치면 안 되는 것** | 미통과가 **"교육의 실패"** 로 표기되는 것 — *노동자 평가가 아니라는 것* |

### 컷 5 — 담당자는 무엇을 보는가 (20초)

| | |
|---|---|
| **계정** | `kim@daesung.co.kr` / `1234` → 대시보드 |
| **보여줄 것** | 이수율이 아니라 **"어느 언어의 누가 무엇에서 막혔는지"**. 취약 항목 막대 |
| **자막** | `이수율 100%는 사고를 예측하지 못합니다` |
| **놓치면 안 되는 것** | 화면에 적힌 정책 문장 — *"노동자 평가가 아닙니다 / 미통과는 교육의 실패입니다"* |

### 컷 6 — 재교육 지시 → 루프가 돈다 (15초)

| | |
|---|---|
| **길** | 조치 대상 → 재교육 지시 |
| **자막** | `교육을 고치고 다시 보냅니다 — 이 루프가 다른 서비스에 없습니다` |

### 컷 7 — ★ 증빙 (15초) — **세 번째로 중요**

| | |
|---|---|
| **길** | 증빙 → 인쇄 미리보기 (Ctrl+P) |
| **보여줄 것** | 감독기관에 그대로 낼 수 있는 문서. **미이수자가 그대로 들어가 있는 것** |
| **자막** | `미이수자를 걸러 볼 수 있는 칸이 없습니다 — 숨길 수 있는 증빙은 증빙이 아닙니다` |
| **★ 말할 것** | *"이 화면에는 저장하는 코드가 아예 없습니다. 수정 불가를 규칙이 아니라 구조로 만들었습니다"* |

### 컷 8 — 폰 · QR (15초, 폰 촬영)

| | |
|---|---|
| **길** | PC: `kim@` → 콘텐츠 → 접속 주소 → QR 띄우기 / **폰 카메라로 찍기** |
| **보여줄 것** | 폰이 QR 을 읽고 **바로 그 교육 화면으로 들어오는 것** |
| **자막** | `현장에서는 QR 하나로 들어옵니다` |
| **★ 경고** | **이건 아직 실제로 안 찍어 봤습니다.** 촬영 전에 반드시 테스트하세요. 안 되면 **이 컷을 빼세요** — 발표 중에 안 찍히는 것이 훨씬 나쁩니다 |

### 컷 9 — 오프라인 (15초, 폰 촬영) · 보너스

| | |
|---|---|
| **길** | 폰에서 교육 화면 열어 둔 뒤 **비행기 모드 켜고 새로고침** |
| **보여줄 것** | 인터넷이 끊겨도 화면이 열린다 |
| **자막** | `현장 인터넷은 약합니다 — 끊겨도 교육은 계속됩니다` |
| **★ 경고** | 홈 화면의 **"오프라인 가능" 표시는 실제 판정 결과**입니다. 고정 문구가 아닙니다 |

## 2. 자막에 쓸 문장 — 그대로 복사해서 쓰세요

```
1. 번역이 정반대로 뒤집혔습니다 — 인도네시아어만 중지했습니다
2. 한 언어의 오역이 다른 언어 노동자의 안전 지시를 빼앗지 않습니다
3. 글자를 한 자도 읽지 않고 답합니다
4. 맞고 틀림만 알려 주면 다음에 또 같은 선택을 합니다
5. 이수율 100%는 사고를 예측하지 못합니다
6. 교육을 고치고 다시 보냅니다
7. 미이수자를 걸러 볼 수 있는 칸이 없습니다
8. 현장에서는 QR 하나로 들어옵니다
9. 끊겨도 교육은 계속됩니다
```

## 3. 시간이 부족할 때 — 3컷만

| 컷 | 왜 이 셋인가 |
|---|---|
| **3** 이해도 검증 | 제품의 심장. 이것만 보여도 무엇을 만들었는지 전달됩니다 |
| **4** 일부러 틀리기 | "시험" 과 "교육" 의 차이가 여기서 갈립니다 |
| **7** 증빙 | 문제(서명부)와 해결(증빙)이 여기서 닫힙니다 |

**합계 60초.** 문제 제기 60초 + 이것 60초 + 마무리 30초 = 2분 30초로 발표가 됩니다.

## 4. 라이브 시연을 보험으로 남기는 법

영상을 틀되, **질문이 오면 그 자리에서 열 수 있게** 준비합니다.

| 상황 | 대응 |
|---|---|
| *"직접 해볼 수 있나요?"* | 노트북을 열어 **배포 주소**로 그 자리에서 (계정표를 인쇄해 두기) |
| 인터넷이 안 됨 | **`src/index.html` 더블클릭.** 빌드가 없어서 파일만 있으면 그대로 돕니다 ← **최후 보험** |
| 데이터가 비어 있음 | 새로고침 한 번이면 예시가 저절로 채워집니다 |
| 음성이 안 남 | **그것도 시연입니다** — 화면에 *"소리가 나지 않습니다"* 가 뜨는 것을 보여 주세요 |

> ### ★ 이건 사고가 아니라 기회입니다
> *"지금 소리가 안 나는데, **화면이 그걸 말하고 있습니다.**
> 조용히 실패하지 않게 만든 부분이 바로 이겁니다."*
