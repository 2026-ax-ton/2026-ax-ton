# 05. PPT ↔ 실제 프로그램 대조표

> **이 문서의 목적** — 슬라이드에 쓴 한 문장이 실제 코드와 어긋나면,
> 심사위원이 시연에서 그것을 봅니다. 그리고 **그 순간 나머지 전부를 의심합니다.**
>
> 개발을 한 사람만 이 대조를 할 수 있습니다. 그래서 제가 합니다.

---

## ★ 먼저 — 피드백 두 개는 이미 반영됐습니다

| 받은 피드백 | 상태 |
|---|---|
| *"음성 TTS 를 한국어가 아니라 사용자가 선택한 언어로 재생되도록 해야 될 것 같은디"* | **이미 그렇습니다.** 그 언어 음성이 기기에 있으면 그 언어로 읽습니다 (`VOICE_TAG`). 그리고 **2026-08-30 에 한 겹 더 넣었습니다** — 기기에 그 언어 음성이 **없을 때 한국어로 대신 읽던 것을 그만뒀습니다.** 뜻이 안 닿는 소리가 나면 사람은 "들었다" 고 넘어가기 때문입니다 |
| *"음성 신고기능 추가"* | **이미 있습니다.** 신고 화면 ③ 칸의 **🎤 말로 알리기.** 말하면 글자로 옮겨지고 **목소리는 저장하지 않습니다** (익명 신고라서) |

**둘 다 발표 문서에 아직 안 들어가 있습니다.** 아래 §3 참고.

## 1. 말해도 되는 것 — 코드로 증명됩니다

**슬라이드에 그대로 쓰세요.** 시연에서 그 자리에서 보여 줄 수 있습니다.

| 말할 문장 | 증거 |
|---|---|
| 화면 **11개가 실제 데이터로 끝까지 돕니다** | 배포 주소에서 바로 확인 |
| 자동 검사 **1,463건 / 14묶음 전부 통과** | `node tests/run-all.js` |
| **외부 요청 0건** (예외 2개는 화면에 적어 뒀습니다) | CDN·웹폰트·npm 0개. QR 도 직접 만들었습니다 |
| 문항 **3유형 전부 손가락으로만** 합니다 | hotspot · choice · match |
| 검수되지 않은 문구는 **어느 화면에도 안 나옵니다** | `Store.phraseOk` · 검사 136건 |
| **한 언어의 오역이 다른 언어를 안 내립니다** | 언어별 검수 판정. `ph-3` 으로 시연 |
| 증빙에는 **저장하는 코드가 아예 없습니다** | "수정 불가" 를 구조로 |
| 증빙·대시보드에 **미이수자를 숨기는 경로가 없습니다** | 걸러 보기·결과순 정렬 없음. 검사가 지킴 |
| **화면 글자가 6개 언어로 나옵니다** | 버튼·탭·배지·안내 음성 (`i18n.js`) |
| **문항과 선택지도 노동자의 언어로** 나옵니다 | `Store.qtext` |
| **인터넷이 끊겨도 화면이 열립니다** | `sw.js` · 폰 비행기 모드로 확인 |
| 신고는 **익명이고, 목소리를 저장하지 않습니다** | `reports` 에 식별값 없음. 검사가 지킴 |
| **QR 을 외부 라이브러리 없이 직접 만들었습니다** | `assets/qr.js` · 검사 75건 |
| 터치 타깃 **60px 이상** (장갑 낀 손) | `--tap-min` · CSS 검사 |
| **글자 크기 조절**이 됩니다 | `prefs.fontScale` |
| **서버를 붙일 자리를 `Store` 한 곳으로 좁혀 뒀습니다** | 화면 11개는 `localStorage` 를 직접 안 부릅니다 |
| 배포돼 있습니다 | `https://2026-ax-ton.vercel.app` |

## 2. ★★ 하면 거짓말이 되는 것 — 슬라이드에서 빼세요

**이 표가 이 문서에서 가장 중요합니다.**

| 쓰면 안 되는 표현 | 실제 | 대신 이렇게 |
|---|---|---|
| *"AI 가 번역합니다"* | **제품 안 AI 번역은 안 돕니다.** 번역은 사람이 입력하고, `review.js` 는 **역번역을 대조**만 합니다 | *"번역 검수를 사람이 하도록 만들고, AI 는 뜻이 뒤집혔는지 대조하는 데만 씁니다"* |
| *"실제 이주노동자에게 검증받았습니다"* | **안 했습니다** | *"아직 못 했습니다. 만든 사람은 어디를 눌러야 할지 이미 알아서 스스로 확인이 안 됩니다"* |
| *"법정 교육 증빙으로 인정됩니다"* / *"면책"* | **인정 여부를 확인하지 않았습니다.** 코드에 "면책" 이라는 단어를 못 쓰게 검사까지 걸어 뒀습니다 | *"감독기관에 제출할 수 있는 형태로 만들었습니다. 인정 여부는 확인하지 않았습니다"* |
| *"서버 / 데이터베이스"* | **없습니다.** 브라우저 저장소만 | *"서버 없이 만들고, 서버가 필요해지는 지점까지 정리해 뒀습니다"* |
| *"사진을 첨부해 신고합니다"* | **안 됩니다.** 5MB 벽 | *"사진이 필요해지는 시점이 서버가 필요해지는 시점입니다"* |
| *"조치 결과가 신고자 언어로 회신됩니다"* | **안 만들었습니다.** 목업에 있었지만 일부러 안 옮겼습니다 | 아예 말하지 않기 |
| *"오프라인에서 전부 동작합니다"* | **화면만 열립니다.** 받아쓰기는 인터넷이 필요하고, 쌓인 기록이 담당자에게 자동으로 안 갑니다 | *"인터넷이 끊겨도 교육은 계속됩니다"* |
| *"6개 언어 음성을 제공합니다"* | **브라우저 음성합성입니다.** 기기에 그 언어 음성이 없으면 안 납니다 | *"기기의 음성을 씁니다. 없으면 소리를 내지 않고 그 사실을 화면에 적습니다"* |
| *"번역 품질이 검증됐습니다"* | 번역과 역번역을 **같은 사람이 넣습니다.** 번역기를 두 번 돌리면 대조가 통과합니다 | *"대조 장치를 만들었고, 두 사람이 나눠 넣어야 진짜 대조가 됩니다"* |
| *"여러 사업장을 관리합니다"* | **사업장 1개 전제**입니다 | 말하지 않기 |
| *"기한이 지나면 알려 줍니다"* | **알림이 없습니다.** 담당자가 대시보드를 열어야 봅니다 | 말하지 않기 |
| *"QR 을 폰으로 찍어 확인했습니다"* | **아직 안 찍어 봤습니다.** 되읽기 검사는 "내 글씨를 내가 읽는 것" 입니다 | 촬영 전에 찍어 보고, 되면 말하기 |
| *"iOS 에서도 됩니다"* | **안드로이드만 확인했습니다** | *"안드로이드에서 확인했습니다"* |
| *"글자를 한 자도 안 읽고 끝까지 갈 수 있습니다"* | **설계는 그렇게 했지만 실증 못 했습니다** | *"그렇게 만들었고, 실제로 그런지는 다른 사람에게 건네 봐야 압니다"* ← **먼저 말하면 점수** |
| *"댓글도 고치고 지울 수 있습니다"* | 글은 되고 **댓글은 안 됩니다** | 말하지 않기 |

> ### 발표팀에게
> **위 표의 왼쪽 문장이 슬라이드에 하나라도 있으면 지우세요.**
> 심사위원이 시연 중에 확인할 수 있는 것들입니다.

## 3. ★ 빼면 아까운 것 — 만들었는데 발표 문서에 없습니다

발표 문서(`docs/발표/2026-09_아이디어톤/presentation/`)를 쓴 뒤에 세 덩어리를 더 만들었습니다.
**전부 발표에서 쓸 값이 있는데 아직 안 들어가 있습니다.**

### ① 화면 글자가 노동자의 언어로 나옵니다 (2026-08-28)

지금 발표 문서는 *"안전 문구와 문항이 그 언어로 나온다"* 까지만 말합니다.
실제로는 **거기까지 가는 길** — **버튼 · 하단 탭 · 배지 · 안내 음성** — 도 6개 언어입니다.

> **말할 것** — *"안전 문구만 번역해 놓고 버튼이 한국어면, 그 사람은 그 문구까지
> 도달하지 못합니다. 그래서 **동선 전체**를 그 사람의 언어로 만들었습니다."*
>
> **그리고 검사가 이걸 지킵니다** — 사전에 *"손을 넣지 마십시오"* 같은 문장이 들어오면
> 검사가 막습니다. 사전은 **검수를 지나지 않기** 때문에, 거기에 안전 지시가 들어오면
> **검수를 우회하는 통로가 새로 생기는 것**입니다.

### ② 말로 알리기 — 음성 신고 (2026-08-28)

> **말할 것** — *"글을 쓰기 어려운 사람이 **말만으로** 신고할 수 있습니다.
> 그런데 **목소리는 사람을 식별합니다.** 10~50인 사업장에서 담당자가 녹음을 들으면
> 누구인지 거의 확실히 압니다.
> 그래서 **말한 것을 글자로 바꾸고 오디오는 버립니다.** 기능이 하나 줄어드는 게 아니라,
> 익명이 깨지면 신고가 멈추고 이 제품의 선행지표가 함께 사라집니다."*

**AI 활용 항목에도 쓸 수 있습니다** — 받아쓰기가 브라우저 AI 이고,
**그것 때문에 "외부 요청 0건" 에 예외가 생긴 것을 숨기지 않고 화면에 적었습니다.**

### ③ 뜻이 안 닿는 소리를 내지 않습니다 (2026-08-30)

**이게 세 개 중 발표에서 가장 강한 이야기입니다.**

> **말할 것** — *"음성이 없을 때 한국어로 대신 읽어 주던 기능을 **일부러 없앴습니다.**
> 친절해 보이지만, 크메르어 노동자에게 한국어 소리는 뜻이 닿지 않습니다.
> **소리는 나는데 아무것도 전달되지 않으면 사람은 '들었다'고 생각하고 넘어갑니다.**
> 그리고 그대로 이해도 검증을 통과합니다.
> **서명이 참석의 증거일 뿐인 것과 정확히 같은 구조입니다** — 소리도 이해의 증거가 아닙니다.
> 그래서 기본은 소리를 안 내고, **왜 안 내는지를 그 사람의 언어로 화면에 적습니다.**
> 대신 말은 알아듣는데 글만 못 읽는 사람을 위해 **고를 수 있게** 남겨 뒀습니다."*

**이 이야기가 좋은 이유** — 이 팀이 *"기능을 늘리는 것"* 이 아니라
*"제품의 전제를 지키는 것"* 을 기준으로 판단한다는 증거입니다.
그리고 **기능을 뺀 이야기**라 따라 하기 어렵습니다.

### ④ 그 밖에 말할 값이 있는 것

| 무엇 | 왜 발표에 쓸 값이 있나 |
|---|---|
| **한국인 노동자 계정** (`W-4821-31`) | *"한국어도 노동자의 언어입니다. 되돌림이 아닙니다."* 한국어 사용자에게 "번역 준비 중" 배지를 안 띄우는 것까지 검사가 지킵니다 |
| **글자 크기를 계정이 아니라 기기에** 붙인 것 | *"계정에 넣으면 로그인해야 글자가 커지는데, **로그인 화면 글자가 안 보이는 사람은 거기서 막힙니다**"* — UX 판단의 좋은 예 |
| **CSS 정보 위계까지 검사** | 취약 항목 타일이 이수율 타일보다 작아지지 않는지를 **CSS 를 글로 읽어** 검사합니다. *"CSS 한 줄로 정보 위계가 뒤집힐 수 있어서"* |
| **가짜 QR 그림을 안 그린 것** | *"붙여 놓고 안 찍히는 것이 가장 나쁩니다"* |
| **일부러 망가뜨려 보기 10건** | 가장 최근 것. [`03`](03-검증-신뢰도와-숫자.md) §4 |
