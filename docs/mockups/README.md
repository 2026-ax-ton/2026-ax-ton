# 목업 — 옮겨 오면 되는 화면들

**여기 있는 파일은 실제 서비스가 아닙니다.** 기획 문서를 눈으로 볼 수 있게 옮긴 화면 구성안입니다.
버튼은 목업 동작이고 데이터도 가짜입니다.

**새로 만들지 마세요. 여기 있는 걸 옮겨 오면 훨씬 빠릅니다.**

## 여는 법

파일을 더블클릭하면 그대로 열립니다. 외부 요청이 없어서 인터넷 없이도 뜹니다.

`-pc` 가 붙은 것은 데스크톱용, 안 붙은 것은 모바일용입니다.

## 옮길 때 주의할 것

목업은 **폰 목업 껍데기**를 두르고 있습니다. 실제 화면에는 그게 없습니다.

**버리는 것**

- `<main class="stage">` `<div class="phone">` `<div class="statusbar">` `<div class="app">` — 폰 모양 액자
- 맨 아래 `<div class="caption">` — 근거를 적어 둔 설명 상자
- `<h2 class="stage-title">` — 화면 번호 제목

**가져오는 것**

- `<div class="scroll">` 안의 내용 전체 — 이게 진짜 화면입니다
- `.card` `.badge` `.sec-head` `.kpi-row` `.bar-list` `.queue` 같은 클래스 이름 — 그대로 씁니다
- 화면 안에 적힌 문장들 — **특히 "이 목록은 노동자 평가가 아니라 콘텐츠 개선 신호입니다" 같은 문장은
  기획에서 온 것이라 빼지 마세요**

**바꾸는 것**

- CSS 경로 → `../assets/style.css` 처럼 (여기 `assets/` 는 참고용 사본입니다)
- 가짜 숫자와 이름 → `Store` 에서 읽은 실제 데이터로
- `<button>` 으로 된 하단 탭 → `src/` 의 다른 화면처럼 `<a>` 로

`src/admin/setup.html` 이 이미 이 방식으로 옮겨진 화면입니다. 그걸 참고하세요.

---

## `assets/` 폴더

목업이 참조하는 CSS 사본입니다. **여기 있는 걸 고치지 마세요.**
실제로 쓰는 것은 `src/assets/` 쪽이고, 이건 목업이 깨지지 않게 두는 사본입니다.

`style-pc.css` 는 목업 전용 골격(`.desk` `.topbar` `.layout`)이라
실제 화면에는 옮기지 않았습니다. 클래스 이름이 새 마크업과 충돌합니다.
