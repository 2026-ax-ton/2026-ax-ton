### ★ 코드가 아니라 사람이 해야 하는 확인 두 가지

만들 것은 없습니다. **해 보는 것**이 남았습니다. 둘 다 발표에서 나올 질문입니다.

1. **폰 카메라로 QR 을 실제로 찍어 보기** —
   `kim@daesung.co.kr` → 콘텐츠 → 발급한 교육의 **접속 주소** → QR.
   되읽기 검사는 "내 글씨를 내가 읽는 것" 이라 규격 자체를 오해했으면 못 잡습니다
2. **글을 모르는 척하고, 또는 아무 설명 없이 다른 사람에게 폰을 건네 보기** —
   *"글자를 한 자도 안 읽고 끝까지"* 가 이 제품의 핵심 주장입니다 (V3 의 남은 한계)
3. **크메르어 음성이 없는 폰에서 소리가 안 나는 것을 눈으로 보기** —
   검사는 가짜 `speechSynthesis` 로 그 상황을 흉내 낸 것입니다.
   `10-checklist.md` **B0-3** 에 순서가 있습니다 (음성이 있는 기기면 네팔어·태국어로 바꿔 보기)
4. **★ 내보내기 → 불러오기로 재교육 지시가 살아 오는지 눈으로 보기** (2026-09-04 고침) —
   기능1 **내보내기** → 데이터 지우기 → **불러오기** → 대시보드에 지시가 그대로인지.
   검사는 붙였지만 화면으로는 아직 안 봤습니다

> **★ 무엇을 어떻게 확인하는지는 [`10-checklist.md`](10-checklist.md) 에
> 순서대로 있습니다** — 성공/실패 케이스와 **"이건 안 되는 게 맞다"** 는 경계까지.

### 지난 항목들에서 생긴 규칙 (새 코드가 어겨서는 안 되는 것)

- 문항 문구·선택지는 **`Store.qtext(q, lang, field)`** 로만 읽습니다.
  화면에서 `q.i18n` 을 직접 뒤지지 않습니다 — 번역 배열 길이 검사가 그 함수 한 곳에 있고,
  어긋나면 `answer` 인덱스가 다른 선택지를 가리킵니다
- 문구 판정은 **`Store.phraseOk(p, lang)`** 로만 읽습니다.
  `p.status` 를 직접 보면 언어별 판정이 무시되고, 한 언어의 오역으로
  다른 언어 노동자가 안전 지시를 잃습니다
- 음성이 **났는지 안 났는지를 브라우저 이름으로 넘겨짚지 않습니다.**
  `UI.speak()` 가 실제 신호를 보고 판정하고, 판정은 `UI.voiceNote()` 와
  버튼 그림(🔊 → 🔇)에 함께 나옵니다. 넘겨짚기 시작하면 다음에 나올
  인앱 브라우저를 또 놓칩니다
- 로그인 화면의 자동 채우기는 **`Seed.fillIfEmpty()`** 만 부릅니다.
  `Seed.fill()` 로 바꾸면 담당자가 등록한 사업장이 새로고침마다 예시로 되돌아갑니다
- 교육 기한 배지는 **`UI.dueBadge(dueAt)`** 로만 그립니다.
  같은 계산을 화면마다 두면 한쪽만 고쳐져서 콘텐츠 화면과 대시보드가
  서로 다른 날짜를 말합니다
- 새로 만든 안전 문구는 **`status: 'waiting'`(검수 대기) 으로만 들어갑니다.**
  추가 폼에서 `reviewed` 를 만들 수 있게 하면 검수를 지나지 않은 문구가 그대로
  안전 지시가 되고, 기능9 라는 화면이 있는 이유가 사라집니다
- 항목을 끝내면 **화면 안 "여기부터 채우시면 됩니다" 칸에서도 그 줄을 지웁니다.**
  그리고 `tests/test-docs.js` 의 `DONE` 목록에 한 줄 더합니다 — 그래야 다음에
  또 어긋나면 검사가 잡습니다. 문서와 화면이 다른 말을 하면 사람은 화면을 믿습니다
- 무엇을 **골라 뽑을 수 있게 만들면, 무엇이 빠졌는지도 함께 적습니다.**
  대시보드의 기간 필터(C2)와 증빙의 기간 묶음(C1)이 둘 다 그렇게 합니다.
  조용히 줄이면 보는 사람은 "전부 본 것" 으로 읽고, 범위 밖의 미이수를 놓칩니다
- 기간으로 거를 때 기준은 **교육을 발급한 날(`course.createdAt`)** 입니다.
  수강한 날로 거르면 아직 아무것도 안 한 사람은 날짜가 없어서 통째로 빠지고,
  이수율이 저절로 올라갑니다. 이 제품이 절대 하면 안 되는 일입니다
- **그 언어 음성이 없으면 한국어로 대신 읽지 않습니다.** 기본은 소리를 내지 않고,
  **왜 안 내는지를 그 사람의 언어로 화면에 적습니다** (`UI.voiceSilent` · `UI.voiceNote`).
  뜻이 안 닿는 소리가 나면 사람은 "들었다" 고 생각하고 그대로 검증을 통과합니다.
  되돌림은 없애지 않고 마이 화면에서 **고르게** 합니다 (`Store.prefs.voiceFallback`,
  기본 `silent`) — 말은 알아듣는데 글만 못 읽는 사람에게는 그것이 유일한 통로입니다
- **한국어도 노동자의 언어입니다.** `voiceSilent()` 는 한국어에 늘 거짓이고,
  한국어 사용자에게는 "내 언어 번역 준비 중" 배지를 띄우지 않습니다
  (`needsTranslation()` — `home.js` · `learn.js`). 원문이 곧 그 사람의 언어이고,
  `translations.ko` 는 앞으로도 생기지 않으므로 그 배지는 영원히 남습니다
- **검사에 한국어 글자를 박지 않습니다.** 화면 글자는 노동자의 언어로 나오므로
  `I18N.t(키, 언어)` 로 견줍니다. 번역을 고칠 때마다 깨지는 검사는 번역을 막는 검사입니다
- 이 규칙들은 맨 아래 **"절대 지우지 말 것"** 표에도 들어 있습니다

  > 쌓인 기록이 담당자에게 저절로 가지 않습니다. 그건 서버가 필요한 문제이고,
  > 지금은 기능1 의 **내보내기 / 불러오기**로 옮깁니다.
  > 그리고 **홈 화면에 추가(web app manifest)는 하지 않았습니다** — 아이콘 파일이
  > 필요해서 "외부 이미지 0건" 과 부딪칩니다. 따로 정할 일입니다.

## 아직 서버가 있어야 하는 것

- **현장 실사진 hotspot** — `localStorage` 약 5MB 벽. **사진이 필요해지는 시점이
  서버가 필요해지는 시점입니다**
- **실제 6개 언어 음성** — 지금은 브라우저 음성합성입니다. **음성도 문구처럼
  검수 상태를 가져야 합니다**
- **문항 검수** — 문항 문구도 역번역 대조와 사람 승인을 거치게 (A1 의 남는 한계)
- **노동자 → 운영자 오역 신고 직결** — 지금은 홈에 안내만 있습니다
- **익명 유지 회신 채널** — 신고자를 식별하지 않는 티켓 번호로 "조치됐습니다" 회신
- **증빙 위조 검증** — 생성 시점 해시·타임스탬프
- **감독기관 제출 서식 연동** — **"면책" 표현 금지는 그대로**
- **문항 난이도 자동 관측** — 최초 통과율이 70~85% 밖으로 나가면 경고

## 전체

| 무엇 | 왜 |
|---|---|
| **외부 요청 0건** — CDN · 웹폰트 · 외부 이미지 · npm 금지 | 인터넷 없이 `file://` 로 열리는 것이 이 프로젝트의 확인 방법 전체입니다. `sw.js` 의 `fetch(req)` 만 예외이고, 그 대신 "외부 주소 0건 · 같은 오리진만" 을 따로 검사합니다 |
| **Service Worker 는 `https:` 일 때만 등록** — `assets/ui.js` `registerSW()` | `file://` 에서는 부르는 것만으로 예외가 나는 브라우저가 있습니다. 더블클릭 확인을 잃으면 확인 방법이 없어집니다 |
| **새 화면·새 공용 파일을 만들면 `src/sw.js` 목록에 한 줄** | 빠뜨리면 그 화면만 오프라인에서 안 열립니다. 온라인에서는 멀쩡해서 사람 눈으로는 못 잡습니다 (`tests/test-offline.js` 가 대조합니다) |
| **"오프라인 가능" 을 고정 문구로 박지 않는다** — `worker/home.js` `renderOfflineOk()` | 담기지 않았는데 담겼다고 말하면 화면이 거짓말을 합니다. B4 에서 이 배지를 일부러 뺐던 이유가 그것입니다 |
| **`innerHTML` 금지** — `UI.el` 로 `textContent` | 설비 이름 한 줄로 화면이 깨지면 안 됩니다 |
| **ES 모듈 금지** — `var X = (function(){...})()` | `file://` 에서 CORS 로 막힙니다. 한 번 겪고 되돌린 기록이 devlog 에 있습니다 |
| **`localStorage` 직접 호출 금지** — `Store` 를 거친다 | 서버가 생기면 `store.js` 하나만 바꾸면 됩니다 |
| **첫 방문 자동 채우기는 `Seed.fillIfEmpty()` 만** — `assets/login.js` | `fill()` 은 덮어씁니다. 담당자가 등록한 사업장이 새로고침마다 예시로 되돌아갑니다. 그리고 **로그인 확인보다 뒤에서** 부릅니다 — 앞에 두면 계정이 지워진 세션을 되살려 로그인하지 않은 사람이 화면 안으로 들어갑니다 |
| **색상만으로 상태 구분 금지** | 아이콘 + 글자 + 색 3중. 흑백으로 봐도 뜻이 남아야 합니다 |
