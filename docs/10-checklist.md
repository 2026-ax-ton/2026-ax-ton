# ★★ A. 가장 중요한 두 가지

이 둘이 이 제품의 **핵심 주장**이고, 아직 **한 번도 제대로 확인 못 했습니다.**

## A1. QR 을 폰 카메라로 실제로 찍기

> **왜 중요한가** — 자동 검사는 "만든 QR 을 내가 다시 읽어서" 확인했습니다.
> 그건 **내 글씨를 내가 읽는 것**이라, 규격 자체를 오해했으면 못 잡습니다.
> 규격 상수(형식정보·버전정보·생성 다항식·용량표)를 대조해서 상당히 막아 뒀지만,
> **마지막 판정은 카메라입니다.**

**길** — PC 에서 https://2026-ax-ton.vercel.app → `kim@daesung.co.kr`
→ 하단 **콘텐츠** → 발급한 교육 표에서 **접속 주소** 버튼

- **✅ 성공**
  - QR 그림이 뜨고, 아래에 주소가 **글자로도** 보인다
  - 주소가 `https://2026-ax-ton.vercel.app/worker/learn.html?course=c-press` 꼴이다
    (상대경로 `../` 로 시작하면 **실패**)
  - **폰 카메라로 찍으면** 그 주소가 인식된다
  - 열면 → (로그인 안 돼 있으면) 로그인 화면 → 로그인 → **그 교육이 바로 열린다**
    (교육 목록이 아니라 **문구 첫 장**이 떠야 합니다)
- **❌ 실패와 볼 곳**

  | 증상 | 어디를 보나 |
  |---|---|
  | 카메라가 QR 을 **아예 못 알아봄** | `src/assets/qr.js` 의 격자 만들기. 화면을 키우거나 종이에 인쇄해서 다시 |
  | 주소는 읽히는데 **딴 글자** | `qr.js` 의 데이터 인코딩 / 블록 섞기 |
  | 열었는데 **로그인 화면에서 멈춤** | `assets/auth.js` 의 `loginUrl` · `assets/login.js` 의 `next` 처리 |
  | 로그인은 됐는데 **교육 목록**만 뜸 | `src/worker/learn.js` 맨 아래 `openFromQR()` |
  | 파일(`file://`)로 열었더니 주소가 `null/...` | 정상 아님 → `content.js` 의 `appBase()` |
- **⬜ 경계**
  - **`file://` 로 연 화면의 QR 은 배포 주소를 가리킵니다.** 그래서 찍으면
    "내 PC 에 넣은 데이터"가 아니라 배포 주소의 데이터가 보입니다 — **맞습니다.**
    화면에도 그렇게 적혀 있습니다
  - QR 은 **밝은 바탕에 어두운 칸**이어야 읽힙니다. 화면 밝기를 낮추거나
    어두운 곳에서 찍으면 안 읽힐 수 있습니다 — 코드 문제가 아닙니다
  - **주소가 213바이트를 넘으면 QR 을 안 만듭니다.** 대신 이유를 적습니다.
    지금 주소는 65자라 여유가 큽니다

## A2. 글자를 한 자도 안 읽고 끝까지 가기

> **왜 중요한가** — 이 제품의 존재 이유입니다.
> **만든 사람은 어디를 눌러야 할지 이미 알아서 스스로 확인이 어렵습니다.**
> 그래서 방법이 둘입니다.

**방법 1 — 혼자서**: 화면의 **한글을 일부러 안 읽고**, 그림·아이콘·소리만으로 갑니다.
**방법 2 — 더 정확함**: 다른 사람에게 **아무 설명 없이 폰을 건네고**,
"안전교육을 끝까지 해 보세요" 라고만 말합니다. **옆에서 아무 말도 하지 않습니다.**

**길** — 폰에서 `W-4821-03` (베트남어 · 미수강) 으로 로그인

- **✅ 성공**
  - 홈에서 **지금 무엇을 해야 하는지**를 그림·소리로 알 수 있다
  - 🎧 를 눌러 교육으로 가고, 문구를 끝까지 넘기고,
    👆 검증 3문항을 풀고, 결과 화면까지 **한글을 안 읽고** 도달한다
  - 막히는 자리가 있으면 **그 자리를 적어 둔다** ← 이게 이 확인의 결과물입니다
- **❌ 실패로 볼 것**
  - **글자를 읽어야만 다음으로 갈 수 있는 자리**가 하나라도 있으면 실패입니다
  - 소리가 안 나는데 **화면에 아무 말도 없으면** 실패입니다
    (안 나면 🔇 로 바뀌고 안내가 떠야 합니다)
- **⬜ 경계**
  - **베트남어 음성이 기기에 없을 수 있습니다.** 그때 한국어로 읽고
    **"내 언어 음성이 없습니다" 라고 화면에 적으면 맞습니다** — 조용히 넘어가면 실패
  - **재교육 지시 메모는 한국어입니다.** 못 읽는 게 맞고, 대신
    "담당자가 한국어로 남긴 말" 배지가 붙고 **할 일(🔁 · 교육 이름 · 다시 듣기 버튼)은
    글자 없이** 전달돼야 합니다
  - **번역이 없는 문구는 한국어 + "준비 중" 배지**로 나옵니다.
    조용히 숨기는 것보다 낫다고 정한 것입니다

# B. 오늘 만든 것 — 눈으로 확인

## B0. ★ 오프라인 — 비행기 모드로 잘라 보기 (E1)

> **왜 중요한가** — *"현장 인터넷이 약하다"* 가 이 제품의 전제이고,
> *"QR 을 설비 앞에 붙입니다"* 가 시연 문장입니다. 그 자리에 신호가 없으면
> 찍어도 아무것도 안 열립니다. **자동 검사는 sw.js 를 글로 읽었을 뿐이고,
> 실제로 담기는지는 브라우저만 압니다.**

**길** — 폰에서 https://2026-ax-ton.vercel.app 을 **한 번 엽니다** (여기서 담깁니다)
→ **비행기 모드 켜기** → 새로고침

- **✅ 성공**
  - 비행기 모드에서 새로고침해도 **로그인 화면이 그대로 뜬다**
  - 로그인해서 `W-4821-07` 홈으로 가면 메뉴 아래에 **"✓ 오프라인 가능"** 배지와
    *"…처음 한 번만 인터넷이 필요합니다"* 가 있다
  - 위쪽에 **📴 오프라인 — 이 기기에 저장된 화면으로 그대로 이어집니다** 띠가 뜬다
  - **QR 주소**(`.../worker/learn.html?course=c-press`)를 비행기 모드에서 열면
    **교육이 바로 열린다** ← `?course=` 가 붙어 있어도 열려야 합니다
  - 비행기 모드로 **이해도 검증을 끝까지 풀 수 있고** 기록이 남는다
  - 비행기 모드를 끄면 띠가 **저절로 사라진다**
- **❌ 실패와 볼 곳**

  | 증상 | 어디를 보나 |
  |---|---|
  | 비행기 모드에서 **아무 화면도 안 뜸** | 담기지 않았다. F12 → Application → Service Workers. `src/sw.js` 가 배포에 올라갔는지 (`curl -s <주소>/sw.js \| head`) |
  | 다른 화면은 열리는데 **한 화면만** 안 열림 | `src/sw.js` 의 `PRECACHE` 에서 그 파일이 빠졌다 |
  | **QR 주소만** 안 열림 (`learn.html` 은 열림) | `sw.js` 의 `ignoreSearch: true` |
  | 고쳐서 배포했는데 **옛 화면이 그대로** | `src/sw.js` 의 `VERSION` 을 안 올렸다. 탭을 완전히 닫았다 열기 |
  | **배지는 뜨는데 실제로는 안 열림** | 화면이 거짓말을 하고 있다 — `home.js` 의 `renderOfflineOk` / `UI.offlineReady` |
- **⬜ 경계**
  - **처음 한 번은 반드시 인터넷이 필요합니다.** 담을 것을 그때 받습니다.
    설비 앞에서 QR 을 *처음* 찍는 사람에게는 그 한 번이 있어야 합니다 — 맞습니다
  - **`file://` 로 열면 오프라인 배지가 안 뜹니다.** Service Worker 는 `https:`
    에서만 등록됩니다. 안 뜨는 것이 맞습니다
  - **오프라인은 이 기기 안에서만입니다.** 끊긴 동안 푼 검증 기록이 담당자에게
    저절로 가지 않습니다. 서버가 없어서 그렇고, 옮기려면 기능1 의 내보내기/불러오기입니다
  - **첫 방문 자동 채우기는 인터넷이 있을 때 일어납니다.** 비행기 모드로 처음 열면
    계정이 없는 것이 맞습니다

## B0-2. ★ 말로 알리기 (음성 신고)

> **왜 중요한가** — 글을 쓰기 어렵거나 손이 자유롭지 않은 사람이
> **말만으로 신고**할 수 있어야 합니다. 그런데 **목소리는 사람을 식별합니다.**
> 그래서 말한 것을 글자로 바꾸고 **목소리는 저장하지 않습니다.**

**길** — 폰에서 `W-4821-07` → **신고** → ③ 칸의 **🎤 말로 알리기**

- **✅ 성공**
  - 버튼을 누르면 마이크 허용을 묻고, 허용하면 **"듣고 있습니다"** 가 뜬다
  - 말하는 대로 아래 칸에 **글자가 쌓인다**
  - 버튼 글자가 **"다 말했습니다"** 로 바뀐다 (색만으로 구분하지 않는다)

  - 옮겨진 글을 **손으로 고칠 수 있다**
  - 화면에 **"목소리는 저장하지 않습니다"** 와 **"이 기능만 인터넷이 필요합니다"** 가 적혀 있다

  | 마이크를 물어보지도 않음 | https 가 아니거나 브라우저가 지원 안 함. 화면에 이유가 떠야 한다 |
  | **한국어로 알아들음** | `report.js` 의 `lang: me.lang` · `ui.js` 의 `VOICE_TAG` |
  | 저장된 신고에 **오디오가 들어 있음** | 그건 **사고**입니다. `report.js` 저장 블록 |
- **⬜ 경계**
  - **`file://` 과 오프라인에서는 안 됩니다.** 받아쓰기는 인터넷이 필요합니다.
    그때 화면에 **"인터넷이 끊겨 있어…"** 가 뜨면 맞습니다
  - **이 기능만 외부 요청이 있습니다.** 브라우저가 소리를 인식 서버로 보냅니다.
    화면에 적어 놨습니다
  - **받아쓰기는 틀립니다.** 그래서 고칠 수 있는 칸에 넣고, 담당자 화면에도
    "잘못 옮겨졌을 수 있습니다" 를 적습니다
  - **설비와 위험유형은 여전히 눌러서 고릅니다.** 음성은 "더 할 말" 을 대신합니다 —
    두 번 누르는 것만으로도 신고는 끝납니다

## B0-3. ★★ 내 언어 음성이 없을 때 (음성 되돌림)

> **왜 중요한가** — 지금까지는 크메르어 음성이 없으면 **한국어로 읽어 줬습니다.**
> 친절해 보이지만, 그 노동자에게 한국어 소리는 대부분 뜻이 닿지 않습니다.
> **소리는 나는데 아무것도 전달되지 않으면 사람은 "들었다" 고 생각하고 넘어갑니다.**
> 그리고 그대로 이해도 검증을 통과합니다 — **이 제품이 막겠다고 만든 상황이 그것입니다.**
>
> 그래도 없애지 않았습니다. **말은 알아듣는데 글만 못 읽는 사람**에게는
> 한국어 음성이 유일한 통로입니다. 그래서 **고르게** 합니다.

**길** — `W-4821-07`(크메르어) → **마이** → 글자 크기 **아래** 새 칸

- **✅ 성공**
  - 칸에 칩이 **둘**: **🔇 소리 안 냄**(지금 골라져 있음) · **🔊 한국어로 들려주기**
  - 칩 글자와 제목·설명이 **크메르어**로 보인다 (아이콘은 그대로)
  - 이 PC 에 크메르어 음성이 없으면, 화면 맨 위 안내 줄에 **크메르어 문장**이
    떠 있고 🔊 버튼이 **🔇** 로 보인다. **눌러도 소리가 안 나는 것이 맞습니다** —
    조용히 안 나는 것이 아니라, **화면에 이유가 적힌 채로** 안 나야 합니다
  - **🔊 한국어로 들려주기** 를 고르면 **누르는 즉시**
    ① 토스트가 뜨고 ② **안내 줄 문장이 바뀌고**
    ③ **새로고침하지 않고** 홈으로 가도 버튼이 🔊 로 돌아와 있고 한국어로 읽는다
  - **소리가 나도 안내 줄이 사라지지 않는다** — 한국어로 듣고 있다는 사실이 남아야 합니다
  - 🔇 로 되돌리면 다시 바뀌고, **새로고침해도 유지**된다 (기기 설정)
- **❌ 실패와 볼 곳**

  | 증상 | 어디를 보나 |
  |---|---|
  | 소리가 안 나는데 **화면이 아무 말도 안 함** | 가장 나쁜 실패. `ui.js` `voiceNote` · `voiceNoteKey` |

# D2. 서버·DB·AI 망가뜨려 보기 (3차, T15) — 배포 주소에서

> 자동 검사(가짜 `sql`·가짜 `fetch`)가 **코드 수준**에서 이미 본 것들입니다.
> 여기서는 **실물 배포 주소**에서 같은 상황을 만들어 눈으로 봅니다.
> 둘 다 해야 끝난 것입니다 — 자동 검사는 "약속대로 코드가 짜였는가", 이 표는
> "그 약속이 실제 네트워크·실제 DB 앞에서도 지켜지는가" 를 봅니다.

| | 무엇을 해 보나 | 이러면 ✅ |
|---|---|---|
| ☐ | 로그인한 채로 **비행기 모드** → 아무 화면이나 새로고침 | 화면이 그대로 열린다 (캐시). 저장은 "이 기기에 저장 중" 배지와 함께 계속된다 |
| ☐ | 비행기 모드에서 신고를 보내고, **연결을 다시 켠다** | 잠시 뒤 자동으로 서버에 올라간다 (안 눌러도 됨) |
| ☐ | 틀린 비밀번호로 로그인 5번 연속 | 5번째에 **잠김** 안내(10분). 아이디가 있는지 없는지는 메시지로 구분되지 않는다 |
| ☐ | 아예 없는 아이디로 로그인 | 비밀번호가 틀렸을 때와 **같은 문장** (아이디가 있는지 흘리지 않는다) |
| ☐ | 노동자 계정으로 **이해도 검증을 통과** → 홈으로 | 로그인 화면으로 돌아간다 (자동 로그아웃). 다시 들어가려면 로그인해야 한다 |
| ☐ | 노동자 계정으로 검증에서 **일부러 틀림** → 지금 다시 풀기 | 로그아웃되지 않고 바로 다시 풀 수 있다 |
| ☐ | 운영자 화면에서 AI 번역 받기 → **문구가 길거나 이상한 언어일 때** | 실패해도 손 입력 칸이 그대로 있다 (버튼이 사라지지 않는다) |
| ☐ | 노동자 폰에서 신고 1건 전송 → **20초 안에** 담당자 PC 대시보드 새로고침 없이 확인 (STC-E25-010) | 신고 큐에 뜬다 |
| ☐ | 노동자 폰에서 수강·검증 완료 → 담당자 PC 대시보드가 20초 안에 반영 (STC-E25-010) | 이수율·취약 항목이 바뀐다 |
| ☐ | 담당자가 신고 상태를 바꾼 뒤 **다른 기기**로 같은 신고를 연다 | 20초 안에 바뀐 상태로 보인다 |

> **두 기기 확인(STC-E25-010·011)은 Vercel Preview `DATABASE_URL` 이 정리된 뒤**
> 미리보기 주소에서 폰 1대 + PC 1대로 해야 합니다. 기기가 하나뿐이면
> 브라우저 둘(예: 크롬 + 엣지)로 계정을 달리 해서 흉내 낼 수 있습니다
> (같은 브라우저의 다른 탭은 `sessionStorage` 를 공유하지 않지만, 창을 새로 열면
> 보통 같은 세션을 봅니다 — **다른 브라우저 또는 시크릿 창**을 쓰세요).

**발표에서 보여 줄 순서입니다.** 한 번 돌려 보고 막히는 자리를 적어 두세요.

| 3 | 같은 계정 → 이해도 검증 👆 | *"글로 답하지 않습니다. 설비 그림에서 위험한 곳을 짚습니다"* |
| 4 | 일부러 틀려 보기 | *"맞고 틀림만 알려 주면 다음에 또 같은 선택을 합니다. **어떤 사고가 되는지**를 말합니다"* |
| 5 | `kim@` → 대시보드 | *"이수율이 아니라 **어느 언어가 무엇을 못 알아들었는지**를 봅니다"* |
| 6 | 조치 대상 → **재교육 지시** | *"이건 '이 교육을 다시 듣게 한다'는 뜻이지 '이 사람이 못했다'가 아닙니다"* |
| 7 | 콘텐츠 → **접속 주소** → QR | *"설비 앞에 붙입니다. 찍으면 그 설비 교육이 바로 열립니다"* |
| 8 | 증빙 → 인쇄 미리보기 | *"서명이 아니라 **이해도 검증 결과**입니다. 미이수자를 숨길 경로가 없습니다"* |

**시연 전 준비**

- ☐ 배포 주소를 미리 한 번 열어 둔다 (첫 방문 자동 채우기가 돌게)
- ☐ 폰과 PC **둘 다** 데이터를 채워 둔다 (기기마다 별개입니다)
- ☐ **시크릿 모드로 시연하지 않는다** (껐다 켜면 사라집니다)
- ☐ 발표 직전 **기능1 → 내보내기**로 JSON 백업
