# 00. 처음 한 번 — 설치부터 첫 화면까지

**소요 시간 약 20분.** 이 문서는 딱 한 번만 하면 됩니다.

코드를 몰라도 됩니다. 회색 상자 안의 글자는 **그대로 복사해서 붙여넣으면** 됩니다.

---

## 1단계 · 준비물 세 가지

이미 깔려 있으면 넘어가세요.

| 프로그램 | 무엇 | 받는 곳 |
|---|---|---|
| **Git** | 코드를 팀과 주고받는 도구 | https://git-scm.com/downloads |
| **VS Code** | 코드를 여는 편집기 | https://code.visualstudio.com |
| **Claude Code** | 개발을 대신 해 주는 도구 | https://claude.com/claude-code |

### 잘 깔렸는지 확인

VS Code 를 열고 상단 메뉴에서 **터미널 → 새 터미널** 을 누릅니다.
아래쪽에 검은 칸이 생기면, 거기에 한 줄씩 치고 엔터를 누르세요.

```
git --version
```

`git version 2.xx.x` 처럼 나오면 성공입니다.
`명령을 찾을 수 없습니다` 가 나오면 Git 이 안 깔린 것이니 다시 설치하세요.

---

## 2단계 · 코드 받아오기

터미널에 아래를 **한 줄씩** 붙여넣고 엔터를 누릅니다.

```
cd ~/Documents
```

```
git clone https://github.com/2026-ax-ton/2026-ax-ton.git
```

```
cd 2026-ax-ton
```

> 처음 clone 할 때 GitHub 로그인을 물어볼 수 있습니다.
> 창이 뜨면 GitHub 계정으로 로그인하세요. 관리자에게 저장소 초대를 미리 받아 두셔야 합니다.

---

## 3단계 · 내 브랜치로 이동

**브랜치**는 "나만의 작업 공간"입니다. 각자 자기 공간에서 작업해야 서로 안 부딪힙니다.

아래에서 **본인 이름** 부분만 바꿔서 치세요.

```
git checkout feature/본인이름
```

예를 들어 `classyb` 님이면 이렇게 됩니다.

```
git checkout feature/classyb
```

> 내 브랜치 이름을 모르겠으면 관리자에게 물어보세요.
> 현재 브랜치는 `git branch --show-current` 로 언제든 확인할 수 있습니다.

이어서 팀의 최신 코드를 받아옵니다.

```
git pull origin develop
```

## 4단계 · 화면이 뜨는지 확인

**여기서 아무것도 설치할 필요가 없습니다.** 빌드가 없는 프로젝트입니다.

1. 파일 탐색기(Finder)에서 방금 받은 `2026-ax-ton` 폴더를 엽니다
2. `src` 폴더 안의 **`index.html`** 을 더블클릭합니다
3. 브라우저에 **로그인 화면**이 뜨면 성공입니다

### 예시 데이터 채우기

서버가 없어서 계정도 내 브라우저 안에만 있습니다. 처음엔 아무 계정도 없습니다.

화면 아래쪽 **`예시 데이터 채우기`** 버튼을 누르세요.
예시 사업장과 계정 4개가 한 번에 생깁니다.

### 로그인해 보기

비밀번호는 전부 **`1234`** 입니다. 계정 옆의 `이 계정으로` 버튼을 누르면 자동으로 채워집니다.

| 아이디 | 역할 | 도착하는 화면 |
|---|---|---|
| `W-4821-07` | 노동자 | 노동자 홈 |
| `kim@daesung.co.kr` | 사업장 담당자 | 담당자 대시보드 |
| `oper@safety.kr` | 시스템 운영자 | 안전 문구 라이브러리 |

**세 계정으로 번갈아 로그인해 보세요.** 역할에 따라 다른 화면으로 들어가는 것이 이 서비스의 구조입니다.

지금은 대부분의 화면이 "아직 만들지 않은 화면입니다" 라고 나옵니다. 정상입니다.
그 빈칸을 채우는 것이 우리가 할 일입니다.

## 5단계 · Claude Code 열기

VS Code 터미널에서 프로젝트 폴더에 있는 상태로 아래를 칩니다.

```
claude
```

Claude Code 가 뜨면, **[03-prompts.md](03-prompts.md)** 를 열어
**내 포지션 블록을 통째로 복사**해서 붙여넣고 엔터를 누르세요.

내 포지션이 무엇인지 모르겠으면 **[02-positions.md](02-positions.md)** 를 먼저 보세요.

## 6단계 · 오늘 작업이 끝나면

**아무것도 안 하셔도 됩니다.**

Claude Code 에게 그냥 이렇게 말하세요.

> 오늘은 여기까지 할게요. 정리해 주세요.

그러면 Claude 가 알아서

1. 개발일지에 오늘 한 일을 적고
2. 코드를 저장(commit)하고
3. GitHub 에 올립니다(push)

`git` 명령어를 직접 칠 필요가 없습니다.
저장소에 [`CLAUDE.md`](../CLAUDE.md) 라는 규칙 파일이 있어서 Claude 가 알아서 따릅니다.

> **PR 과 머지는 관리자가 합니다.** 세 분은 본인 브랜치에 올리기만 하면 됩니다.
