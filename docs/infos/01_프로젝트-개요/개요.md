## 1. 한 줄 정의

- **이주노동자 안전교육 이해도 검증 플랫폼** (아이디어톤 발표 이름 **SAFE-LANG**).
- 노동자가 **자기 나라 말 음성**으로 안전교육을 듣고, **그림 문제**로 이해했는지 확인받는다. 통과해야 교육이 끝나고, 그 결과가 증빙 문서가 된다.
- 핵심 문장: *이해했는지 확인되지 않으면 교육이 끝나지 않는 시스템.*

## 2. 왜 만드나 (문제 → 해결)

| 지금의 안전교육 | 우리가 바꾸는 것 |
|---|---|
| 한국어로 설명하고 출석부에 서명하면 "교육 완료"다 | 내 언어 음성으로 듣고 그림 문제로 이해를 확인해야 "완료"다 |
| 서명은 참석의 증거일 뿐 이해의 증거가 아니다 | 이해했는지가 기록으로 남는다 |
| 사고가 나면 "교육했다"는 서명만 남는다 | 못 알아들은 부분이 대시보드에 드러나 교육을 고친다 |

- 외국인 취업자의 78.9%가 50인 미만 사업장에서 일한다 ([S02 N-04](../../documentations/10_사업화/S02_수치-근거대장.md)). 이 사업장이 주 대상이다.
- 2027-01-08부터 사업주는 외국인 노동자의 기초안전보건교육 이수를 챙겨야 한다 (S02 N-20). 단, 우리는 **법정 교육을 대신한다고 말하지 않는다** — 「교육 뒤 이해 확인과 기록」 도구다 ([C06 D-021](../../documentations/00_개발컨벤션/C06_결정기록.md), 제안).

## 3. 절대 바꾸지 않는 제품 원칙 ★

> 어떤 작업이든 이 원칙을 어기는 변경은 하지 않는다. 테스트(`tests/`)가 이 원칙이 코드에 남아 있는지 검사한다.

| # | 원칙 | 코드에서 지키는 방법 |
|---|---|---|
| 1 | **검수 완료(`reviewed`) 문구만 안전 지시로 쓴다.** 상태가 겹치면 가장 엄한 것이 이긴다 (stopped > waiting > reviewed) | `Store.phraseOk(p, lang)`으로 판정 |
| 2 | **신고는 익명이다.** 신고 데이터에 신고자를 식별할 값을 넣지 않는다 | `Store.reports`에 식별값 0 |
| 3 | **미이수자를 숨기지 않는다.** 인사평가용 내보내기와 순위를 만들지 않는다 | 대시보드·증빙 검사 |
| 4 | 통과하지 못한 것은 **교육의 실패**로 다룬다. **"면책" 표현을 쓰지 않는다** | 증빙 화면 검사 |
| 5 | **노동자 화면은 제3자 서버에 요청을 보내지 않는다** (예외 2개뿐: `sw.js`의 같은 출처 요청, 신고 화면 받아쓰기). 🆕 DB 도입 뒤에는 **같은 출처 우리 `/api`** 로만 데이터를 주고받는다 ([C06 D-023](../../documentations/00_개발컨벤션/C06_결정기록.md)) | 외부 주소 검사 |
| 6 | **글자를 한 자도 읽지 않고 끝까지 쓸 수 있어야 한다.** 모든 안내에 음성을 붙인다. 터치 영역 60px | 화면 규칙 |
| 7 | 외국인등록번호·여권번호를 받지 않는다. 사업장 내 식별번호만 쓴다 | 가입 화면 |
| 8 | **AI의 출력은 항상 `status:'waiting'`이고, 승인은 사람이 한다.** AI가 실패하면 손으로 하는 경로로 돌아간다 | 해커톤에서 만들 경계 테스트 |
| 9 | 노동자 개인 데이터를 팔지 않는다 | [C06 D-009·D-015](../../documentations/00_개발컨벤션/C06_결정기록.md) |

코드 규칙(`innerHTML` 금지, ES 모듈 금지, `localStorage`는 `Store`만, `src/` 의존성 0)은 [03 개발 §4](../03_개발/개발.md)에 있다.

## 4. 누가 쓰나 (표 1)

| 사용자 | 누구 | 하는 일 | 화면 색 |
|---|---|---|---|
| 노동자 | 외국인 제조업 노동자. 6개 언어: 크메르어(km)·인도네시아어(id)·베트남어(vi)·네팔어(ne)·태국어(th)·한국어(ko) | 교육 듣기 → 그림 문제 → 위험 신고·질문 | 코랄(빨강 계열) |
| 담당자 | 50인 미만 사업장의 안전 담당자 (생산팀장 겸직) | 설비 등록 → 교육 만들기 → 대시보드 → 증빙 출력 | 보라 |
| 운영자 | 번역 검수 담당 | 안전 문구 번역을 승인·대기·중지로 판정 | 보라 |
| 돈을 내는 사람 | 지자체·공공기관·산업단지 관리 기관·사업주 (노동자는 0원) | 이용권 구매 | — ([07 사업화](../07_사업화/사업화.md)) |
