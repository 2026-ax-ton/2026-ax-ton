## 1. 한 줄 요약

**지자체·공공기관이 연간 이용권을 사서 관내 50인 미만 사업장에 무료로 나눠 주고, 노동자는 돈을 내지 않는다.** 사업주가 직접 사는 경로는 2027-01-08 법 시행 뒤의 두 번째 매출원이다 (D-010 제안).

## 2. 왜 지금 돈이 나오나 (S01 §2)

| 근거 | 숫자 ID | 뜻 |
|---|---|---|
| 법이 생겼다 — 2027-01-08부터 외국인 노동자 기초안전보건교육 이수 의무 | N-20 | "교육했다"를 증명할 수요 |
| 예산이 생겼다 — 2026년 국비 143억 원 지역 중대재해 사각지대 해소 사업, 11개 광역 참여 | N-22·N-23 | 지자체가 쓸 돈 |
| 선례 — 성동구 QR 안전 영상 무료 배포, 부산진해경자청 AI 통역앱 1년 무상 제공 | N-26·N-27 | 같은 구조로 산 적이 있다 |

- ⚠️ 우리는 **법정 교육을 대신한다고 말하지 않는다.** 법정 교육은 공단·등록 교육기관이 한다. 우리 자리는 「교육 뒤 이해 확인 → 재교육 → 기록」이고, 등록 교육기관·수행기관과 제휴한다 (D-021 제안).

## 4. 숫자 — 어디까지 믿나

- **규칙 (D-020 제안)**: 발표 기본은 **보수 시나리오**다. 사람이 원문을 대조한 숫자만 ✅로 쓴다. AI가 찾은 출처는 대조 전까지 「AI 확인」이다. **S02 대장에 없는 숫자는 문서·발표에 쓰지 않는다.**
- 사용 금지: 아이디어톤의 TAM·SAM·SOM(1.2조·1,440억·180억 원), "2.4배", "3.4%", "62.2%" 같은 산출식 없는 수치.
- 가격 가설 (🔷 가정, S01 §5): 지자체 묶음 사업장당 연 20만 원 · 사업주 직접 연 30만 원. **가격 단위는 "사업장"** (노동자 수로 받으면 등록 인원을 줄일 동기가 생긴다).
- 3년 매출 (🔶 계산값, S09 §8, 10/24 다시 쌓음): 1년차 보수 약 1,900만 / 기본 3,600만 원 → 3년차 **보수 약 1.0억 / 기본 2.2억 원**. 5년차는 근거가 없어 말하지 않는다. (옛 S01의 3년차 4.6억, S06의 7.6억은 과장 지적으로 내렸다.)
- 솔직한 결론 (제안): 투자형 고성장보다 **공공 사업형(이용권·용역)** 에 가깝다. 고정비 1억 원이면 보수 시나리오는 3년차에도 손익분기를 못 넘는다 → 「창업 지원금 + 수행기관 계약으로 버티는 구조」라고 쓴다.
