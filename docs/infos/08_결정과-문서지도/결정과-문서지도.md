### 3.2 ID 사슬

| ID | 뜻 | 예 |
|---|---|---|
| `T-nn` → `E-nn` → `US-nn` → `TK-차수-nn` → `STC-에픽-nnn` | 주제 → 에픽 → 사용자 스토리 → 태스크 → 시험 케이스 | `TK-1-06` |
| `FR-<기능>-nn` · `AC-…` | PRD 기능 요구·수용 기준 (기능 `CM`·`AD`·`WK`) | `FR-WK-01-06` |
| `D-nnn` | 결정 | `D-022` |
| `N-nn` | 숫자 근거 (S02) | `N-20` |
| `Q숫자` | 멘토 질문 (`보관_해커톤-초기기획/MENTORING-QUESTIONS.md`) | `Q1` |
| `H1`~`H9` | 07-next-tasks H절 개발 항목 | `H1` |
| `R1`~`R13` · `K1`~`K8` · `M1`·`M2` | A03 안에서만 쓰는 결과물·컨펌 항목·마일스톤 | `M1` |

### 3.3 상태 표기
- 문장: **확정** (C06에 기록 있음) · **후보** (비교표와 함께) · **제안** (작성자 의견, 팀 검토 전) · **미정** (반드시 담당·기한을 함께).
- 표 기호: ✅ 완료 · 🔶 진행 중·계산값 · ⬜ 아직 · ❓ 확인 필요 · 🔷 가정.
- 「아마」「~할 수도 있다」 같은 애매한 말은 쓰지 않는다.

### 3.4 문서를 고칠 때 같이 확인할 것 (C03 §8 영향표)

| 바뀐 것 | 함께 확인 |
|---|---|
| 기능 추가·삭제 | D03 → D04 → D05 → D06 → D07 |
| 일정 | D02 §4, D05 스프린트 구분표, C01 §8, 이 폴더 02 |
| 결정 | C06 새 결정, 영향받는 C·D 문서, 이 폴더 08 |
| 테스트 숫자 | D07 §6, C01 §4.2, D08 |
| 수익 모델·가격 | S01, D01 비용 부담, C06 D-010 |
| 숫자 | S02 먼저, 그 `N-nn`을 인용한 문서 |

### 3.5 문체
- 주어·동사·목적어가 있는 개조식, 모호한 표현 금지, 표·그림에 번호, 약어는 처음 한 번 풀어쓴다, 숫자에는 출처·측정일, 추측은 추측이라고 쓴다.
