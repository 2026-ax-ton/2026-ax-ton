## 1. 오늘의 자세 — 멘토에게 "정해 달라"가 아니라 "점검해 달라"

- 멘토는 **준비도를 평가하고 전략을 조언**하는 사람이다. 무엇을 만들지, 어떻게 개발할지를 대신 정해 주지 않는다.
- 그래서 우리는 **설계·결정·일정을 모두 정해서** 가져간다. 멘토에게는 ① 빠진 위험 ② 심사 관점의 전략 ③ 일정의 현실성만 묻는다.
- 결정 11개는 byeonsoyun이 정했다 ([02 §7](02_최종-개발-설계.md)). 멘토 의견으로 바뀌면 멘토링 뒤 C06에 반영한다.
