## 1. 한 줄

**AI 번역·검수 에이전트(해커톤 2차)를 만들어 운영 주소에 올렸고, 실제 Gemini 유료 API로 돌아간다. 다음은 3차 DB·로그인이다.**

## 2. 무엇을 만드나

외국인 노동자 안전교육 앱. 담당자가 한국어 안전 문구를 쓰면 → **AI가 6개 언어로 번역하고 스스로 검사**한 뒤 → 사람이 승인 → 노동자 폰에서 음성·그림 문제로 수강 → 이수 증빙.

AI 에이전트 흐름: 번역 → 원문을 모르는 채로 다시 한국어로 되돌림(역번역) → 자동 검사(부정어 뒤집힘·새 단어) → 문제 있으면 최대 2번 다시 → 그래도 안 되면 사람에게 올림. **결과는 늘 「승인 대기」, 승인은 사람만.**

## 4. Neon이 뭔가요?

**인터넷에 있는 데이터베이스(창고) 서비스**입니다. 지금은 데이터가 각 폰·PC 브라우저 안(localStorage)에만 있어서, 노동자 폰에서 수강해도 담당자 PC에는 안 보입니다. Neon에 저장하면 **모든 기기가 같은 데이터**를 봅니다.

- 왜 Neon: Vercel 화면에서 클릭 몇 번으로 붙고, 연결 정보가 자동으로 들어가고, 무료 등급이 있다 (D-023)
- 할 일 (사용자): Vercel 프로젝트 → Storage → Neon 추가(싱가포르) — [A04 체크리스트](../../../documentations/20_기술명세/A04_운영준비-체크리스트.md)
- 그 뒤 개발(3차): 진짜 로그인, 기기 간 동기화, 현장(사업장)별 데이터 분리, 익명 신고 저장

| **보안 — 권한** | 다른 사업장 데이터 차단 | ⬜ | 3차 서버 권한 검사 + 테스트 |
| **개인정보** | 신고자 익명 · 외국인등록번호·여권번호 미수집 · AI에 노동자 데이터 안 보냄 | ✅ | 테스트로 검사 · DB 국외(싱가포르) 이전 고지 ⬜ (처리방침 초안 A05) |
| **외부 요청** | 노동자 화면 제3자 요청 0건 | ✅ | 화면마다 테스트 (D-025) |
| **비용 통제** | 요금 폭주 방지 | 🔶 | 호출 상한 ✅ · 하루 상한 ✅ · **Google 예산 알림 ⬜ (사용자 설정)** |
| **품질 보증** | 바꿔도 안 깨진다 | ✅ | 자동 테스트 **1,943건** · CI(PR마다, 실패 시 머지 금지) |
| **배포 · 운영** | 올리면 바로 반영, 상태를 본다 | ✅ | GitHub → Vercel 자동 배포 · 함수 로그 한 줄 JSON · 운영/미리보기 분리 |
| **백업 · 데이터 이전** | 데이터를 잃지 않는다 | 🔶 | 지금은 내보내기/불러오기 · 3차 백업 스크립트 + Neon 스냅샷 |
| **유지보수성** | 1명이 끝까지 고칠 수 있다 | ✅ | `src/` 의존성 0 · 빌드 없음 · 데이터는 `Store` 한 창구 · 결정 기록 C06 |
