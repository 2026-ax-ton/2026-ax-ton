## 6. 솔직한 약점 (멘토에게 먼저 말한다)

1. ~~해커톤 코드가 아직 0줄이다.~~ → **10/31 2차(AI) 완료·배포.** 남은 것은 3차 DB·로그인 (11/16 동결까지).
2. **사용자 검증이 0건이다.** 팀원 참여가 낮아 섭외가 진행되지 않았다.
3. **개발자가 1명이다.** 아프거나 막히면 대체 인력이 없다 → 범위를 필수 4개로 줄이고 버리는 순서를 정했다 ([04 §4](04_개발-일정.md)).
4. **크메르어·네팔어 번역 품질** — 자동 검사는 통과(150/150)했지만 원어민 확인은 0건이다.
5. **현장 시연 규정(zip·외부 API 호출)의 운영진 답변이 없다.** 영상 시연을 보험으로 둔다.
6. 🆕 **AI와 DB를 1명이 16일에 한다.** 서버 모드가 불안하면 끄고 로컬 모드로 제출하는 되돌리기 조건을 정했다 (D-023).
