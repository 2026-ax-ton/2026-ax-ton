## 1. 한 문장

**운영자가 안전 문구를 넣으면, AI 에이전트가 5개 언어로 번역하고 → 스스로 다시 한국어로 되돌려 → 뜻이 뒤집혔는지 검사하고 → 뒤집혔으면 고쳐 다시 번역하고 → 그래도 안 되면 사람에게 넘긴다. 사람이 승인한 번역만 노동자에게 나간다.**

- 지금(v1.0)은 이 일을 운영자가 **손으로** 한다: 번역문과 역번역을 직접 입력하고, `review.js`가 부정 뒤집힘을 표시한다.
- 해커톤에서는 **번역·역번역·대조·재시도를 에이전트가 하고, 사람은 판정만** 한다. 판정 규칙(`review.js`)과 승인 화면은 그대로 재사용한다.
- 🆕 **그리고 실제 서버·DB 위에서 돈다.** 노동자 폰에서 푼 결과가 담당자 PC에 나타나고, 진짜 로그인과 사업장 분리가 된다 (2026-10-31 결정, C06 D-023).

## 3. 왜 이것이 "AI Agent"인가 (표 2)

> 심사 「서비스 완성도 25점」은 **AI가 실제로 작동하는가**를 본다. 우리 에이전트는 한 번 묻고 끝나는 번역 호출이 아니다.

| 에이전트 요소 | 우리 구현 |
|---|---|
| 목표 | "사람이 검수할 수 있는, 뜻이 뒤집히지 않은 번역 초안"을 언어마다 만든다 |
| 도구 | ① `translate` (Gemini) ② `backtranslate` (다른 모델, 원문을 보지 않음) ③ `compare` (`Review.negationFlipped`·`newWordCount`, 규칙) |
| 스스로 검사 | 자기 번역을 되돌려 원문과 대조한다 |
| 피드백 반영 | 뒤집혔으면 "앞 번역을 되돌렸더니 '<역번역>'이 되었다. 부정과 금지를 다시 확인하라"를 붙여 다시 번역한다 |
| 멈춤 조건 | 재시도 최대 2회 (언어당 최대 3번 시도). 문구 1개당 호출 상한 = 언어 수 × 2 × 3 |
| 사람에게 넘김 | 상한까지 못 풀면 "사람에게 올림". 그 언어는 AI 번역문 그대로 승인할 수 없고, 사람이 직접 입력해야 승인된다 |
| 넘지 않는 선 | 결과는 **항상 `waiting`**. 승인은 사람만. 실패하면 손 입력 경로 |

- **판정을 AI에게 맡기지 않는 이유**: AI가 AI를 채점하면 같은 실수를 같이 놓친다. 규칙 대조는 결과가 매번 같고, 테스트로 고정할 수 있고, 왜 걸렸는지 화면에 보여 줄 수 있다. 규칙이 못 잡는 미묘한 오역은 **사람 승인 단계**가 잡는다.

## 4. 구조 (그림 1)

```
 노동자 화면 6개 ── 변경 없음, 외부 요청 0건 유지
 관리자·운영자 화면
   └ admin/library (운영자 문구 검수)
        │ [AI 번역 받기]
        ▼
   assets/agent.js  ── 언어마다 상태 기계, 언어끼리는 병렬
        │ ① POST /api/translate      {ko, lang, attempt, hint}
        │ ② POST /api/backtranslate  {text, lang}          ─► api/*.mjs (Vercel 함수, 저장소 루트)
        │                                                        └► Gemini generateContent (키는 서버 환경변수)
        │ ③ Review.negationFlipped + newWordCount  (브라우저, 기존 코드)
        ▼
   Store.library.translations[lang] = { text, back, status:'waiting', agent:{…} }
        │
   운영자 [승인] → status:'reviewed' + judged:{by, at}  →  Store.phraseOk()가 노동자 화면에 내보낸다

 🆕 [DB — 3차]  모든 화면 ── Store(서버 모드: 캐시 + 당겨오기 + 보낼 대기열) ── 같은 출처 /api/auth · /api/store · /api/reports
                                                                         └► Vercel 함수 (토큰·역할·사업장 검사) ──► Neon Postgres (싱가포르)
                `file://`(현장 시연)이면 로컬 모드 — 지금처럼 기기 안에서만
```

**상태 기계 (언어마다)**
```
idle ─[AI 번역 받기]→ translating → backtranslating → comparing ─┬─ 맞음 ─────────────→ done (waiting)
                                                                 └─ 뒤집힘 → 재시도(n<2) → translating
                                                                            └─ n=2 ───→ escalated (waiting + 사람에게 올림)
어느 단계든 오류·시간 초과 → failed → 손 입력 칸 + 이유 표시
```

## 7. 이미 정한 것 — 결정 11개 (표 5) ★

| # | 결정 | 이유 | 이렇게 되면 바꾼다 |
|---|---|---|---|
| 1 | **에이전트는 1개(A 번역·검수)를 깊게** 만든다. B·C는 설계 장표만 | 개발자 1명. 「AI가 실제로 작동」은 개수보다 끝까지 도는 것이 중요하다. A는 우리 핵심 원칙(검수된 번역만)과 바로 이어진다 | 11/8에 A가 끝나고 시간이 남을 때만 B 최소판 |

| 3 | **`/api`는 저장소 루트 `api/`에 둔다** — Root Directory = 저장소 루트, 출력 폴더 = `src` (🆕 10/31 수정: DB 드라이버가 필요해져 `src/`와 분리) | `src/`(브라우저)는 의존성 0을 그대로 지킨다. 서버 의존성은 루트 `package.json`에만 | 11/3 미리보기에서 `docs/`·`tests/`가 노출되면 출력 설정을 다시 확인 |
| 4 | **Gemini `generateContent`**, 키는 `x-goog-api-key` 헤더, 모델 코드는 환경변수 | 한 번 묻고 한 번 답하는 호출이라 상태가 필요 없다. 모델을 코드 수정 없이 바꿀 수 있다 | 공급사 공지로 중단 일정이 나오면 Interactions API |
| 5 | **역번역은 번역과 다른 모델로, 원문을 보여 주지 않고** 한다 | 같은 모델은 같은 실수를 같이 놓친다. 원문을 주면 "맞춰서 고친다". 시연 규모에서 비용 차이는 문구 100개당 수 달러 이하 (S02 N-65, 계산값) | 할당량·품질 문제면 같은 모델 + 다른 프롬프트 (환경변수만 변경) |

| 7 | **AI 결과는 항상 `waiting`으로 저장**, 데이터에 `agent`·`judged` 추가 | 제품 원칙 8. 누가 승인했는지가 안전 지시의 책임 기록이다 | — (원칙) |

| 11 | 🆕 **DB를 붙인다** — Neon Postgres(싱가포르), 진짜 로그인(scrypt·토큰·잠금), `Store` 서버 모드/로컬 모드, 사업장 분리, 익명 신고 별도 테이블 (C06 D-023) | 「노동자 폰 → 담당자 PC」가 실제 서비스의 증거다. 화면은 `Store` 한 창구라 거의 안 바꾼다 | 11/13 두 기기 시험이 안 되면 서버 모드를 끄고 로컬 모드로 제출 |

## 8. 시연 설계 (2분, 표 6)

| 순서 | 화면 | 보여 줄 것 |
|---|---|---|
| 1 | 운영자 문구 라이브러리 | 새 문구 "회전 중인 롤러에 손을 넣지 마세요" 입력 → [AI 번역 받기] |
| 2 | 같은 화면 | 5개 언어 진행 줄: 번역 중 → 역번역 중 → 대조 → (재시도) → 완료/올림 |
| 3 | 같은 화면 | 역번역과 원문 대조, "AI는 여기까지 · 승인은 사람" → 운영자 승인 |
| 4 | 담당자 교육 만들기 → 노동자 홈 | 승인된 문구가 크메르어 음성으로 나간다. 승인 전에는 나가지 않는다 |
| 5 | 노동자 그림 문제 → 담당자 대시보드 | 이해 확인과 기록 |
| 🆕 6 | **노동자 폰**에서 풀기 → **담당자 PC** 대시보드 | 서버·DB를 거쳐 다른 기기에 나타난다 (영상 시연 필수 — 현장 운영 PC는 `file://` 로컬 모드) |

- 재시도·올림은 실제 호출에서 나올 때만 보여 준다. 안 나오면 **경계 테스트 결과(가짜 응답)** 로 설명한다. 시연에서 결과를 조작하지 않는다.
- 운영 PC는 빈 브라우저다 → 시작 화면에서 **예시 데이터 채우기**를 먼저 누른다.

## 9. 하지 않는 것

- 🆕 노동자 화면은 제3자 서버를 부르지 않는다 (같은 출처 우리 `/api`만).
- 노동자 화면에서 AI를 부르지 않는다. 노동자 데이터·신고 데이터를 AI에 보내지 않는다.
- AI가 승인하지 않는다. AI 판정 점수로 사람 검수를 건너뛰지 않는다.
- 외부 라이브러리·프레임워크·빌드를 넣지 않는다 (`src/` 의존성 0).
