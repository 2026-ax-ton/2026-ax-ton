2. 추천 — fal.ai

  • 선불 크레딧이라 키가 새거나 실수로 반복 호출해도 충전액 이상 나가지 않는다 (예: $5 충전)
  • 키 하나로 Kling 2.6($0.07/초)과 MiniMax Turbo($0.025/초)를 둘 다 시험해 보고 고를 수 있다
  • Kling 공식은 승인 대기가 있어 제출(11/23) 일정에 맞지 않을 수 있다

비용 감 (Kling 2.6 Pro, 소리 없음)

  • 시험 클립 1개 (5초): $0.35 (약 500원)
  • 교육 1건 = 위험 3곳 × 5초: 약 $1.05 (약 1,500원)
  • 시연 준비(기계 2대 × 3클립 + 다시 만들기 몇 번): 대략 $5 안쪽
  • 음성은 영상 AI 소리를 쓰지 않는다 — 노동자 언어로 우리 앱이 읽어 준다(지금처럼). 그래서 「소리 없음」 값이 맞다

3. 만들기 전에 정할 것 · 알아 둘 것

  • 사진 → 영상을 권한다: 담당자가 찍은 그 기계 사진을 움직이게 하면 노동자가 자기 기계를 본다. 글 → 영상은 남의 기계 모양이 나온다
  • AI 영상은 틀린 동작(장갑 없이 손 넣기 등)을 그릴 수 있다 → 담당자가 미리 보고 승인해야 노동자에게 간다 (지금 승인 흐름 그대로, 영상도 waiting)
  • 클립은 5~10초다. 긴 설명 영상이 아니라 「위험 한 곳당 짧은 장면 1개」로 쓴다
  • 키는 .env.local·내 Vercel 환경변수에만 (지금 규칙 그대로). 브라우저에서 영상 AI 를 직접 부르지 않는다 — 우리 서버만 부른다 (D-032)

4. 다음 순서 (사용자가 고른 뒤)

  1. fal.ai 가입 → $5 충전 → API 키를 .env.local 에 (FAL_KEY) — 사용자 직접
  2. 시험 클립 1개: C형 사진(research/photos/gap-press-clutch.jpg, CC BY-SA) + 「가드 측방으로 손을 넣지 않는다」 장면 → Kling 2.6 vs MiniMax Turbo 비교 (약 $0.48)
  3. 결과를 보고 모델을 정한 뒤 서버 함수 /api/video(대본 GPT → 영상 fal) 를 만든다
