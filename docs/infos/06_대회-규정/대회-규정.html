3. 발표·시연 규정 (표 3)

규정우리 대응
팀당 10분 = 발표 7분(화면 전환·영상·시연 포함) + 질의 3분, 연장 없음7분 대본에 시연 2분 이내 (제안)
발표는 제출한 PPT로, 깨지면 PDF. 필요하면 폰트 파일 송부맑은고딕 위주
무대: 발표자 1 + 시연자 1, 나머지는 질의 때 등단발표자·시연자 미정 (발표팀)
시연: 현장·영상 중 하나 또는 둘 다, 점수 차이 없음현장 + 영상 둘 다 (D-019 제안)
현장 시연은 운영 PC에서 제출한 HTML을 크롬 더블클릭으로만우리 앱은 file://로 열린다 ✅. 운영 PC는 빈 브라우저 → 시작 화면에서 예시 데이터 채우기
영상 시연 장표에 [영상 시연] 표기장표에 표기
제출본이 아닌 파일·URL로 시연하면 실격배포 주소로 시연하지 않는다 (확정)
현장 인터넷 제공AI 호출은 가능. 그래도 AI 부분은 영상으로 백업

4. 제출 (표 4)

  • 받는 곳: axton@likelion.net. 필요한 파일을 모두 첨부한 메일만 제출로 인정.
  • 메일 제목: [거점대학교] 팀명_발표자료제출 → 우리 [한국기술교육대학교] 청일점_발표자료제출 (❓ 표기 확인)
  • 파일명: [팀명] 발표자료_형식 → [청일점] 발표자료_PPTX · _PDF · _영상 · _HTML
파일필수비고
발표 장표 PPTX✅
발표 장표 PDF✅
영상 시연 파일영상 시연을 하면우리는 한다
현장 시연 HTML현장 시연을 하면우리 앱은 폴더(HTML 13개 + JS·CSS)다 → ❓ zip 가능 여부
폰트 파일다른 글꼴을 쓰면
  • 25MB 초과는 구글 드라이브 링크, "링크가 있는 모든 사용자" 보기 권한. 마감 뒤 수정된 파일은 인정 안 됨.
  • 제출 시점 제안: 11/22(일) 저녁 — 사고를 피하고 뒤쪽 순서를 받는다. 11/21까지 리허설 완료.

5. 운영진에게 물을 것 — 채널톡 (⬜ 미발송, 2026-10-31)

  1. 폴더를 zip으로 압축해 제출하고 현장에서 풀어 index.html을 실행해도 되나, 아니면 HTML 한 파일이어야 하나
  2. 제출한 HTML이 우리 서버 함수(API)를 호출해 AI 결과를 받아오는 것이 허용되나 (다른 URL을 열지는 않는다)
  3. 메일 제목 [거점대학교]에 학교 이름을 적으면 되나
  • 문안 전체: C08 §8. 답에 따라: zip 불가 → 한 HTML로 묶는 스크립트 (작업량 큼) / 외부 호출 금지 → 현장은 AI 없는 흐름 + AI는 영상으로만.
