4.2 업무 흐름

  1. 담당자가 사업장·설비·노동자를 등록한다 (setup).
  2. 운영자가 안전 문구를 넣고 🆕 에이전트로 번역 초안을 받아 언어별로 승인한다 (library).
  3. 담당자가 검수된 문구만 골라 교육과 그림 문제를 만들고 QR과 함께 발급한다 (content).
  4. 노동자가 QR로 들어와 내 언어 음성으로 듣고 그림 문제를 푼다 (learn → quiz). 통과해야 완료다.
  5. 담당자가 언어×위험유형 정답률을 보고 재교육을 지시하고, 증빙을 인쇄한다 (dashboard · proof).
  6. 노동자가 이상한 번역을 신고하면 그 언어만 즉시 중지되고 운영자에게 돌아간다 (🆕 H1).
  7. 🆕 서버 모드에서는 노동자 폰에서 저장한 기록이 서버를 거쳐 담당자 PC에 나타난다 (대시보드 20초마다 당겨옴). 인터넷이 끊기면 기기에 쌓았다가 다시 연결될 때 올린다.

작품 설명

이 시스템은 한국어를 잘 모르는 외국인 노동자가 안전교육을 이해했는지 확인하는 웹 서비스이다. 노동자는 자기 언어(6개)의 음성으로 교육을 듣고, 글을 읽지 않고 손가락으로 푸는 그림 문제로 이해를 보인다. 통과하지 못하면 교육 완료로 기록되지 않고, 결과는 언어별 취약 항목과 제출용 증빙 문서로 정리된다. 해커톤 버전은 여기에 AI 번역·검수 에이전트와 실제 DB·로그인을 붙인다. 노동자 폰에서 푼 결과가 서버를 거쳐 담당자 PC에 바로 나타난다. 에이전트가 번역 → 역번역 → 대조 → 재시도 → 사람에게 올림을 수행하고, 안전 지시로 쓰이는 최종 승인은 사람이 한다.

사용자 유형

  • 주요 사용자 : 노동자 — 한국어가 서툰 외국인 제조업 노동자. 크메르어·인도네시아어·베트남어·네팔어·태국어·한국어를 지원한다.
  • 보조 사용자 : 담당자 — 50인 미만 사업장의 안전 업무 겸직자(생산팀장 등). 교육을 만들고 결과와 증빙을 다룬다.
  • 관리자 : 운영자 — 안전 문구의 언어별 번역을 승인·대기·중지로 판정한다. 해커톤 버전에서 AI 에이전트를 부르는 사람이다.
  • 비용 부담자 (사용자 아님) : 지자체 주무관·산업단지 관리 기관·사업주. 노동자는 돈을 내지 않는다 (S01, 제안).

운영 개념

  1. 시스템은 정적 웹앱(HTML + 순수 JS, 빌드 없음)과 Vercel 서버리스 함수로 Vercel에 배포된다. 데이터는 Store 모듈을 거쳐 🆕 Neon Postgres(서버 모드)에 저장되고, 기기에는 캐시가 남는다. file://로 열면 기기 안에서만 동작한다(로컬 모드).
  2. 담당자가 사업장·설비를 등록하고, 운영자가 검수한 안전 문구로 교육과 그림 문제를 만들어 설비 앞 QR과 함께 발급한다.
  3. 노동자는 QR로 접속해 내 언어 음성으로 수강하고 그림 문제로 이해를 검증받는다. 인터넷이 끊겨도 화면이 열린다(Service Worker). 노동자 화면은 외부 요청 0건이다.
  4. 담당자는 대시보드에서 언어×위험유형 정답률을 보고 재교육을 지시하며, 증빙을 인쇄한다.
  5. 🆕 (해커톤) 담당자가 사업장을 만들고 가입 코드를 발급하면 노동자가 그 코드로 가입·로그인한다. 서버는 역할과 사업장 권한을 검사하고, 신고는 계정 없이 저장한다.
  6. 🆕 (해커톤) 운영자가 [AI 번역 받기]를 누르면 Vercel 서버리스 함수가 Gemini API를 불러 번역·역번역을 받고, 브라우저의 에이전트가 대조·재시도를 지휘한다. 결과는 항상 waiting이며, AI가 실패하면 손 입력 경로로 돌아간다.

작품의 주요 기능

  1. 문해력 비전제 이해도 검증 — 그림 문제 3유형(위험 지점 짚기·올바른 작업 고르기·보호구 짝 맞추기). 통과해야 교육 완료로 기록된다.
  2. 내 언어 음성 수강 — 검수된 문구만 6개 언어 음성으로 한 장씩 보여 준다. 음성이 없으면 소리 없이 넘어가지 않고 이유를 내 언어로 알린다.
  3. 검수 게이트가 있는 다국어 안전 문구 — 언어별 판정(승인·대기·중지), 역번역 대조, 오역 신고 시 그 언어만 즉시 중지.
  4. 익명 위험 신고·현장 소통 — 그림·음성으로 익명 신고, 글·댓글·공식 답변.
  5. 대시보드·재교육·증빙 — 언어×위험유형 정답률, 재교육 지시, 미이수자를 숨길 수 없는 증빙 인쇄.
  6. 오프라인·6개 언어 화면·QR — 인터넷 없이 열림, 화면 글자 126키 × 6개 언어, 자체 QR 인코더.
  7. 🆕 AI 번역·검수 에이전트 — 번역 → 다른 모델로 역번역 → 규칙 대조 → 뜻이 뒤집히면 고쳐 재시도(최대 2회) → 못 풀면 "사람에게 올림". 승인은 사람만 한다.
  8. 🆕 판정 기록 — 누가·언제 승인했는지, AI 초안인지 사람 입력인지 남긴다.
  9. 🆕 계정과 기기 간 데이터 공유 — 진짜 로그인(비밀번호 해시), 사업장별 분리, 노동자 폰 → 담당자 PC 동기화, 인터넷이 끊긴 동안의 기록을 나중에 올림.

📌 7·8·9는 2026-10-31 확정 범위다 (9는 DB 도입 결정 C06 D-023) (최종 개발 설계 §7). 문항 출제(B)·현장 신호(C) 에이전트는 해커톤 범위 밖(로드맵)이다.

기타 개발 시 고려사항

  1. 현장 환경 — 인터넷이 약하고, 장갑을 끼고, 글을 못 읽는 사용자를 전제한다. 노동자 화면은 외부 요청 0건, 오프라인 동작, 60px 터치, 음성 병행을 지킨다.
  2. 사람·데이터 보호 — 익명 신고(신고자 식별값 0), 미이수자 숨김 금지, 인사·평가용 내보내기 금지, 외국인등록번호·여권번호 미수집, "면책" 표현 금지.
  3. AI 경계 — AI 출력은 항상 waiting, 승인은 사람만, AI 키는 서버 환경변수에만, AI 출력은 textContent로만 표시, AI에는 안전 문구만 보낸다(노동자·신고 데이터 금지).
  4. 현장 시연 규정 — 운영 PC에서 제출 HTML을 크롬 더블클릭(file://)으로 연다. ES 모듈 금지·상대 경로·의존성 0을 유지한다.
  5. 🆕 개인정보 — DB가 싱가포르(Neon)에 있어 국외 이전·처리 위탁 고지가 필요하다. 해커톤은 예시 데이터만 쓰고, 실데이터 전 처리방침·동의(A05)와 법률 확인을 거친다.
  6. 수치의 신뢰성 — 발표·문서의 숫자는 S02에 출처가 있는 것만 쓴다.

[6] 🆕 Agent.runLang(phrase, lang, onStep) @ src/assets/agent.js — 에이전트 A (확정 설계)

항목내용
목적한국어 문구를 한 언어로 번역하고, 자기 번역을 되돌려 뜻이 뒤집혔는지 스스로 검사하고, 뒤집혔으면 고쳐 다시 번역하고, 못 풀면 사람에게 올린다
입력문구 {id, ko}, 언어 코드(km·id·vi·ne·th), 진행 콜백
출력{text, back, tries, flipped, escalated, model} → 저장은 translations[lang] = {text, back, status:'waiting', agent:{tries, flipped, escalated, model, at}}
절차① attempt=0, hint='' ② /api/translate {ko, lang, attempt, hint} → text ③ /api/backtranslate {text, lang} → back (원문을 주지 않는다) ④ compare(ko, back) ⑤ 뒤집힘이 없으면 끝 ⑥ 뒤집혔고 attempt<2면 hint=back, attempt+1로 ② ⑦ attempt=2에서도 뒤집히면 escalated=true
오류어느 단계든 오류·25초 초과·응답 모양 이상 → failed. 화면은 손 입력 칸과 이유를 보인다
왜 필요한가지금 운영자가 손으로 하는 번역·역번역 입력을 줄이되, 검수 게이트(사람 승인)는 그대로 둔다
주의응답에 status가 있어도 무시하고 상수 'waiting'으로 저장한다. 출력은 textContent로만 표시한다. 호출 상한 = 언어 수 × 2 × 3

시스템 설명

SAFE-LANG은 한국어를 잘 모르는 외국인 노동자가 안전교육을 이해했는지 확인하는 웹 서비스이다. 노동자는 설비 QR로 접속해 자기 언어(6개)의 음성으로 교육을 듣고, 글자 없이 그림을 눌러 이해도 문항에 답한다. 통과해야 교육이 끝난 것으로 기록된다. 담당자는 검수가 끝난 안전 문구만 교육에 쓰고, 이수·미이수 전원이 담긴 증빙을 만든다. 통과하지 못한 결과는 노동자의 잘못이 아니라 교육의 실패로 다룬다. 해커톤 버전은 AI 번역·검수 에이전트와 실제 DB·로그인을 더했다. 노동자 폰에서 푼 결과가 서버를 거쳐 담당자 PC에 나타난다. 에이전트가 번역 → 역번역 → 대조 → 재시도 → 사람에게 올림을 수행하고, 사람이 승인한 번역만 노동자에게 나간다.
