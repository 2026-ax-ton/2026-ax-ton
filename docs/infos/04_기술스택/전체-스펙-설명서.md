# 1부 · 개발 정리

## 1. 한 장 요약

| 항목 | 내용 |
|---|---|
| 무엇 | 외국인 노동자가 **내 언어 음성**으로 안전교육을 듣고 **그림 문제**로 이해를 확인받아야 교육이 끝나는 웹앱. 결과는 증빙이 된다 |
| 사용자 | 노동자(6개 언어) · 담당자(50인 미만 사업장) · 운영자(번역 검수) |
| 형태 | **빌드 없는 정적 웹앱** — HTML + CSS + 순수 JS(전역 IIFE), 의존성 0, `file://`로도 열림 |
| 데이터 | `Store` 모듈만 접근 — 🆕 **서버 모드: Neon Postgres** (싱가포르) + 기기 캐시 · **로컬 모드(`file://`)**: 브라우저 `localStorage` 10칸 |
| 지금 (v1.0) | 화면 13개 동작 · 배포 https://2026-ax-ton.vercel.app · 오프라인 · 6개 언어 · 테스트 **1,619건 통과 (2026-10-31)** |
| 해커톤에서 더하는 것 | **AI 번역·검수 에이전트** — Gemini로 번역 → 다른 모델로 역번역 → 규칙 대조 → 재시도(≤2) → 사람에게 올림. 결과는 항상 `waiting`, 승인은 사람 |
| 새로 생기는 서버 | Vercel 서버리스 함수 — 저장소 루트 `api/`: AI 2개(`translate`·`backtranslate`) + 🆕 로그인·데이터·익명 신고. **DB는 Neon Postgres** (2026-10-31 결정, C06 D-023) |
| 개발 인원 | **1명** (byeonsoyun — 설계·FE·BE·AI·테스트·배포) |

## 2. 기술 스택 (표 1)

| 층 | 기술 | 버전·설정 | 왜 이것인가 | 상태 |
|---|---|---|---|---|
| 언어 | JavaScript (전역 IIFE `var X = (function(){…})()`, `'use strict'`) | ES 모듈 **금지** | `file://`에서 ES 모듈은 CORS로 막힌다. 현장 시연이 `file://`이다 | ✅ |
| 화면 | HTML 13개 + CSS 5개, 프레임워크 없음 | `UI.el`·`textContent` (`innerHTML` 금지) | 의존성 0, 저사양 폰에서 빠름, 사용자 입력으로 화면이 깨지지 않음 | ✅ |
| 디자인 | CSS 토큰 (보라 = 관리, 코랄 = 노동자), 선 아이콘 47개 인라인 SVG | 외부 폰트·이미지 없음 | 외부 요청 0건, 이모지는 기기마다 다르게 보임 | ✅ |
| 데이터 | `localStorage` 10칸 (`safety.<이름>.v1`, 봉투 `{v, updatedAt, data}`) | 접근은 `Store`만 | 서버가 생기면 `store.js` 안쪽만 바꾼다 | ✅ |
| 🆕 DB | **Neon Postgres** (Vercel Marketplace) | 싱가포르 `aws-ap-southeast-1`, 운영/미리보기 브랜치, 테이블 7개 | 무료 등급, 연결 정보 자동 주입. Neon에 서울 리전이 없다 | 🔶 11/9 |
| 🆕 인증 | `node:crypto` scrypt + 토큰 | 토큰 12시간 `sessionStorage`, 5회 실패 10분 잠금, 가입 코드 | 추가 의존성 없음. 공용 폰은 탭을 닫으면 로그아웃 | 🔶 11/10 |
| 🆕 동기화 | `Store` 서버 모드 | 캐시 + 당겨오기 + 보낼 대기열 + 서버 id 기준 합치기 | 화면 코드를 거의 안 바꾼다 | 🔶 11/12 |
| 오프라인 | Service Worker `sw.js` | `VERSION='v9'`, 캐시 우선, GET만, 같은 출처만 | 공장 안 약한 인터넷 | ✅ |
| 음성 | Web Speech API — `speechSynthesis` · SpeechRecognition | 음성 없음 감지(`UI.voiceSilent`) | 외부 TTS를 쓰면 노동자 화면에 외부 요청이 생긴다 | ✅ |
| 다국어 | 자체 사전 `I18N` | 126키 × 6개 언어 (km·id·vi·ne·th·ko) | | ✅ |
| QR | 자체 인코더 `qr.js` | 바이트 모드, 오류 정정 M | 외부 QR 서비스 미사용 | ✅ |
| 역번역 대조 | `review.js` | `negationFlipped`·`newWordCount` 등 순수 함수 | 사람이 볼 곳을 좁힌다. 판정은 사람 | ✅ |
| 🆕 서버 | **Vercel Functions** (Node, Web Handler `.mjs`) | 저장소 루트 `api/`, 리전 `sin1`, `maxDuration: 30`, 서버 의존성 `@neondatabase/serverless` 1개(루트 `package.json`) | 키·DB를 브라우저에 두지 않는다. `src/`는 의존성 0 유지 | 🔶 11/2 |
| 🆕 AI | **Google Gemini API** `generateContent` | 번역 `gemini-3.1-flash-lite` · 역번역 `gemini-3.8-flash` (환경변수, 구현 직전 가격표 재확인) | 공급사 결정 D-018. 모델은 코드 수정 없이 바꾼다 | 🔶 키 ✅ |
| 🆕 에이전트 | `src/assets/agent.js` | 언어별 상태 기계, `MAX_RETRY=2`, 25초 시간 초과 | 브라우저가 지휘 → 기존 `review.js` 재사용, 진행 표시 | 🔶 11/4 |
| 테스트 | Node 22 + jsdom + 자체 하네스 | jsdom 30.1.3 (저장소 밖) · 16묶음 1,619건 | 실제 배포될 화면 스크립트를 그대로 돌린다 | ✅ |
| 🆕 CI | GitHub Actions | PR마다 `tests/run-all.js` | 1인 개발에서 테스트가 리뷰어 | 🔶 11/1 |

## 4. 시스템 구조

### 4.1 지금과 해커톤 (그림 2)

```
 [노동자 화면 6]  외부 요청 0건 ── 해커톤에서도 바뀌지 않음
   home · learn(음성 수강) · quiz(그림 문제) · report(익명 신고) · talk · my
          │ Store (localStorage)
          ▼
 [관리 화면 5]  setup · content(교육 만들기·QR) · dashboard · proof(증빙) · library(문구 검수)
                                                                             │ 🆕 [AI 번역 받기]
                                                                             ▼
                                                     assets/agent.js ── 언어마다 상태 기계 (병렬)
                                                       │ ① POST /api/translate      ─► Gemini (번역 모델)
                                                       │ ② POST /api/backtranslate  ─► Gemini (다른 모델, 원문 없이)
                                                       │ ③ Review.negationFlipped + newWordCount (브라우저)
                                                       ▼
                                   translations[lang] = { text, back, status:'waiting', agent }
                                                       │ 운영자 [승인] → reviewed + judged
                                                       ▼
                                   Store.phraseOk() 가 통과한 번역만 노동자 화면에 나간다

 🆕 [DB — 3차]  모든 화면 ── Store(서버 모드) ── 같은 출처 /api/auth · /api/store · /api/reports ── Vercel 함수 ── Neon Postgres
                └ 캐시 + 보낼 대기열 (Bearer 토큰, 서버가 역할·사업장 검사)      `file://`이면 로컬 모드
```

### 4.2 업무 흐름

1. 담당자가 사업장·설비·노동자를 등록한다 (`setup`).
2. 운영자가 안전 문구를 넣고 🆕 에이전트로 번역 초안을 받아 언어별로 승인한다 (`library`).
3. 담당자가 **검수된 문구만** 골라 교육과 그림 문제를 만들고 QR과 함께 발급한다 (`content`).
4. 노동자가 QR로 들어와 내 언어 음성으로 듣고 그림 문제를 푼다 (`learn` → `quiz`). 통과해야 완료다.
5. 담당자가 언어×위험유형 정답률을 보고 재교육을 지시하고, 증빙을 인쇄한다 (`dashboard` · `proof`).
6. 노동자가 이상한 번역을 신고하면 그 언어만 즉시 중지되고 운영자에게 돌아간다 (🆕 H1).
7. 🆕 **서버 모드에서는** 노동자 폰에서 저장한 기록이 서버를 거쳐 담당자 PC에 나타난다 (대시보드 20초마다 당겨옴). 인터넷이 끊기면 기기에 쌓았다가 다시 연결될 때 올린다.

## 6. API (해커톤에서 새로 만든다)

| 메서드 | 경로 | 요청 | 응답 200 |
|---|---|---|---|
| POST | `/api/translate` | `{ko: 1~300자, lang: km·id·vi·ne·th, attempt: 0~2, hint?: ≤600자}` | `{text, model, attempt}` |
| POST | `/api/backtranslate` | `{text: 1~600자, lang}` | `{back, model}` |

| 공통 규칙 | 값 |
|---|---|
| 헤더 | `Content-Type: application/json` · `X-Agent-Pass` |
| 검사 순서 | 메서드(405) → 출처(403) → 통과 문구(401) → 4KB(413) → 입력(400) → 일일 상한(429) → 모델 20초(504) → 빈 출력(502) |
| 응답 | `application/json; charset=utf-8` · `Cache-Control: no-store` · 오류 `{error, message}` |
| CORS | 같은 출처면 없음. `null` 출처를 허용할 때만 `Access-Control-Allow-Origin: null` 등 |
| 금지 | 응답에 승인 상태(`status`)를 넣지 않는다. 로그에 원문·키·IP를 남기지 않는다. `temperature`를 보내지 않는다 |
| 프롬프트 | 번역: "산업안전 지시문 번역가. 금지·부정을 반드시 보존. 쉬운 말. 번역문 한 문장만" + 재시도면 "되돌렸더니 '<hint>'가 되어 뜻이 바뀌었다. 부정과 금지를 다시 확인하라" · 역번역: "쓰인 그대로 직역. 부정은 부정으로. **원문을 주지 않는다**" |

**🆕 데이터·로그인 API (3차)** — [A02 §14.3](../../documentations/20_기술명세/A02_기술-개발-명세서.md)

| 메서드 · 경로 | 누가 | 하는 일 |
|---|---|---|
| `POST /api/auth/signup-workplace` | 담당자 | 사업장 등록, 가입 코드 발급 |
| `POST /api/auth/signup` | 노동자 | 가입 코드 + 식별번호 + 비밀번호 |
| `POST /api/auth/login` · `logout` | 전원 | 토큰 발급 (5회 실패 → 423 잠금) · 폐기 |
| `GET /api/store` · `PUT /api/store/:key` | 역할별 | 받기 · 보내기 (서버 합치기, 오래된 판 409) |
| `POST /api/reports` · `PATCH /api/reports/:id` | 노동자 · 담당자 | 익명 신고 (계정 미저장) · 처리 상태 |

- 서버는 요청 본문의 사업장·역할을 믿지 않고 **토큰으로만** 판단한다. 노동자는 자기 `progress`만 쓸 수 있다.

## 7. AI 에이전트 설계

| 요소 | 구현 |
|---|---|
| 목표 | 사람이 검수할 수 있는, 뜻이 뒤집히지 않은 번역 초안을 언어마다 만든다 |
| 도구 | `translate` (Gemini) · `backtranslate` (다른 모델, 원문 없음) · `compare` (`Review` 규칙) |
| 루프 | 번역 → 역번역 → 대조 → 뒤집혔으면 hint를 붙여 재번역 (최대 2회) → 그래도 뒤집히면 `escalated` |
| 상태 | `idle → translating → backtranslating → comparing → done / escalated / failed` (언어별, 화면 진행 줄) |
| 병렬성 | 언어끼리 `Promise.allSettled` 병렬, 언어 안은 순차. 이미 `reviewed`인 언어는 건너뜀 |
| 상한 | 문구 1개당 호출 = 언어 수 × 2 × 3 (5개 언어면 최대 30회) |
| 사람 | 결과는 항상 `waiting`. `escalated` 언어는 사람이 직접 입력해야 승인 가능 |
| 실패 | 오류·25초 초과·응답 모양 이상 → `failed` + 손 입력 칸 + 이유 |
| 비용 | 문구 100개 × 5개 언어 ≈ 1.1~3.3달러 (계산값, S02 N-65) |
| 품질 지표 | 첫 시도 통과율 · 재시도 후 해결률 · 사람에게 올림 비율 · 사람 승인 비율 |

> 🔑 **판정을 AI에게 맡기지 않는다.** 규칙 대조는 결과가 매번 같고, 테스트로 고정되고, 이유를 화면에 보여 줄 수 있다. 규칙이 못 잡는 오역은 사람 승인이 잡는다.

## 11. 코드 규칙 — 어기면 깨지는 것 (표 12)

| # | 규칙 | 어기면 |
|---|---|---|
| 1 | 문구는 `Store.phraseOk()`로만 판정한다 | 한 언어 오역 때문에 다른 언어 노동자가 안전 지시를 잃는다 |
| 2 | 문항은 `Store.qtext()`로만 읽는다 | 번역 배열 길이가 다르면 정답이 다른 선택지를 가리킨다 |
| 3 | AI 결과·새 문구는 `waiting`으로만 저장한다 | 검수 안 된 문장이 안전 지시가 된다 |
| 4 | `innerHTML` 금지 (`UI.el`·`textContent`) | 설비 이름·AI 출력 한 줄로 화면이 깨지거나 스크립트가 실행된다 |
| 5 | ES 모듈 금지, 상대 경로 | `file://` 시연이 깨진다 |
| 6 | `localStorage`는 `Store`만 부른다 | 서버 전환 때 화면을 다 고쳐야 한다 |
| 7 | 노동자 화면 외부 요청 0건 | 약한 인터넷에서 교육이 끊긴다 |
| 8 | 신고에 식별값을 저장하지 않는다 | 익명이 깨져 신고가 멈춘다 |
| 9 | 새 화면 문구는 6개 언어를 모두 채운다 | 노동자 화면에 한국어가 섞인다 |
| 10 | 색만으로 상태를 구분하지 않는다, 새 이모지 금지 | 흑백·색약에서 뜻이 사라진다 (테스트가 잡는다) |
| 11 | 🆕 서버 코드는 루트 `api/`에만, `src/`에는 의존성·서버 코드를 넣지 않는다 | 브라우저 쪽 의존성 0이 깨진다 |
| 13 | 🆕 서버는 토큰으로만 사업장·역할을 판단한다, 질의는 매개변수 방식만 | 남의 사업장 데이터 노출, SQL 인젝션 |
| 14 | 🆕 신고 경로는 계정을 저장·기록하지 않는다 | 익명이 깨져 신고가 멈춘다 |
| 15 | 🆕 서버 실패 시 캐시로 계속하고 「이 기기에 저장 중」을 표시한다 | 노동자 기록이 조용히 사라진다 |
| 12 | 데이터 모양을 바꾸면 그 키를 읽는 화면을 전부 확인한다 | 다른 화면이 깨진다 |
