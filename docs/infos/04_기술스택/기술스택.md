- **의존성 원칙** — `src/`(브라우저)는 의존성 0이다 (확정). 🆕 서버 `api/`만 루트 `package.json`에 DB 드라이버 1개를 둔다 ([C06 D-023](../../documentations/00_개발컨벤션/C06_결정기록.md), C05 T-5′).
- 왜 이렇게 골랐나 — 인터넷 없이 `file://`로 열려야 하고(현장 시연·확인 속도), 저사양 안드로이드에서 빨라야 하고, 노동자 화면에서 외부 요청이 0건이어야 하기 때문이다.

## 2. 구조 — 지금과 해커톤 (그림 1)

```
 [지금 v1.0]                                   [해커톤 H — 만들 것]
 브라우저 (정적 HTML + 순수 JS)                 운영자 화면 (admin/library) ─ assets/agent.js (루프 지휘)
   ├─ 노동자 화면 6   외부 요청 0건                  │ ① POST /api/translate {ko, lang}
   ├─ 관리 화면 5                                    │ ② POST /api/backtranslate {text, lang}
   └─ Store ─► localStorage (기기마다 따로)          ▼
                                                  Vercel 함수 ─► Gemini API (키는 서버 환경변수 GEMINI_API_KEY)
 Vercel 정적 배포 (Root Directory = src)             │
                                                  ③ Review.negationFlipped + newWordCount로 대조 (브라우저)
                                                     ├ 맞음 → status:'waiting'으로 저장
                                                     ├ 뒤집힘 → 재시도 (최대 2번 더)
                                                     └ 그래도 뒤집힘 → "사람에게 올림"
                                                  ④ 운영자가 승인해야 reviewed → 노동자 화면에 나감
                                                  ⑤ 어느 단계든 실패 → 손 입력 칸 (지금 방식 그대로)

 🆕 [DB — 3차]  모든 화면 ── Store(서버 모드) ── 같은 출처 /api/auth · /api/store · /api/reports ── Vercel 함수 ── Neon Postgres (싱가포르)
                  └ 캐시 localStorage + 보낼 대기열      (Bearer 토큰, 서버가 역할·사업장 권한 검사)
```

- **노동자 화면의 모양은 해커톤에서도 바뀌지 않는다.** AI를 부르는 것은 운영자 화면 하나뿐이다. 🆕 서버 모드에서는 노동자 화면도 **같은 출처 `/api`** 로 데이터를 주고받는다 (제3자 요청 0건 유지).
- 에이전트 상태 기계 (언어마다 따로): `idle → translating → backtranslating → comparing → done | retry | escalated | failed`.
- 현장 시연에서 제출 HTML을 `file://`로 열면 `Origin: null`이 된다 → 시연 기간에만 `ALLOW_FILE_ORIGIN=1`로 `null` 출처를 허용하고, `agent.js` 맨 위 `API_BASE`(배포 주소)로 부른다 (D-019 제안, 운영진 답변 대기).
- 비용 (계산값): 문구 100개당 약 1.1~3.3달러 (S02 N-65).

## 4. API 계약 요약 (해커톤, A02 §5)

| 항목 | 값 |
|---|---|
| 경로 | `POST /api/translate` · `POST /api/backtranslate` (+ `OPTIONS`) |
| 요청 헤더 | `Content-Type: application/json` · `X-Agent-Pass` |
| 시간 | 함수 30초, 모델 호출 20초, 브라우저 25초 |
| 본문 상한 | 4KB |
| 오류 | `{error, message}` — 400 `bad_request` · 401 `pass_required` · 403 `origin` · 405 · 413 `too_large` · 429 `limit` · 500 `config` · 502 `model` · 504 `timeout`. **모든 오류에서 화면은 손 입력 칸을 보인다** |
| 금지 | 응답에 승인 상태(`status`) 필드를 넣지 않는다. 로그에 문구 원문·키·IP를 남기지 않는다 |

## 6. 넘지 않는 선 (보안·개인정보)

- 노동자 화면 **제3자** 요청 0건 (테스트로 검사). 🆕 같은 출처 `/api`만 허용.
- 🆕 서버는 요청 본문의 사업장·역할을 믿지 않고 토큰으로 판단한다. 다른 사업장 데이터는 어떤 경로로도 나오지 않는다.
- 🆕 익명 신고는 별도 테이블·경로에 계정 없이 저장한다. 비밀번호는 scrypt 해시, 토큰은 sha256만 저장한다.
- AI 키는 서버 환경변수에만 둔다. `src/`에 키 패턴이 0건이어야 한다.
- AI 출력은 신뢰하지 않는 문자열이다 → `textContent`로만 표시하고, 항상 `waiting`으로 저장한다.
- AI에 보내는 데이터는 안전 문구뿐이다. 노동자·신고 데이터는 보내지 않는다.
- 판매 단계 집계는 5명 미만 칸을 밖으로 내보내지 않는다.

## 7. 🆕 DB — 해커톤 3차 (2026-10-31 확정, D-023)

| 테이블 | 무엇 |
|---|---|
| `workplaces` | 사업장, 노동자 가입 코드 |
| `accounts` | 계정 (해시 비밀번호, 외국인등록번호 열 없음) |
| `sessions` | 로그인 토큰 (sha256만) |
| `docs` | 사업장별 `setup`·`courses`·`progress`·`posts`·`orders` (jsonb, 판 번호) |
| `library` | 문구 라이브러리 — 전 사업장 공용 |
| `reports` | 익명 신고 — 계정 열 없음 |
| `audit` | 판정·계정·내보내기 기록 |

| API | 하는 일 |
|---|---|
| `POST /api/auth/signup-workplace` · `signup` · `login` · `logout` | 사업장 등록·가입 코드, 노동자 가입, 로그인(5회 실패 잠금), 로그아웃 |
| `GET /api/store` · `PUT /api/store/:key` | 받기·보내기 — 서버가 id 기준으로 합치고 오래된 판은 409 |
| `POST /api/reports` · `PATCH /api/reports/:id` | 익명 신고 · 처리 상태 |

- **판매 단계로 남은 것**: 사진 첨부 신고(파일 저장소), 알림, 증빙 봉인, 비밀번호 재설정, 외부 보안 점검, 유료 요금제. 운영 준비 전체는 [A04](../../documentations/20_기술명세/A04_운영준비-체크리스트.md).
