
- **1화면 = HTML 1개 + JS 1개.** 화면 하나를 고칠 때 여는 파일이 둘로 정해져 있다.
- `src/assets/`를 고치면 11화면이 함께 영향을 받는다. 더하는 것은 안전하고, 고치는 것은 전체 테스트가 필요하다.

## 2. 브랜치와 git (표 1)

| 브랜치 | 용도 | 규칙 |
|---|---|---|
| `main` | **배포 전용**, 보호됨 | 작업 커밋 금지. 배포할 때만 `develop` → `main` `--ff-only`. `src/`가 안 바뀐 커밋은 올리지 않는다. **push는 `main` 먼저** (Vercel 빌드 건너뜀 방지) |
| `develop` | 기준 브랜치, 깃허브 기본 | 작업 브랜치를 PR로 머지 |
| `feat/agent-prd-v1` | **해커톤 작업 브랜치** (아직 없음) | CLAUDE.md 진행 루틴 1번이 만든다. 혼자여도 PR을 쓴다 |
| `feature/byeonsoyun` | 아이디어톤 작업 | 그대로 둔다. 지금 작업 트리가 여기에 있다 |
| `feature/yesool` 등 옛 팀 브랜치 | 보존 | **지우지 않는다** (`feature/yesool`은 Next.js+Supabase 별개 구현, 서버 참고용) |

- 커밋 제목: `feat:` `fix:` `docs:` `style:` `refactor:` `chore:` + 한글로 무엇을 했는지.
- 금지: `git push --force`, `git reset --hard`, `--no-verify`, `git add .` (고친 파일만 add).
- **이 사용자의 지시 (2026-10-31)**: 문서 작업 세션에서는 Claude가 커밋·푸시하지 않는다. 필요하면 사용자가 한다. 개발 루틴(아래)은 CLAUDE.md대로 커밋·push한다.

## 3. 개발 세션 루틴 (CLAUDE.md 요약)

| 사용자가 하는 말 | 루틴 |
|---|---|
| "docs 보고 진행해 줘" · "이어서 개발해 줘" · "나 뭐 하면 되는지 알려줘" | **진행** — 브랜치 확인 → `develop` 받아오기 → 07 「지난 세션이 끝난 자리」·**T 절** → 기준선 테스트 → T 절 맨 위 `- [ ]` 하나 → 만들기 → 테스트 → 체크·**「개발 후 문서 갱신 표」**·개발일지 → 커밋·push |
| "마무리해 줘" · "오늘 여기까지" | **마무리** — 멈출 자리 정리 → 전체 테스트 → 07 맨 위 갱신 블록 → **「개발 후 문서 갱신 표」 15줄 훑기** (D05·D06·D07·PRD·SPEC·A02·C06·C01·infos 등) → `node docs/infos/_build.js` → `node docs/infos/_check-links.js` → 개발일지 → 커밋·push·초안 PR → 5줄 보고 |

- 데이터 모양(10개 저장 키의 필드)을 바꾸는 항목은 **시작 전에 사용자에게 한 줄로 확인**한다.
- 멘토링 결정에 걸린 값은 파일 맨 위 상수 한 곳에 모으고 `멘토링 후 확정 — A02 §12 결정 n` 주석을 단다.
- 문서와 코드가 다르면 **코드가 사실**이다. 문서를 고치고 사용자에게 알린다.

## 4. 코드 규칙 — 어기면 안 되는 것

| 규칙 | 이유 |
|---|---|
| **제3자 요청 0건** (CDN·웹폰트·외부 이미지·npm 금지). 🆕 서버 모드는 같은 출처 `/api`만 (D-023, C05 T-1′). 아이콘은 `assets/icons.js` 인라인 SVG | 오프라인·`file://` 동작, 노동자 화면 원칙 |
| **`innerHTML` 금지** — `UI.el` 또는 `textContent` | 사용자 입력 한 줄로 화면이 깨지지 않게 |
| **ES 모듈(`import`/`export`) 금지** — `var X = (function () { ... })()` | `file://`에서 CORS로 막힌다. **현장 시연이 `file://`이다** |
| **`localStorage`는 `Store`만 부른다** | 서버가 생기면 `store.js`만 바꾼다 |
| **`src/`는 의존성 0, 빌드 없음.** `src/` 안에서 `npm install` 금지 (🆕 서버 `api/`만 루트 `package.json`) | "그냥 열린다"를 지킨다 |
| 경로는 상대 경로 (`../assets/...`) | 절대 경로는 `file://`에서 깨진다 |
| `<head>`에 `store.js` → `auth.js` → `Auth.require('역할')`, 문서 끝에 `icons.js`를 `ui.js`보다 먼저 | 화면 가드, 아이콘 교체 순서 (테스트가 본다) |
| 상태는 아이콘 + 글자 + 색 3중 (`UI.okBadge` 등). 새 이모지 금지 | 흑백·색약에서도 뜻이 남게. `test-icons.js`가 본다 |
| 노동자 화면 터치 60px (`--tap-min`), 관리자 보조 조작 40px | 장갑 낀 손 |
| 새 화면 문구는 i18n 6개 언어를 모두 채운다 (모르면 한국어 + `TODO(번역)`) | 노동자 언어 화면 |
| `sw.js`의 `VERSION`을 올려야 배포 후 새 판이 들어온다 (탭을 다 닫아야 적용) | 캐시 |

- 데이터는 출처(`file://`·`localhost`·배포 주소)마다 따로다. 다른 기기에선 안 보인다. 약 5MB 한계.

### 5.2 자동 테스트
```bash
mkdir -p ~/jsdom-box && cd ~/jsdom-box && npm i jsdom            # 한 번만, 저장소 밖
cd <저장소> && NODE_PATH=~/jsdom-box/node_modules node tests/run-all.js
```
- 기준선: **16묶음 1,619건 통과** (2026-10-31).
- ⚠️ **IMP-1** — 테스트 10개 파일(`harness.js` `test-content.js` `test-dashboard.js` `test-docs.js` `test-learn.js` `test-library.js` `test-proof.js` `test-quiz.js` `test-smoke.js` `test-worker.js`)에 `C:/Users/byeonsoyun/2026-ax-ton/2026-ax-ton`이 박혀 있다. 다른 PC·Linux에서는 그대로 돌지 않는다.
  - 임시 방법 (2026-10-31에 쓴 것): 저장소 밖에 `src/`·`tests/`·`docs/`·`CLAUDE.md`를 복사 → 복사본에서 그 경로를 복사본 경로로 `sed` 치환 → 실행. 원본은 건드리지 않는다.
  - 해결은 C01 §7 #7 (TK-1-06). 코드 수정이므로 사용자 요청 뒤에 한다.
